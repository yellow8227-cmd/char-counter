## 주석(annotation)의 출처

디자인 앵커 3종(부적 · 색동저고리 · 짚신)의 문화적 설명은
대본 `赫血_260812_LAST_FINAL_한국어` 안에 이미 달려 있던 ▶주석을 그대로 옮긴 것입니다.
스펙 텍스트(키 150cm / 여성 / 노인 / 특징)는 캐릭터 시트 이미지에 적힌 내용을 따랐습니다.
연출 노트는 트리트먼트의 해당 장면에서 근거를 가져왔습니다.

## 빌드

```bash
pip install python-pptx pillow
python3 build_deck_kr.py        # → build/KAKKETSU_그것_컨셉레퍼런스_KR.pptx
```

`assets/` 는 원본 이미지를 덱용으로 리사이즈·크롭한 것입니다.
디테일 크롭(부적, 색동 소매, 짚신, 타이틀 락업)도 여기 들어 있습니다.

PDF 변환:

```bash
soffice --headless --convert-to pdf build/KAKKETSU_그것_컨셉레퍼런스_KR.pptx
```

## 폰트

- 한글 · 한자 — `Malgun Gothic` (윈도우 기본. 맥에서는 Apple SD Gothic Neo로 대체됨)
- 라틴 소제목 · 숫자 — `Cambria`

다른 폰트로 바꾸려면 `build_deck_kr.py` 상단의 `KR`, `LAT` 상수만 고치면 됩니다.

## 일본 투자사용 버전 (8월 말)

같은 빌더를 재사용할 수 있게 텍스트는 전부 스크립트 안에 문자열로 분리해 두었습니다.
일본어판에서 추가로 다뤄야 할 것:

- 대본에 이미 달려 있는 일본어 독자용 주석 전체 반영
  (짚신/와라지 비교, 부적과 오마모리의 차이 = 후다·인·결계, 순사, 처형인(회자수), 개량한복, 태극기, 붉은청년단, 생간·천엽·순대)
- 폰트를 `Yu Gothic` / `Noto Sans JP` 계열로 교체
- 1984 오사카 · 1996 큐슈 · 2011 후쿠오카 등 일본 로케이션 비중을 앞으로
- 「封神」의 일본어 독음과 한자 표기 병기
