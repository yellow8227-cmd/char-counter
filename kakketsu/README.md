## 편집 원칙 (빌더가 강제한다)

- **같은 사진을 두 번 쓰지 않는다.** `_src()` 가 중복 사용 시 빌드를 실패시킨다.
- **본문은 12pt 이상, 어두운 판 위에만.** `note()` 가 반투명 검정 판을 자동으로 깐다.
- **판 높이는 CJK 라인박스(1.38em)로 계산한다.** 이 보정을 빼면 판이 짧아져 글이 넘친다
  (`EM`, `LSP` 상수). 각 슬라이드 끝의 `assert` 가 푸터 침범을 빌드 타임에 잡는다.
- 겹치는 내용은 슬라이드를 합치거나 버린다.
- **레퍼런스 시트를 통짜로 나열하지 않는다.** 4안을 나란히 놓으면 같은 그림의 반복으로
  보이고, 시트 안의 글자는 읽히지 않는다. 차이가 드러나는 부분만 크롭해서 크게 쓴다
  (`look_a`~`look_d`, `cost_a`~`cost_d`). 크롭은 네 컷의 비율을 통일해야 하단선이 맞는다.

## 주석의 출처

디자인 앵커 3종(부적 · 색동저고리 · 짚신)의 문화 주석은 대본
`赫血_260812_LAST_FINAL_한국어` 안에 이미 달려 있던 ▶주석을 옮긴 것입니다.
스펙(150cm / 여성 / 노인 / 특징)은 캐릭터 시트 이미지의 기재를 따랐고,
연출 노트는 트리트먼트의 해당 장면에서 근거를 가져왔습니다.

## 빌드

```bash
pip install python-pptx pillow
python3 build_deck_kr.py                     # → build/*.pptx
soffice --headless --convert-to pdf build/KAKKETSU_그것_컨셉레퍼런스_KR.pptx
```

`assets/` 는 원본 컨셉 이미지를 덱용으로 리사이즈 · 크롭한 것입니다.
빌드 로그의 `미사용:` 목록이 비어 있으면 모든 애셋이 정확히 한 번씩 쓰인 것입니다.

## 폰트

- 한글 · 한자 — `Malgun Gothic` (맥에서는 Apple SD Gothic Neo로 대체됨)
- 라틴 소제목 · 숫자 — `Cambria`

`build_deck_kr.py` 상단의 `KR`, `LAT` 상수만 바꾸면 교체됩니다.
