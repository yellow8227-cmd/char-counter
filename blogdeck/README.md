# ✍️ BLOGDECK · 블로그덱

키워드 고르기부터 발행 전 점검, 릴스 대본과 카드뉴스까지 한 자리에서.
**설치도 인터넷도 필요 없습니다** — `index.html`을 더블클릭하면 바로 열려요.

## 🚀 시작하기

**① 파일로 쓰기** — `index.html` 더블클릭. 끝.

**② 웹 주소로 쓰기**

```
https://yellow8227-cmd.github.io/char-counter/blogdeck/
```

주소만 있으면 폰이든 남의 컴퓨터든 그냥 열립니다.
적은 것은 **그 브라우저에만** 남고 어디로도 나가지 않습니다.
탭을 옮기면 주소 끝이 `#check` 처럼 바뀌니, 그 주소를 그대로 북마크해도 됩니다.

## 🧭 무엇을 하는 도구인가

블로그 글 하나를 **키워드 → 글 → 점검 → 다른 채널로 재활용**까지 밀고 가는 작업대입니다.
초보가 반복하는 실수는 정해져 있으니, 그걸 사람이 매번 기억하는 대신 **화면이 잡아 주게** 만들었습니다.

| 탭 | 하는 일 |
|---|---|
| **키워드** | 후보를 늘어놓으면 비율·판정이 자동으로. 롱테일 조합도 만들어 줍니다 |
| **글쓰기** | 종류별 단락 틀, AI에게 시킬 말, 이미지 프롬프트, 소재함 |
| **점검** | 다 쓴 글을 붙여 넣으면 고칠 자리를 짚어 줍니다 — **이 도구의 핵심** |
| **릴스** | 훅·본론·마무리를 초 단위로 나눈 대본과 촬영 목록 |
| **카드뉴스** | 장별 카피와 배경 이미지 프롬프트 |
| **자료실** | 체험단 50곳 · 제휴 19곳 · 도구 8곳 |

## 🔍 점검 — 제일 많이 쓰게 될 자리

제목·본문·해시태그를 붙여 넣고 사진/영상 수만 적으면 한 번에 훑습니다.

- **글자수** — 공백 포함/제외. 1,000자 미만이면 ×, 1,500자 넘으면 ✓
- **제목 키워드** — 없으면 ×, 3번 겹치면 × (누락 위험)
- **본문 키워드** — 목표 횟수와 견줍니다. 상위 1~5위가 쓴 횟수를 적으면 **그보다 한 번 더**로 목표가 잡힙니다. 35번 넘으면 ×
- **띄어쓰기 어긋남** — `애월 숙소`로 쓴다면서 본문엔 `애월숙소`로 붙여 쓴 자리를 찾아 줍니다. 이건 **다른 말로 읽혀서 세어 주지 않습니다**
- **해시태그** — 5개 넘으면 경고. 해시태그에만 있고 본문에 없는 말도 따로 짚어 줍니다
- **문단** — 한 번도 안 띄우고 7줄 넘게 이어진 자리를 몇 번째 줄인지까지
- **사진·영상** — 15장 / 10~15초 1개 기준

마지막에 **「반드시 고칠 것 N개 · 보면 좋은 것 N개」**로 정리됩니다. × 부터 처리하면 됩니다.

## 🎯 키워드 판정이 조금 특이한 이유

비율(문서수 ÷ 총조회수)만 낮으면 좋은 키워드일 것 같지만 아닙니다.

| 키워드 | 총조회수 | 문서수 | 비율 | 판정 |
|---|---:|---:|---:|---|
| 진도 쏠비치 | 51,050 | 34,023 | **0.67** | 문서수 많음 · 초보엔 벅참 |
| 진도 쏠비치 인피니티풀 | 3,650 | 7,617 | 2.09 | **노려볼 만함** ★ |

「진도 쏠비치」가 비율은 제일 낮지만, 초보가 **34,023편을 제치고** 1페이지에 낄 수는 없습니다.
그래서 **넘어야 할 문서수부터 걸러내고**, 남은 것들끼리 비율을 견줍니다.
「예시 채우기」를 누르면 위 표가 그대로 들어가니 직접 확인해 보세요.

## 📐 판정에 쓰는 숫자

전부 `index.html` 맨 위 `R` 객체에 모아 뒀습니다. **기준이 바뀌면 거기만 고치면** 화면 전체가 따라 바뀝니다.

```js
글자수_최소: 1000,   글자수_권장: 1500,
사진_권장: 15,       영상_권장: 1,        영상_길이: '10~15초',
본문키워드_기본목표: 6,  본문키워드_위험: 35,
제목키워드_주의: 2,      제목키워드_위험: 3,
해시태그_최대: 5,        문단_연속줄_주의: 7,
초보_총검색량: 3000,     초보_문서수: 20000
```

> ⚠️ 숫자는 그날그날 바뀝니다. 화면이 짚어 주는 건 **놓치기 쉬운 것**이고,
> 마지막 판단은 상위 1~5위 글을 직접 열어 보고 하세요.

## 🧱 만들어진 방식

- 단일 HTML 하나. 빌드도 의존성도 없습니다
- 밝은 화면 · 어두운 화면 둘 다
- 폰에서도 가로로 밀리지 않습니다 (키워드 표만 자기 칸 안에서 좌우로 움직입니다)
- 저장은 `localStorage` — 브라우저를 닫아도 남고, 서버로는 아무것도 가지 않습니다
