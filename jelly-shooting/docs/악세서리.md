# 악세서리 — 어떻게 씌우는가

캐릭터에 물건을 씌우는 규칙과, 여기까지 오면서 실제로 밟은 함정들.
캐릭터 그림이나 아이템을 손볼 때 먼저 읽으면 같은 길을 두 번 안 간다.

## 한 줄 요약

자리를 `R` 배수로 못 박지 않는다. **캐릭터를 한 번 실제로 그려 보고 머리를 재서** 그 위에
얹는다. 그래서 캐릭터 그림을 고쳐도 악세서리가 저절로 따라온다.

## 머리를 재는 세 가지 값 (`headShape`)

캐릭터마다 한 번만 재고 적어 둔다(256×256 로 그려서 알파를 훑는다).

| 값 | 뜻 | 쓰는 곳 |
|---|---|---|
| `crown` | **정수리** — 가운데(x=0)를 지나 이어진 폭이 0.45R 이상인 가장 위 줄 | 왕관·모자·정수리 물건, 헤드폰 띠 |
| `top[x]` | 열마다 위쪽 실루엣선 | 옆에 꽂는 물건 |
| `hw[y]` | 행마다 반너비 | 헤드폰 덮개 위치, 모자 브림 폭 |

`crown` 을 "가운데를 지나는 이어진 폭"으로 정의한 이유가 핵심이다.

- **열마다 가장 위 화소**로 잡으면 🧒 애교머리 한 올(정수리보다 0.3R 위)이 기준이 돼서
  모자가 공중에 뜬다.
- **두께(연속 화소 길이) 필터**로도 안 걸러진다. 애교머리는 가늘지만 **머리에 붙어 있어서**
  위에서 아래로 한 덩어리로 이어진다.
- 가운데를 지나는 폭을 보면 가느다란 것(애교머리)과 가운데를 안 지나는 것(🐰🐱 귀)이
  저절로 빠진다. 실제로 "모자를 얹을 수 있는 면"이 잡힌다.

## 물건마다 쓰는 자리가 다르다 (`ACC_WEAR` / `WEAR`)

전부 정수리에 올리면 헤드폰은 머리에 얹은 모자가 되고 막대사탕은 머리에 꽂은 꼬치가 된다.

| 스타일 | 물건 | 자리 |
|---|---|---|
| `crown` | ⭐💎🌙☁️❄️🔥🍄🧁🍰🎈🎁🪩🌻🎃🪐 · 기본 왕관 | 정수리에 얹는다 |
| `jelly` | `*jl` 젤리 | 정수리에 얹는다 — **직접 그린다** |
| `hat` | 🧢🎩 · 기본 모자 | 눌러쓴다 (정수리보다 아래) |
| `side` | 🦋🍀🐚🍁🍃🔔🐣🪷 · 기본 리본·꽃 | 머리 옆(오른쪽)에 꽂는다 |
| `ears` | 🎧 | 머리에 두른다 — **직접 그린다** |
| `mouth` | 🍓🍉🍦🍥🍭🍬🍡🍩🍪🥕🍒🍑🍇🧋🍧🍮🥐 | 입에 문다 + 혀를 내민다 |
| 얼굴 | 👓 안경 · 🕶️ 선글라스 | 눈에 쓴다 (`KIND_FX` 의 눈 위치에서 뽑는다) |

**먹는 것은 입에.** 딸기·수박·가마보코를 정수리에 올리면 머리에 꽂은 꼬치가 된다.

**혀는 입선 '아래'로.** 처음엔 `mouthY` 를 0.26R 로 잡아 혀를 0.29~0.46R 에 그렸는데
입선은 0.39~0.48R 이었다. 혀가 입 위에 있어서 "입이랑 떨어져 있다"고 보였다. `mouthY` 는
입선 가운데(대부분 0.44R, 🐰 0.36R, 🐶 0.50R)이고 혀는 그보다 0.10R 아래다.

크기는 **그 캐릭터 얼굴 폭**(`KIND_FX.sx`)에 맞춘다. 실루엣 폭을 쓰면 🐶 늘어진 귀·🐰 귀까지
머리 폭으로 세어 들쭉날쭉해진다. (예외: 🎧 는 머리카락까지 감싸니 실루엣 폭을 쓴다.)

정수리 물건을 얹을 때 **물건 폭 전체로 머리선을 재면 안 된다.** 🐰는 귀 끝에, 🐱은 귀 위에
올라앉아 공중에 뜬다 — 리본은 귀 **사이**에 놓여야 한다. 가운데 좁은 띠(`±0.20R`)로 잰다.

옆에 꽂는 물건은 그 위치의 머리선에 얹되, **얼굴 표면보다 0.14R 넘게 올라가지 못하게**
막는다(`sideLine`). 안 막으면 🐰 리본이 긴 귀 끝까지 타고 올라가 얼굴에서 0.77R 떠 있었다.

## 색은 어떻게 바꾸는가

이모지는 여러 색이 박힌 **그림 글자**라 `fillStyle` 로는 색이 안 바뀐다. 그래서 한동안
겉의 빛무리만 색이 바뀌었다("색을 골랐는데 안 바뀐다").

캔버스 `globalCompositeOperation='color'` 는 **색조·채도만 갈아끼우고 밝기는 남긴다.**
원래 음영·테두리·하이라이트가 그대로 살아서 "같은 모양의 다른 색 물건"이 된다.

```
① 이모지를 그린다
② op='color' + 고른 색으로 전체를 덮는다   ← 색조·채도 교체
③ op='destination-in' + 이모지를 다시 그린다 ← 혼합이 투명한 곳까지 덮으므로 글자 모양으로 자른다
```

결과는 (이모지, 색, 크기) 별로 적어 둔다(`accSprite`, 48개까지). 크기는 2px 단위로 묶는다.

## 직접 그리는 것 — 🎧 헤드폰 · 🎩 모자 · 🕶️ 선글라스

이모지로 안 되는 것이 있다.

**🎧** 정면 제품 사진이라 띠와 귀 덮개의 간격이 고정돼 있다. 덮개를 귀에 맞추려 키우면
띠가 머리보다 훨씬 커져 도넛을 뒤집어쓴 꼴이 되고, 띠를 머리에 맞추면 덮개가 얼굴
가운데로 들어온다. → 직접 그린다. 띠는 덮개에서 정수리를 넘어 덮개까지 가는 **타원 호**,
덮개는 귀 높이 양옆에 타원.
띠를 실루엣 윗선을 따라가게 했더니 🐰🐱은 귀 모양을 타고 올라가 **'M자'** 가 됐다 —
띠는 귀와 상관없이 머리를 넘어가는 것이다.

**🎩** 예전에는 납작한 네모 두 개였다. 브림이 1.0R 폭밖에 안 돼서 2R 짜리 머리 위에
걸터앉은 꼴(머리 폭의 39~46%)이었고 그게 "떠 있는 느낌"의 원인이었다. → 브림을 머리
폭까지(79~98%) 넓히고 정수리보다 0.19R 아래로 내렸다. 브림 아래 그늘이 있어야 닿아 보인다.

**🕶️** 렌즈를 반투명으로 깔면 눈이 살짝 비친다 — 악세서리는 얼굴보다 나중에 그려지므로
아래 눈이 배어 나온다. 유리 반사가 없으면 눈을 색종이로 가린 것처럼 보인다.

## 빛무리는 '있는 줄도 모르게'

처음엔 리본만큼 큰 덩어리를 깔았더니 머리에 분홍 풍선을 하나 더 얹은 꼴이 됐다
(악세서리+빛무리 1.43R). 지금은 0.67R — 빛무리는 **물건보다 작게**, 중간 정지점을 넣어
가장자리가 테두리로 보이지 않게.

옅은 물건(☁️)이 흰 캐릭터 위에서 사라지지 않게 그늘 한 겹, 머리에 닿는 그늘로 '얹혀
있다'는 느낌.

## 공방에 무엇을 넣을지

- **기본 악세서리(무료)와 겹치는 것은 넣지 않는다.** 리본🎀·왕관👑·꽃🌸·모자🎩🧢·안경👓·
  선글라스🕶️·뿔😈 은 프로필에서 공짜로 고를 수 있다. 공방은 3,000코인부터 시작하니
  '돈 내고 만들 만한 것'만 둔다.
- **색을 갈아끼우면 정체를 잃는 것은 빼라.** `color` 혼합은 색조·채도를 한 색으로 바꾸므로
  '여러 색이 곧 그 물건'인 것(🌈무지개·🐞무당벌레)은 그냥 덩어리가 된다.
- **가느다란 것도 빼라.** 🪄요술봉·🧷핀·🫧방울은 작게 그리면 뭔지 안 보인다.
- **넣기 전에 실제로 그려서 확인하라.** 폰트에 글자가 없으면 빈 칸이 된다. 스모크 검사가
  잉크 800화소 미만이면 잡아낸다.
- 쓰는 자리(머리 위·옆·입·두르기)로 묶어서 보여준다. 40개를 한 줄로 늘어놓으면 뭘 고르는지
  알 수 없다. `#caEmojis` 는 `.mini`(flex·가운데 정렬)이므로 묶음일 때 `display:block` 으로
  덮어야 라벨이 왼쪽에 붙는다.

지금 42종 · 악세서리 색 20가지 · 캐릭터 색 18가지.

## 검사 (`tools/` 밖 · 스모크 검사에 들어 있다)

눈으로 보면 "대충 위에 있네" 하고 넘어가므로 화소로 잰다. 새로 넣을 때는 **예전 코드로
되돌려 실패하는 것을 반드시 확인한다.** 실패하지 않는 검사는 검사가 아니다.

| 검사 | 되돌리면 |
|---|---|
| 정수리 물건이 캐릭터마다 머리선을 따라간다 (흔들림 ≤0.12R) | 0.31R 어긋남 |
| 옆에 꽂는 물건이 얼굴 옆에 붙어 있다 (얼굴 표면 −0.28R~+0.22R) | 🐰 0.77R 위로 뜸 |
| 악세서리 크기가 얼굴 폭을 따라간다 (편차 ≤10%) | 전부 68px 고정, 편차 20% |
| 아이템 색을 바꾸면 아이템 자체가 바뀐다 (속살 평균색 거리 ≥60) | 거리 0 |
| 🎧 는 얼굴을 0화소도 안 가리고 덮개가 머리 옆으로 나온다 | 덮개가 머리 안에 숨음 |
| 🍭 는 입 높이에 물려 있고 혀가 나온다 | 머리 위에 꽂힘, 혀 0화소 |
| 모자 브림이 머리 폭의 ≥78% 이고 머리에 겹친다 | 46% |
| 선글라스 렌즈로 눈이 비친다 (같은 줄 밝기 차 30~95) | 불투명 렌즈 12 |
| 혀가 입선 아래끝보다 아래로 나온다 | 혀 가운데 0.36R vs 입선 0.48R |
| 머리 위 젤리는 속이 비친다 (머리 색 비침 ≥12) | 불투명 젤리 4.8 |
| 공방 목록이 기본과 겹치지 않고 빈 칸이 없다 | 겹치면 목록으로 알려준다 |

### 검사를 만들 때 밟은 함정

- **알파 차이로 아이템을 찾으면 안 된다.** 🐶 리본은 이미 불투명한 귀 위에 놓이므로 알파가
  하나도 안 늘어난다("안 그려짐"으로 나왔다). 흰 바닥을 깔아 전부 불투명하게 만든 뒤
  **색이 크게 달라진 곳**(거리 >70)을 아이템으로 본다. 그러면 빛무리(≈45)·그늘(≈25)도
  저절로 걸러진다.
- **이모지 폰트는 `measureText` 로 모든 글자에 같은 상자를 답한다.** 잉크 크기는 직접
  그려서 재야 한다(`accInk`).
- **'파묻힘'은 화소로 정의할 수 없다.** 악세서리는 늘 머리 위에 덧그려지므로 가려지지
  않고, 🐶 리본처럼 실루엣 안(귀 위)에 있어도 색이 달라 잘 보인다. 실제 위험(얼굴을
  덮는 것)만 본다.
- **머리선 기준을 '가장 위 화소'로 잡으면 안 된다.** 👧 뒷머리처럼 가느다란 조각이 훨씬
  위까지 뻗어 있으면, 앞머리 위에 떠 있는 물건도 '닿았다'고 나온다.
- **렌즈 전체를 뭉쳐 평균 내면 안 된다.** 위아래 그라데이션의 밝기 차를 "눈이 비친다"로
  잘못 읽어서 **불투명 렌즈도 통과했다.** 같은 줄끼리 비교해야 한다. 그리고 문턱은 실측으로
  정한다 — 불투명 렌즈도 유리 광택 때문에 12는 나온다.
- **렌더 결과를 재사용하지 않으면 검사가 몇 분씩 걸린다.** 같은 차림새를 몇 번이고 다시
  그리고 있었다(`ACC_CACHE`).
- **혀를 사탕과 같이 그려 놓고 재면 안 된다.** 사탕 화소가 가운데 띠에 섞여 혀의 위치를
  흐린다. `drawTongue` 만 따로 그려서 재라(t=0 이면 통통·눌림 변형이 없다).
- **입선 기준은 '위끝'이 아니라 '아래끝'.** 위끝으로 재면 🐻는 코가 잡혀(코가 입보다 훨씬
  위에 있다) 기준이 통째로 어긋난다.
- **반투명을 잴 때는 '뒤에 무엇이 있는 화소'만 세라.** 젤리는 대부분 머리 위 허공에 있어서
  전체를 세면 머리 색이 비칠 수 있는 화소가 희석돼 불투명해 보인다(38 → 6).

## 성능

머리 재기·잉크 크기·색칠 결과를 모두 적어 두므로 게임 속도에 영향이 없다.
한 프레임 1.1~1.4ms (젤리 20개).

## 젤리곰 (`*jl`) — 왜 슬라임에서 곰으로 바꿨나

처음엔 둥근 반투명 방울(슬라임)로 그렸다. "너무 별로"였다.
젤리다움은 '속이 비치는 것'만으로는 안 된다 — **실루엣이 정체성**이다. 하리보 곰은
귀·팔·다리가 붙은 그 모양이 곧 그 물건이다. 둥근 방울은 그냥 젤 덩어리로 보인다.

지금은 머리·귀·몸통·팔·다리를 한 path 로 잇고, 눌린 눈·코를 아주 작게 찍는다.
작아도 눈·코가 있어야 곰으로 읽힌다. 크기는 `nf.sx*R*0.20` 기준 — 작고 귀엽게.

| 물건 | 자리 |
|---|---|

| 귀마개 | 얇은 띠 + 둥근 돌기를 둘러 붙인 푹신한 덮개 |
| 무선 이어폰 | **그 캐릭터의 귀 안쪽**(`EAR_PT.in`) + 아래로 내려오는 대 |

### 귀는 종류마다 완전히 다른 곳에 있다

무선 이어폰·귀걸이를 '얼굴 옆에서 제일 넓은 곳'에 붙였더니 🐱🐰 처럼 귀가 **머리 위**에 있는
애들은 볼에 달린 꼴이 됐다(토끼는 귀에서 1.12R 떨어져 있었다). 귀를 그린 좌표에서 두 점을
뽑아 `EAR_PT` 에 적어 두었다 — `in`(귀 안쪽·무선 이어폰), `lobe`(귓불·귀걸이).

| | 귀 모양 | in | lobe |
|---|---|---|---|
| 🐱 | 머리 위 삼각귀 | 0.63,−0.87 | 0.85,−0.50 |
| 🐶 | 옆으로 늘어진 귀 | 1.02,−0.34 | 0.86, 0.56 |
| 🐰 | 위로 솟은 긴 귀 | 0.51,−1.24 | 0.76,−0.64 |
| 🐻 | 머리 위 동그란 귀 | 0.80,−0.84 | 0.95,−0.54 |
| 🧒👧 | 옆에 붙은 사람 귀 | 0.90, 0.04 | 0.90, 0.17 |

**이 값은 '그려 보고 잰' 것이다.** 처음엔 귀 그리는 코드의 좌표에서 유추했는데 동물은 전부
어긋났다(🐰는 귀에서 1.12R). 귀는 몸보다 **먼저** 그려져 안쪽이 몸에 덮이므로, 코드에 적힌
중심점은 '보이는 귀'의 중심이 아니다. 보이는 귀 = **몸 타원 바깥에 칠해진 곳** 이고, 그 중심이
`in`, 아래·바깥 끝이 `lobe` 다. 잴 때는 반짝임(±1.0,±0.3)과 🐻의 볼 모양이 섞이지 않게
귀가 있는 구역만 잘라야 한다.

**머리 위를 지나는 띠는 `crownArc` 를 쓴다.** 실루엣 윗선을 따라가면 🐰🐱은 귀 모양을 타고
올라가 'M자'가 된다(헤드폰에서 배운 것). 비니·머리띠·화관이 같이 쓴다.

**칩 그림은 자동으로 잘라 맞춘다.** 물건마다 놓이는 자리가 달라서(정수리 위 / 귀 옆 /
턱 밑) 한 좌표로는 담을 수 없다. 크게 한 번 그려 칠해진 곳의 상자를 재서 칩에 맞춘다.
한 쌍인 것(무선 이어폰·귀걸이)은 `half:true` 로 오른쪽만 크게 보여준다 — 양쪽을 다 담으면
알이 너무 작아진다.


## 사람 머리 모양 (머리카락이 곧 인상이다)

색만 갈아끼울 수 있으면 사람 여섯 명이 다 같은 얼굴로 보인다. 그래서 머리 모양을 넷으로
나누고, 기본만 공짜로 두었다.

| 머리 모양 | 값 | 무엇이 그 머리를 그 머리로 만드나 |
|---|---|---|
| 기본 🙂 | 0 | 🧒 사이드 뱅 + 정수리 뭉치 · 👧 긴 머리채 + 머리끈 방울 |
| 짧은머리 ✂️ | 1,500 | 얼굴 바깥으로 나오는 머리가 거의 없다 + 밑단이 술처럼 처진다 |
| 단발 💇 | 2,500 | **끝을 곧게 자른 선** + 일자 앞머리 |
| 땋은머리 🧶 | 3,500 | 점점 작아지는 덩어리를 **엇갈리게** 겹친 갈래 + 가운데 가르마 + 머리끈 |

그리는 순서가 셋으로 나뉘어 있다. 한 덩이로 그리면 앞머리가 얼굴 뒤로 들어가거나
머리끈이 얼굴에 깔린다.

- `hairBack` — 얼굴보다 **먼저**. 뒷머리·머리채·땋은 갈래
- `hairFront` — 얼굴 **다음**. 앞머리(이마를 덮어야 한다)
- `hairTail` — 맨 마지막. 머리끈 방울·정수리 뭉치

### 밟은 함정

**톱니로 그린 짧은머리는 왕관으로 보였다.** 직선으로 지그재그를 넣으니 각이 서서 종이
왕관이 됐다. 아래로 처지는 곡선 술 다섯 개로 바꿨다.

**머리끈은 결국 없앴다.** 갈래 끝(1.27R)에 두니 매달린 알약처럼 보였고, 끝보다 위(0.98R)로
올려도 "왜 여기 붙어 있지" 싶은 물건이었다. 갈래·머리채 **모양만으로** 충분히 읽힌다.
👧 기본 머리의 방울 두 개도 같이 뺐다(같은 물건이라 같은 소리를 들었다).

**사람 귀는 얼굴 밖으로 삐져나와야 한다.** 귀를 얼굴 반너비(🧒 0.96R · 👧 0.94R) **안쪽**
0.90R 에 두었더니 살색끼리 이어져 실루엣에 아무 변화가 없고, 안쪽 그늘만 남아 **볼에 붙은
살덩이**로 보였다(한 줄을 화소로 떠 보니 0~1.11R 이 전부 살색이었다). 얼굴 테두리에 살짝만
걸치게 `sx + 귀반너비×0.72` 로 밀어냈다 — 🧒 1.04R · 👧 0.98R. `EAR_PT` 도 다시 재서
🧒 in 1.04,0.05 / lobe 1.00,0.25 · 👧 in 1.01,0.07 / lobe 1.00,0.25 로 고쳤다.

**검사가 '안 그려졌다'고 한 건 색이 겹쳤기 때문이었다.** 귀걸이를 새 귓불로 옮기니 귀걸이가
분홍 머리카락 위에 걸렸고, 검사용 악세서리 색도 분홍이라 색 차이가 문턱(70)을 못 넘어
88화소로 셌다. 검사에서 쓰는 악세서리 색을 파랑(`#4a6cff`)으로 바꿨다 — 어디에 걸리든
눈에 띄는 색으로 재야 한다.

**땋은 갈래가 크면 애벌레가 된다.**

**땋은 갈래가 크면 애벌레가 된다.** 반지름 0.30R 로 네 덩이를 겹쳤더니 공을 꿴 꼴이었다.
0.25R 부터 0.13R 까지 다섯 덩이로 줄이고, 홀수 덩이만 `shade(col,-16)` 로 어둡게 하고
좌우로 0.34 라디안씩 엇갈리게 돌려야 '땋은 결'로 읽힌다.

**악세서리 자리는 머리 모양을 따라가지 않는다.** `headShape` 는 종류(kind)별로 한 번만
재고 기본 머리로 그린다. 재 보니 정수리 높이 차이가 최대 0.031R(−1.188 ~ −1.219)라서
모자·왕관이 어긋나 보이지 않는다. 다만 **최대 반너비는 땋은머리가 1.30R** (기본 1.11~1.19R)
이라, 옆에 걸리는 물건은 갈래 안쪽에 놓인다 — 갈래는 귀보다 아래로 흐르니 겹치지 않는다.

## 사람 얼굴이 머리색에 물들면 안 된다

얼굴은 젤리라서 반투명(알파 0.80~0.95)인데, 그 **뒤에 뒷머리를 깔아 두었다**. 그래서
초록 머리는 얼굴이 올리브빛, 갈색 머리는 흙빛이 됐다. 볼 화소가 머리색에 따라 최대
**14.6** 만큼 흔들렸다(rgb 거리). 사람만 살색(`#ffe8d6`) 밑칠을 먼저 깔고 그 위에 젤리
그라데이션을 얹어 **0.0** 으로 만들었다. 동물은 몸 색 = 고른 색이니 배어 나와도 티가
안 나서 그대로 둔다.

## 귀 비침 (광택이 아니라 순서 문제였다)

귀는 몸보다 **먼저** 그린다(그래야 밑동이 머리에 묻힌다). 그런데 몸이 반투명이라
머리 안에 가려져야 할 귀가 배어 나와, 얼굴 안쪽에 귀 테두리 '선'이 보였다. 몸 타원
안쪽을 구멍으로 잘라 두고 귀를 그려서(`rect` 시계 방향 + `ellipse(...,true)` 반시계 →
구멍) 바깥에 나온 부분만 남겼다.

재는 법: 얼굴 안에서 **가로로 붙은 두 화소의 색이 3 넘게 튀는 곳**을 센다. 매끈한
그라데이션이면 0에 가깝고, 선이 있으면 수십 개가 나온다.

| | 고침 뒤 | 되돌려 재면 |
|---|---|---|
| 🐱 | 0 | 37 |
| 🐻 | 10 | 117 |
| 🐰 | 0 | 113 |
| 🐶 | 164 | 222 |

🐶 의 164는 흰 주둥이 경계라서 원래 있던 것이다(창을 좁혀도 남는다).

## 색을 갈아도 '그 색이라서 그 물건인' 곳은 남긴다

`'color'` 혼합은 그림 **전체**를 한 색으로 덮는다. 그래서 🍓 꼭지의 초록, 🍉 껍질,
🍇🍒🥕 의 잎, 🍰 위의 딸기가 죄다 한 덩어리 색이 됐다(사용자가 잡아낸 것).

고친 방법: 색조(hue)를 15°씩 스물넷으로 나눠 **채도×알파로 넓이를 재고**, 가장 넓은
덩어리(=몸통)만 새 색으로 갈고, 몸통 색조와 **45° 이상** 벌어진 곳은 원래 색으로
되돌린다. 무채색(흰 하이라이트·검은 테두리, 채도 0.24 미만)은 예전처럼 물들인다 —
거기까지 남기면 음영이 원래 색으로 되돌아가 물건이 두 색으로 갈라진다.

원래 색이 남은 비율(파랑으로 갈았을 때):

| 여러 색인 것 | | 한 색인 것 | |
|---|---|---|---|
| 🍉 | 43% | 🎈 | 3% |
| 🍒 | 38% | ⭐ | 0% |
| 🍓 | 32% | 💎 | 0% |
| 🥕 | 17% | | |
| 🍇 | 10% | | |

고치기 전에는 전부 **0%** 였다.
