# ⚔️ 실시간 젤리 던지기 대전 — 기획서

> **이 문서가 있는 이유**
> 이 기획은 채팅방에서 이야기하다 기록이 사라진 적이 있다.
> 그래서 코드와 같은 저장소에 남긴다. 대화가 없어져도 이 파일은 남는다.

---

## 1. 한 줄 요약

**두 사람이 각자 자기 화면에서 젤리를 터뜨리다가, 잘 터뜨릴수록 상대 화면에 젤리를 흩뿌려 보낸다.
받은 쪽은 그걸 실시간으로 터뜨려야 한다. 젤리가 위에서 아래로 내려오는 건 지금과 똑같다.**

기존 `도전장`(같은 판을 따로따로 플레이해 점수 비교)과 다르다. 이건 **동시에, 서로 간섭하며** 하는 대전이다.

---

## 2. 핵심 규칙

### 판의 구조

- 두 사람 모두 **자기 화면**을 갖는다. 화면은 지금과 같다 — 젤리가 위에서 아래로 내려온다.
- 기본 젤리 생성은 **방장 시드를 공유**해서 양쪽이 똑같이 나온다 (`runSeed`). 실력 차이만 남긴다.
- 그 위에 **상대가 던진 젤리**가 추가로 쏟아진다. 이때부터 두 화면은 달라진다 — 그게 대전의 본질이다.

### 던지기

| 항목 | 값(초안) |
| --- | --- |
| 게이지 획득 | 좋은 젤리 1개 터뜨릴 때 `+1 × 콤보배수` |
| 던지기 발동 | 게이지 10 → 젤리 3개 / 게이지 25 → 젤리 5개 + 폭탄 1개 |
| 발동 방식 | **수동** (플레이어 아래 던지기 버튼) — 언제 쏟아붓느냐가 전략 |
| 던져진 젤리 | 상대 화면 **맨 위**에서 등장, 낙하 속도는 받는 쪽 난이도 기준 |
| 놓쳤을 때 | 일반 젤리와 동일하게 목숨 감소 |

- **폭탄 던지기**는 게이지를 많이 먹는 특수기로 둔다. 싸게 만들면 서로 폭탄만 던져서 게임이 망가진다.
- 던져진 젤리는 **보라색 테두리 + `닉네임 →` 라벨**로 구분한다. 내 젤리인지 상대가 보낸 건지 한눈에 보여야 한다.

### 승패

- 목숨이 먼저 0이 되는 쪽이 **패배**.
- 제한시간(2분) 안에 아무도 안 죽으면 **점수 높은 쪽 승리**, 같으면 무승부.
- 상대가 5초간 응답 없으면 **연결 끊김** — 진행 중이면 남은 쪽 부전승, 시작 직후면 무승부 처리.

## 3. 네트워킹 설계

### 판 전체를 동기화하지 않는다

각자 자기 판을 자기 기기에서 굴린다. 주고받는 건 **던진 젤리와 상태 요약**뿐이다.

판 전체를 동기화하면 60fps로 젤리 좌표를 계속 보내야 하고, 모바일 네트워크에서 반드시 깨진다.
반대로 "던지기"만 주고받으면 **200~300ms 지연은 체감되지 않는다** — 젤리가 위에서 아래로
내려오는 데 2~3초가 걸리기 때문에, 도착하는 순간 맨 위에 넣어주면 자연스럽다.
**젤리가 아래로 내려오는 구조 자체가 지연에 관대하다.** 이 설계의 핵심 이유다.

### 채널

Supabase Realtime broadcast. 테이블 없이 채널만 쓴다.

```
채널명: jelly:room:<6자리 코드>
```

### 메시지

| type | 보내는 시점 | 내용 |
| --- | --- | --- |
| `hello` | 입장 직후 | `{name, char:{kind,color,acc,accColor}, ver}` |
| `seed` | 방장만, 상대 입장 시 | `{seed, mode, timeLimit}` |
| `ready` | 캐릭터 로딩 끝 | `{}` |
| `start` | 방장만 | `{atMs}` — 카운트다운 기준 시각 |
| `throw` | 던지기 버튼 | `{items:[{x,r,color,face,shape,vy,bomb}], n}` |
| `stat` | 0.5초마다 | `{score, lives, combo, level}` |
| `over` | 목숨 0 또는 시간 종료 | `{score, reason:'dead'\|'time'}` |
| `bye` | 화면 이탈 | `{}` |

- `throw`의 `items`는 **보내는 쪽에서 좌표까지 확정**해서 넘긴다. 받는 쪽이 임의로 만들면
  "왜 저기서 나와?" 하는 억울함이 생긴다. 보낸 쪽 화면에도 "이렇게 보냈다"는 미리보기를 띄운다.
- `stat`은 상대 HUD 표시용. 유실돼도 게임에 영향 없으므로 재전송하지 않는다.

### 동시 시작

방장이 `start {atMs}`를 보내고, 양쪽이 **각자 3-2-1 카운트다운**을 돌린다.
시계 차이는 `hello` 왕복 시간으로 대략 보정한다. 완벽히 맞출 필요는 없다 —
던지기 타이밍이 조금 다른 건 대전에서 문제가 되지 않는다.

```

│ ⭐1240  🔥x5  Lv.7  ❤️❤️🤍   │  내 HUD (기존)
│ ┌───────────────────────┐   │
│ │ 🙋 친구  ⭐980  ❤️❤️❤️  │   │  상대 미니 HUD (신규)
│ └───────────────────────┘   │
│                             │
│     🟣 ← 상대가 던진 젤리     │  보라 테두리 + 닉네임 라벨
│   🍡      🍡                │
│        🍡                   │
│                             │
│   ▓▓▓▓▓▓░░░░ 던지기 게이지    │  신규
│         [🎯 던지기]          │  신규 (수동 발동)
│           (๑˃̵ᴗ˂̵)            │  플레이어
└─────────────────────────────┘
```

- 상대 HUD는 **작게, 위쪽에**. 내 판을 가리면 안 된다.
- 던지기 버튼은 아이템 바(왼쪽 아래)와 **반대쪽(오른쪽 아래)**에 둔다. 급할 때 오폭하면 안 된다.
- 젤리를 받은 순간 화면 위쪽이 **보라색으로 번쩍** + `친구가 5개 던졌어요!` 토스트.

## 5. 지금 코드에 붙일 자리

| 할 일 | 위치 |
| --- | --- |
| 던져진 젤리 생성 | `spawnJelly()` 옆에 `spawnThrown(items)` 추가 |
| 젤리 구분 필드 | `jellies` 항목에 `from:'foe'` 추가 |
| 던져진 젤리 표시 | `drawJelly()`에 `from==='foe'` 테두리 분기 |
| 게이지 적립 | `popGood()` 안에서 `throwGauge += combo` |
| 상태 전송 | `update()`에서 30프레임마다 `stat` |
| 대전 분기 | `startGame()`에 `netMode` 추가 (`battleMode`와 별개) |
| 시드 공유 | 이미 있음 — `runSeed` / `mulberry32` / `srnd()` 그대로 사용 |

`srnd()`는 **젤리 생성 전용**이라는 규칙을 반드시 지켜야 한다.
플레이어 조작이나 이펙트가 이걸 소비하면 두 사람의 기본 판이 갈라진다.

## 6. 만드는 순서

1. **방 만들기 / 참가** — 6자리 코드, Realtime presence로 두 명 모였는지 확인
2. **카운트다운 동시 시작** — `seed` → `ready` → `start`
3. **상대 HUD** — `stat` 브로드캐스트만 붙이면 바로 "같이 하는 느낌"이 난다
4. **게이지 + 던지기** — 여기까지 오면 게임이 성립한다
5. **폭탄 던지기 · 승패 화면**
6. **연결 끊김 처리** — 5초 무응답 판정

3번까지만 해도 재미가 확인된다. **4번을 서둘러 4번부터 만들지 말 것.**
