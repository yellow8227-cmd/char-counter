# 게임을 등록할 때 시비 걸릴 것이 없는지 (저작권·상표 점검)

한 줄 요약: **지금 올려도 걸릴 만한 것은 없다.** 다만 (1) 폰트 두 개의 재배포 조건과
(2) 게임 이름은 사람이 직접 확인해야 한다. 이 컨테이너는 밖으로 나가는 인터넷이 막혀
있어서 **상표 검색·라이선스 원문 확인을 여기서 할 수 없다** — 아래 표에 '직접 확인'으로
표시해 두었다.

## 실제로 고친 것

| 무엇 | 왜 | 어떻게 |
|---|---|---|
| 악세서리 이름 '에어팟' | AirPods 는 애플 상표다. **돈 받고 파는 아이템 이름**으로 쓰면 상표 문제가 가장 잘 생기는 자리다 | 이름을 **'무선 이어폰'** 으로 바꿨다. 그림은 원래부터 직접 그린 일반적인 무선 이어폰 모양이라 그대로 둔다 |
| 주석에 있던 '하리보' | 주석도 `index.html` 에 그대로 실려 배포된다 | '가게에서 파는 곰 젤리', '곰 젤리' 로 바꿨다. 곰 모양 젤리 자체는 특정 회사 것이 아니다 |

`grep -c "하리보\|에어팟" index.html` → **0**

## 남아 있는 상표 이름 — 전부 정상적인 쓰임

| 어디 | 무엇 | 왜 괜찮나 |
|---|---|---|
| `<meta name="apple-mobile-web-app-*">`, `apple-touch-icon` | 애플이 정한 **표준 속성 이름** | 이 이름을 안 쓰면 기능이 안 된다. 이름을 쓰는 것 말고 다른 방법이 없는 경우다 |
| `'Apple SD Gothic Neo'` (CSS 폰트 이름) | 아이폰에 이미 깔린 폰트를 **가리키는** 이름 | 폰트를 싣는 게 아니라 있으면 쓰라는 것이다. 폰트 파일은 배포하지 않는다 |
| "카카오톡 같은 앱 안에서 열었다면 Chrome·Safari로 다시 열어보세요" | 접속 문제 **안내문** | 제품을 지목해 설명하는 것뿐이고, 우리 게임이 카카오 것처럼 보이게 하지 않는다 |
| '아이폰 안전영역' (주석) | 기기를 가리키는 말 | 같음 |

## 그림·글꼴·소리

**이모지 — 우리가 배포하는 파일에 글자 그림이 들어 있지 않다.**
게임 화면의 이모지는 실행할 때 **보는 사람 기기의 폰트**로 그린다(`fillText`).
우리가 이모지 글꼴을 실어 보내지 않으니 재배포가 아니다.

다만 `og.png` 와 아이콘 배너에는 이모지(🍡 등)가 **그림으로 구워져** 들어간다.
그 그림을 만든 곳(이 컨테이너)에 깔린 이모지 폰트는 하나뿐이다:

```
/usr/share/fonts/truetype/noto/NotoColorEmoji.ttf : Noto Color Emoji
```

Noto Color Emoji 는 **SIL Open Font License 1.1** 이다. OFL 은 '폰트 소프트웨어'의
재배포를 규율하고, 그 폰트로 만든 **문서·그림**에는 제약을 두지 않는다. 그래서
`og.png` 를 배포하는 것은 문제가 없다. (애플 이모지로 구운 그림이 아니다 — 애플
이모지는 재배포가 막혀 있으니 이 구분이 중요하다.)

**폰트 두 개 — 직접 확인이 필요하다.**

```
fonts/Griun_Donguri-Rg.ttf         (그리운 동구리)
fonts/Griun_NoltoTAENGGU-Rg.ttf    (그리운 놀토탱구)
```

- 이 두 파일은 **아직 저장소에 없다**(넣으면 글씨가 더 예뻐지고, 없어도 게임은 돈다 —
  `sw.js` 는 없는 파일을 건너뛰게 되어 있고 CSS 는 `font-display:swap` 이라 대체 글꼴로 뜬다).
- 넣기 전에 **배포처의 라이선스 원문에서 '웹폰트(@font-face) 서버 탑재 허용' 과
  '상업적 이용' 두 줄을 확인**해야 한다. 무료 배포 한글 폰트는 대부분 둘 다 허용하지만,
  "웹폰트로는 쓸 수 없음" 이라고 못 박은 것도 있다.
- 확인이 안 되면 **넣지 말고** 지금처럼 기기 기본 글꼴로 두면 된다. 그 편이 안전하다.

**소리 — 라이선스가 필요한 파일이 없다.** 효과음·배경음을 전부 `AudioContext` 로
그때그때 만들어 낸다(`.mp3`/`.ogg`/`.wav` 파일 0개). 남의 음원을 쓰지 않는다.

**그림 — 전부 코드로 그린다.** 캐릭터·젤리·악세서리·배경에 남의 이미지 파일이 없다.
`og.png`·아이콘도 우리 코드로 만든 것이다.

## 게임 내용 — 남의 게임을 베낀 데가 있나

없다. 규칙(웃는 젤리를 쏘고 화난 젤리를 피한다 · 던지기 대전 · 4명 던전)은 흔한
아케이드 규칙이고, 아이디어 자체에는 저작권이 없다. 캐릭터는 고양이·강아지·토끼·곰·
사람 같은 **일반적인 동물·사람 얼굴**이라 특정 캐릭터를 떠올리게 하지 않는다. 남의
캐릭터 이름·대사·음악·이미지를 쓴 곳이 없다.

## 이름 — 직접 확인

- 게임 이름 **젤리슈팅 / Jelly Shooting**. 둘 다 흔한 낱말의 조합이라 상표로 독점되기
  어렵지만, **등록 상표가 이미 있는지는 특허청 키프리스(kipris.or.kr)에서 직접
  검색**해야 한다(여기서는 인터넷이 막혀 검색을 못 했다).
- 앱 스토어에 올릴 거면 같은 이름의 앱이 있는지도 같이 보면 좋다.

## 이건 저작권이 아니라 보안이지만 같이 봐 두면 좋은 것

`index.html` 에 Supabase 주소와 **공개 키**(`sb_publishable_...`)가 들어 있다.
이건 원래 브라우저에 노출되는 키라서 새는 것 자체가 문제는 아니다. 대신 **표(row)
보안 정책(RLS)이 켜져 있어야** 남이 남의 점수를 지우거나 고칠 수 없다.
`docs/배포하기.md` 의 SQL 부분을 볼 때 같이 확인해 두면 좋다.
