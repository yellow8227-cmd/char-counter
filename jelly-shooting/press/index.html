게임 방법

기본떨어지는 젤리를 누르면 터져요. 바닥에 닿으면 목숨이 하나 줄어요.
콤보쉬지 않고 이어 터트리면 점수 배수가 올라가요. 폭탄(😡)은 누르면 안 돼요.
아이템하트팩 · 슬로우 · 폭탄청소 · 2배 점수 · 자석. 창작소에서 만들어 들고 들어가요.
방해 주사위대전에서는 게이지를 모아 지그재그 · 안개 · 스피드업 같은 방해를 상대에게 던져요.
대전 참여방을 만들면 4자리 코드가 나와요. 친구가 그 코드를 넣으면 같은 방에서 시작해요.

HTML 파일 하나 · 엔진 없이 캔버스 직접 그리기 · 실시간은 Supabase Realtime.

파일 하나로 끝나는 게임

index.html 안에 화면·소리·통신·저장이 다 들어 있어요. 정적 호스팅에 올리면 그게 배포예요.

엔진 없이 캔버스로

젤리·캐릭터·표정·승패 애니메이션까지 좌표로 직접 그려요. 캐릭터 6종의 팔·다리·꼬리 비율을 종마다 따로 잡았어요.

실시간 대전

Supabase Realtime 브로드캐스트로 방·점수·방해·관전을 주고받아요. 진 사람은 이긴 사람 화면을 관전할 수 있어요.

흔들리지 않는 화면

아이폰 노치·홈바(safe-area)와 판 크기를 못 박아 두는 규칙을 만들어, 아이템 칸이 줄어도 판이 커지지 않아요.

스스로 검사하는 도구

화면 넘침·작은 버튼·2인/4인 통신·AI 난이도까지 자동 검사 도구를 같이 만들었어요. 이 페이지의 스크린샷과 영상도 스크립트가 진짜 게임을 플레이해서 만든 거예요.

난이도는 실측으로

AI가 2분에 몇 점을 내는지, 젤리를 몇 개 잡는지를 재서 4단계를 잡았어요. “사람이 이길 수 있는 연습 상대”가 목표였어요.

“아이랑 같이 할 게임을 만들다가, 친구랑 붙을 수 있는 방까지 붙었어요. 점수보다 같이 웃는 장면을 남기고 싶어서 이기면 춤추고 지면 분해하는 그림을 넣었습니다.”

faq

자주 묻는 것

앱을 설치해야 하나요?

아니요. 주소만 열면 바로 됩니다. 홈 화면에 추가하면 앱처럼 전체화면으로 열리고, 오프라인에서도 혼자 하기는 돌아가요.

친구랑 어떻게 같이 하나요?

실시간 던전이나 던지기 게임에서 방을 만들면 4자리 코드가 나와요. 친구가 코드를 넣으면 같은 방에서 시작합니다. 2~4명까지 가능해요.

공짜인가요? 광고가 있나요?

무료이고 광고가 없어요. 게임 안 코인은 플레이로만 모아요(현금 결제 없음).

아이가 해도 괜찮나요?

폭력·과금 요소가 없고, 채팅은 방 안 한마디와 말풍선 정도예요. 난이도 순한맛에서 시작하면 쉬워요.
