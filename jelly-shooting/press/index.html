놀이 방법 3가지

혼자여도 재미있고, 둘이면 더 재미있게

떨어지는 젤리를 손가락으로 톡. 연달아 터지면 콤보가 붙고, 폭탄은 피해야 해요.

혼자 하기 — 딱 3분

순한맛부터 핵불닭까지 난이도 네 단계. 잠깐 비는 시간에 한 판, 오늘의 최고 기록에 도전해요.

아이템 다섯 가지를 들고 들어갈 수 있어요 — 하트팩으로 목숨을 늘리고, 슬로우로 시간을 벌고, 폭탄청소·2배 점수·자석으로 위기를 넘겨요.

실시간 던전 — 2~4명이 같은 판에서

방을 만들면 네 자리 코드가 나와요. 친구가 코드를 넣으면 같은 판에서 동시에 시작. 마지막까지 살아남은 사람이 우승이에요.

게이지를 모아 상대에게 방해를 던질 수 있어요 — 지그재그로 젤리를 흔들고, 안개로 시야를 가리고, 스피드업으로 젤리를 빠르게 떨어뜨려요.

던지기 게임 — 역할을 나눠서

한 명은 젤리를 던지고, 한 명은 터트려요. 던지는 쪽은 상대 화면을 보면서 어디로 떨어뜨릴지 정하고, 터트리는 쪽은 쏟아지는 젤리를 막아 내요.

같은 친구와 다시 할 때 역할 바꾸기를 누르면 바로 자리가 바뀌어요.

만든 이야기

HTML 파일 하나로 만든 게임이에요

게임 엔진 없이 캔버스에 직접 그렸고, 실시간 대전은 Supabase Realtime을 씁니다.

파일 하나가 곧 게임

index.html 안에 화면·소리·통신·저장이 다 들어 있어요. 정적 호스팅에 올리면 그게 배포라서, 반년 뒤에 열어도 그대로 돌아가요.

엔진 없이 캔버스로

젤리·캐릭터·표정·승패 애니메이션까지 좌표로 직접 그려요. 캐릭터 여섯 종의 팔·다리·꼬리 비율을 종마다 따로 잡았어요.

실시간 대전

방·점수·방해·관전을 브로드캐스트로 주고받아요. 판 전체를 중계하지 않고 필요한 소식만 보내서, 느린 인터넷에서도 버텨요.

흔들리지 않는 화면

아이폰 노치·홈바까지 계산해 판 크기를 한 판 동안 못 박아요. 아이템 칸이 줄어도 판이 커지지 않아요 — 299×449 → 263×395 로 흔들렸던 걸 잡았어요.

난이도는 실측으로

AI가 2분에 몇 점을 내는지 재서 네 단계를 잡았어요. 가장 쉬운 단계는 20,406점 → 6,576점. 사람이 이길 수 있는 연습 상대가 목표였어요.

스스로 검사하는 도구

화면 넘침·작은 버튼·2인·4인 통신·AI 난이도까지 자동으로 검사해요. 이 페이지의 사진과 영상도 스크립트가 진짜로 플레이해서 만든 거예요.

아이랑 같이 할 게임을 만들다가, 친구랑 붙을 수 있는 방까지 붙었어요. 점수보다 같이 웃는 장면을 남기고 싶어서 이기면 춤추고 지면 분해하는 그림을 넣었습니다.

자주 묻는 것

미리 답해 둘게요

앱을 설치해야 하나요?

아니요, 주소만 열면 바로 됩니다. 홈 화면에 추가하면 앱처럼 전체화면으로 열리고, 인터넷이 없을 때도 혼자 하기는 그대로 돌아가요.

친구랑 어떻게 같이 하나요?

실시간 던전이나 던지기 게임에서 방을 만들면 네 자리 코드가 나와요. 친구가 그 코드를 넣으면 같은 방에서 시작합니다. 2~4명까지 가능해요.

공짜인가요? 광고가 있나요?

무료이고 광고가 없어요. 게임 안 코인은 플레이로만 모아요(현금 결제 없음).

아이가 해도 괜찮나요?

폭력적인 표현이나 과금 요소가 없어요. 주고받는 말은 방 안 한마디와 정해진 말풍선 정도이고, 난이도 순한맛에서 시작하면 쉬워요.
