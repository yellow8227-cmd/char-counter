# ① 유튜브 — 트래블캣 까미 채널에 「일부 공개」

## 왜 이렇게 하나

- **itch 설명란은 유튜브·비메오 주소만** 영상으로 펴 줍니다. 인스타 주소를 붙이면 파란 글씨 링크로만 남고,
  로그인 안 한 사람은 눌러도 안 열립니다. 영상 파일 직접 올리기도 안 받습니다.
- **일부 공개(Unlisted)** 는 채널 「동영상」 탭에 안 뜨고, 추천에도 안 올라가고, 구독자 알림도 안 갑니다.
  고양이 여행 보러 온 사람에게 게임 영상이 노출될 일이 없습니다. itch 에서는 공개 영상과 똑같이 재생됩니다.
  **채널을 빌려 쓰는 것뿐이고 잃는 게 없습니다.**
- 새 채널은 지금 만들지 마세요. 영상 하나짜리 채널은 유튜브에서 아무 일도 안 일어납니다.
  나중에 게임이 굴러가면 그때 만들어 공개로 다시 올리면 됩니다.
- **주소는 안 바뀌니까**, 일부 공개로 먼저 올려 itch 를 열어 두고 나중에 공개로 돌려도 됩니다.

# ② 인스타그램 계정

## 프로필 사진 — 어느 것을 쓰나

```
press/insta-en/profile-320.png     ← 이걸 쓰세요 (320x320, 게임 아이콘)
```

**왜 이것이냐면** 인스타는 프로필 사진을 **동그랗게 잘라냅니다.** 네 귀퉁이가 잘려 나가요.
이 그림은 분홍 고양이 얼굴이 한가운데 크게 있고 리본까지 원 안에 들어와서, 잘라도 멀쩡합니다.
표지(`cover-itch.png`)나 게시물 그림은 **글씨가 있어서** 동그랗게 자르면 글자가 잘립니다 — 쓰지 마세요.

`press/insta/profile-320.png` 와 영어판은 그림이 같습니다. 아무거나 써도 됩니다.

## 아이디 (영문·숫자·밑줄·마침표만 — 한글 불가)

| 순위 | 아이디 | 왜 |
|---|---|---|
| 1 | `jellimo.game` | 이름 그대로 + 게임 계정인 게 보임 |
| 2 | `play.jellimo` | 「플레이」가 앞에 와서 행동을 부름 |
| 3 | `jellimo.official` | 공식 계정 형식 |
| 4 | `jellimo_tap` | 위가 다 있을 때 |

**아이디는 나중에 바꿀 수 있지만, 바꾸면 그동안 뿌린 링크가 다 끊깁니다.** 처음에 정하세요.

## 이름(표시명) — 검색에 잡히는 자리

```
Jellimo · tap & survive
```

인스타 검색은 이름 칸을 **낱말 단위로** 훑습니다. 「jellimo」, 「tap」으로 검색해 나오게 하는 자리예요.
한국도 같이 노리면 `Jellimo 젤리모 · 3분이면 한 판` 으로 해도 됩니다 (한글도 됩니다).

## 소개(bio) — 150자

### 영어판 · 추천 (글로벌 목표라면 이것)

```
Jellimo – OFFICIAL
🍡 3 seconds to learn. 3 minutes a round.
🔥 Nuclear mode: nobody lasts 10 seconds 😏
No install · no sign-up · no ads
👇 Play free in your browser
```

### 한국어 · 영어 섞은 판 (국내도 같이 갈 때)

```
젤리모 Jellimo – OFFICIAL
🍡 규칙은 3초, 근데 귀엽다고 얕보지 마세요😏
🔥핵불닭 10초 버티면 인정 · 설치 X 가입 X 광고 X
👇 프로필 링크로 바로 시작
```

> **왜 이 축인가** — 귀여움만 앞세우면 「여아용 게임」으로 읽혀서, 기록에 매달리는 사람이 안 들어옵니다.
> 캐주얼 게임에서 오래 남는 건 그 사람들입니다.
> **귀여움(들어올 이유)과 극한(안 나갈 이유)을 한 줄에 같이** 넣는 게 핵심입니다.

**공통 규칙**
- 첫 줄에 **게임 이름 + 공식 계정임을 밝히는 말**. 가짜 계정과 구분되는 지점입니다.
- 이모지는 **줄머리에만.** 문장 속에 흩뿌리면 읽기가 급격히 나빠집니다.
- 마지막 줄은 항상 **👇 + 링크를 누르라는 말**. 인스타에서 링크는 바로 그 아래 붙습니다.

## 프로필 링크

```
[ 소개 페이지 주소 ]/en
```

게임 주소가 아니라 **소개 페이지**를 겁니다. 영상·화면·FAQ가 다 있어서 처음 온 사람이 결정하기 좋고,
그 안의 「Play now」 버튼이 게임으로 보냅니다. 나중에 스토어에 올려도 그 페이지에 버튼만 더하면 되니
**링크를 다시 뿌릴 일이 없습니다.**

영어 페이지에는 오른쪽 위에 한국어/EN 단추가 있어서, 한국 사람이 와도 한 번 눌러 넘어갑니다.

# ④ 순서

1. **유튜브에 일부 공개로 올린다** → 주소를 받는다
2. **itch 를 연다** (`press/itch-등록방법.md` 그대로, 설명란은 `press/itch-설명란.md`)
   — 설명 중간에 그 유튜브 주소를 한 줄로 붙인다
3. **인스타 계정을 만든다** — 프로필 사진·이름·소개·링크 채우고, 하이라이트 「먼저 읽기」부터
4. 게시물은 `9-플레이` 부터 거꾸로 올린다 (마지막에 올린 게 맨 위 칸이라 `1-대표` 를 마지막에)

itch 는 심사가 없어서 **오늘 바로 공개됩니다.** 인스타는 천천히 해도 됩니다.
