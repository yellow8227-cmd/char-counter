# 이 게임으로 돈을 벌 수 있나 — itch.io 와 다른 길들

보내 주신 영상의 **itch.io** 부터 보고, 우리 게임에 실제로 맞는 길을 순서로 적었습니다.

---

## 0. 먼저 알아야 할 것 하나

**우리 게임은 지금 "광고 0 · 결제 0"이 최대 무기입니다.**
소개 페이지·스토어 문구·인스타 아홉 칸이 전부 그 말을 하고 있어요.
그래서 **수익화 방법을 고를 때 이 무기를 깨는지 아닌지**가 첫 번째 기준이 돼야 합니다.

| 방법 | "광고 0 · 결제 0" 을 깨나 | 실제 수익 |
|---|---|---|
| itch.io 후원(원하는 만큼 내기) | ✗ 안 깨짐 | 아주 적음 |
| 웹게임 포털(Poki·CrazyGames) 광고 배분 | **○ 깨짐** (게임 안에 광고가 들어감) | 트래픽이 크면 큼 |
| 포털에 게임 통째로 팔기(라이선스) | ✗ 안 깨짐 (한 번 팔고 끝) | 한 번에 목돈 |
| 앱스토어 유료 판매 | △ (결제가 생김) | 마케팅 없으면 거의 0 |

---

## 1. itch.io — 무엇인가

전 세계 인디 게임 마켓입니다. **HTML5 게임을 zip 으로 올리면 브라우저에서 바로 돌아갑니다.**
우리 게임처럼 파일 하나로 된 웹게임에 딱 맞는 형태예요.

### 돈이 되는 구조

| 항목 | 값 |
|---|---|
| 플랫폼 수수료 | **개발자가 직접 정합니다 (0~100%, 기본 10%)** — 스팀·앱스토어의 30% 와 비교되는 지점 |
| 결제 수수료 | 약 **2.9% + $0.30** (PayPal / Stripe) — 이건 못 피합니다 |
| $10 짜리 한 건 팔면 | 기본값 기준 손에 약 **$8.41** |
| 받는 방법 | PayPal 또는 Stripe 계정 |
| 세금 | 미국 밖 개발자는 **W-8BEN 세금 인터뷰**를 채워야 지급됩니다. 세금번호를 안 넣으면 **30% 원천징수**, 한·미 조세조약을 적용하면 낮아집니다 |

### 우리가 쓸 수 있는 방식 세 가지

1. **무료 + "원하는 만큼 내기"(Name your own price)** — 가장 우리 결에 맞습니다.
   광고도 결제 강제도 없고, 재밌게 한 사람만 후원합니다.
2. **무료 + 후원 버튼** — 위와 비슷하지만 더 약합니다.
3. **유료 판매** — 브라우저에서 바로 되는 게임을 돈 받고 팔기는 매우 어렵습니다. 권하지 않습니다.

### 솔직한 기대치

**무료 웹게임의 itch.io 후원 수입은 대부분 한 달에 몇 달러 수준입니다.**
itch.io 는 "돈 버는 곳"이라기보다 **게임을 세상에 내놓고, 사람들이 플레이하고, 댓글이 달리는 곳**입니다.
포트폴리오와 첫 사용자를 얻는 값이 돈보다 큽니다.

### 그래도 올릴 이유는 충분합니다

- **설치 없이 바로 되는 우리 형식에 가장 잘 맞는 마켓**입니다
- 페이지·스크린샷·표지·아이콘·설명이 **이미 다 만들어져 있습니다**(`press/` 폴더)
- 게임 잼(Game Jam)에 낼 수 있고, 거기서 사람이 옵니다
- 앱스토어와 달리 **심사도, 등록비도 없습니다**

## 2. 진짜 돈이 되는 쪽 — 웹게임 포털

광고 수익을 나눠 주는 곳들입니다. 규모가 다릅니다.

| 포털 | 규모 | 조건 |
|---|---|---|
| **Poki** | 월 10억 플레이, 600개+ 스튜디오 | 심사가 가장 까다롭고 몇 주 걸림. SDK 붙여야 함 |
| **CrazyGames** | 월 3억 플레이, 5천만 명 | 개발자 포털에서 직접 제출. 상대적으로 문턱이 낮음 |
| **GameDistribution** | 4,000개 사이트에 배포, 월 3.5억 | 문턱이 가장 낮음. 배분율은 낮은 편 |

- 배분율은 보통 **개발자 50~70%**
- **광고를 게임 안에 넣어야 합니다** (SDK 필수) — 우리 "광고 0" 문구와 정면으로 부딪칩니다
- 라이선스로 통째로 파는 길도 있습니다: **비독점 $300~800, 독점 $5,000 이상**

### 우리 게임의 통과 가능성

| 포털이 보는 것 | 우리 상태 |
|---|---|
| 모바일에서 잘 돌아가나 | ✅ 6기기 × 7화면 자동 검사 통과 |
| 첫 30초에 재밌나 | ✅ 30초면 배우고 3분이면 한 판 |
| UI 가 깔끔한가 | ✅ |
| 영어를 지원하나 | ❌ **한국어뿐** — 해외 포털은 여기서 대부분 걸립니다 |
| SDK(광고) 붙였나 | ❌ |
| 멀티플레이 서버가 있나 | △ Supabase 무료 한도 — 트래픽이 커지면 요금이 듭니다 |

**즉, 포털에 내려면 ① 영어 번역 ② 광고 SDK ③ 서버 비용 — 세 가지 숙제가 있습니다.**

## 3. 그래서 어떻게 하면 좋을까 (제 추천 순서)

### 1단계 — 지금 바로 (돈보다 사람)
- **itch.io 에 무료 + "원하는 만큼 내기"로 올립니다.** 잃을 게 없습니다
- 있는 자료 그대로 씁니다: 표지 `press/shots/cover-1200x630.png`, 스크린샷 6장,
  아이콘, 영상, 소개 문구(`press/스토어-등록문구.md`)
- 세금 인터뷰(W-8BEN)는 **후원이 들어오기 시작한 뒤에** 채워도 됩니다

### 2단계 — 한 달 안 (수익의 진짜 씨앗)
- **영어판을 만듭니다.** 우리 게임은 글이 많지 않아서 문자열만 뽑으면 됩니다.
  이게 되면 itch.io·포털·해외 SNS가 전부 열립니다
- 인스타를 돌려 **한국 사용자 수와 플레이 기록**을 쌓습니다. 포털은 "이미 사람이 붙는 게임"을 좋아합니다

### 3단계 — 숫자가 나오면
- **CrazyGames 에 먼저 제출**합니다(Poki 보다 문턱이 낮고 심사가 빠릅니다)
- 붙으면 **광고를 넣은 포털판**과 **광고 없는 우리 사이트판**을 나눠 둡니다.
  우리 링크로 온 사람은 계속 광고 0 — 문구를 지킬 수 있습니다

### 안 하는 게 낫다고 보는 것
- **앱스토어 유료 판매** — 등록비(애플 연 $99)와 심사를 감당할 만큼 팔리지 않습니다
- **게임 안에 가챠·결제** — 전 연령·가족 타겟에서 잃는 게 더 큽니다
- **지금 상태로 Poki 제출** — 한국어 전용이라 거의 확실히 반려됩니다

## 4. itch.io 에 올릴 때 우리 게임이 걸릴 만한 것

| 걸릴 것 | 확인 |
|---|---|
| 파일 구조 | zip 안에 **`index.html` 이 뿌리에** 있어야 합니다 (넷리파이에서 이미 겪은 그 문제) |
| 서비스워커(PWA) | itch.io 는 게임을 iframe(`html.itch.zone`)에 넣습니다. 오프라인 캐시는 기대하지 마세요 |
| 외부 통신 | Supabase 호출은 됩니다(HTTPS). 다만 **Supabase 대시보드에서 도메인 허용**이 필요할 수 있습니다 |
| 저장 | 인앱 브라우저와 같은 이야기 — iframe 안이라 저장이 막히는 브라우저 설정이 있습니다 |
| 화면 크기 | 등록할 때 **가로 430 · 세로 932** 로 넣고 "모바일 지원" 을 켭니다 |
