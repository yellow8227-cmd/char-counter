# 스토어 등록 자료 — 문구 + 그림 목록 + 주의할 점

`press/shots/` 와 `press/video/` 에 있는 파일을 그대로 올릴 수 있게 정리했습니다.
(문구는 복사해서 쓰고, 대괄호 `[ ]` 부분만 채우면 돼요.)

---

## 0. 먼저 알아야 할 것 — 웹 게임을 스토어에 올릴 때

젤리슈팅은 **웹 게임(PWA)** 입니다. 그래서 스토어 등록은 이 셋 중 하나예요.

| 방법 | 어디에 | 해야 할 일 | 난이도 |
|---|---|---|---|
| **① 그냥 웹으로 쓰기 (추천)** | 주소 공유 · 홈 화면에 추가 | 없음. 지금 상태로 끝 | ⭐ |
| **② 구글 플레이** | Play 스토어 | PWA 를 **Trusted Web Activity**(TWA)로 감싸기. `PWABuilder` 나 `Bubblewrap` 로 몇 분이면 apk/aab 가 나와요. 개발자 등록비 1회 $25 | ⭐⭐ |
| **③ 앱스토어(iOS)** | App Store | 웹뷰만 감싼 앱은 심사에서 자주 반려돼요(가이드라인 4.2 "최소한의 기능"). Capacitor 로 감싸고 **오프라인 동작·홈 화면 위젯 같은 앱다운 요소**를 더하는 게 안전합니다. 개발자 계정 연 $99 | ⭐⭐⭐ |

> 이 문서의 문구·그림은 ②③ 어느 쪽이든 그대로 쓸 수 있고, 웹 소개 페이지(`press/index.html`)에도 씁니다.

## 2. 설명 (Play: 자세한 설명 / iOS: 설명)

```
🍡 톡! 터트리는 3분. 한 판이면 충분해요.

떨어지는 젤리를 손가락으로 톡 누르면 팡 터져요.
쉬지 않고 이어 터트리면 콤보가 붙고 점수가 쭉쭉 올라가요.

⚔️ 친구랑 실시간 대전
방을 만들면 4자리 코드가 나와요. 친구가 코드를 넣으면 같은 판에서 동시에 시작!
2~4명이 함께 겨루고, 게이지를 모아 지그재그·안개·스피드업 같은 방해를 상대에게 던질 수 있어요.

🎯 던지기 게임 — 역할을 나눠서
한 명은 젤리를 던지고, 한 명은 터트려요. 다시 할 때 역할을 바꿔 붙을 수 있어요.

🤖 AI와 대결
인터넷 친구가 없어도 괜찮아요. 실력 4단계 AI와 바로 연습하고,
다시 할 때 실력과 역할을 바꿀 수 있어요.

🎀 내 캐릭터 꾸미기
고양이·강아지·토끼·곰·남자아이·여자아이 6종에 머리 모양, 색깔, 악세서리까지.
코인을 모아 나만의 악세서리도 만들 수 있어요.

🏆 결과는 그림으로 남아요
이기면 트로피를 들고 춤추고, 지면 팔짱 끼고 분해해요.
표정·자세·말풍선이 판마다 달라지고, 그 장면을 그대로 친구에게 공유할 수 있어요.
진 사람은 이긴 사람 화면을 관전할 수도 있어요.

✨ 이런 점이 좋아요
· 설치 없이 웹에서 바로 (홈 화면에 추가하면 앱처럼 전체화면)
· 광고 없음, 현금 결제 없음 — 코인은 플레이로만 모아요
· 한 손으로, 3분이면 한 판
· 오프라인에서도 혼자 하기는 그대로 돼요
· 계정 하나로 폰과 노트북에서 이어서

지금 바로 한 판 해 보세요!
```

### 앱스토어 (iOS)

| 요구사항 | 파일 |
|---|---|
| 앱 아이콘 1024×1024 (투명·둥근모서리 금지) | `shots/icon-1024.png` |

| 앱 미리보기 영상 (15~30초) | `video/jelly-shooting-promo-886x1920.webm` (22초) → **mp4/mov 로 변환해서** 올리기 (아래 6번) |

### 그림은 두 갈래로 만들었습니다

- **게임 화면 12장**은 게임을 실제로 띄워 찍고 문구·액자를 씌운 것 (`appstore-*`, `play-*`)
- **표지·아이콘·대표 이미지**는 게임이 이미 가진 그림을 그대로 씀
  (`cover-1200x630.png` = og.png, `icon-1024.png` = 게임 아이콘)
  — 새로 그리면 게임과 어긋나고, 이 그림들이 더 예쁩니다.

### 스크린샷 순서 (이 순서를 권합니다)

1. `1-play` 톡 터트리면 콤보! — 가장 먼저 보여야 할 핵심
2. `2-dungeon` 친구랑 실시간 대전 — 남들과 다른 점
3. `3-throw` 한 명은 던지고, 한 명은 터트려요
4. `5-result` 이기면 춤추고, 지면 분해요 — 기억에 남는 장면
5. `4-dress` 내 캐릭터 꾸미기 — 계속하게 만드는 이유
6. `6-home` 설치 없이 웹에서 바로

## 6. 영상 파일 변환 (이 컨테이너에는 mp4 인코더가 없어요)

만들어진 영상은 **WebM(VP8)** 입니다. 스토어·인스타그램은 보통 **mp4(H.264)** 를 원해요.
컴퓨터에 ffmpeg 를 깔고 아래 한 줄을 실행하면 됩니다. (`brew install ffmpeg` 또는 https://ffmpeg.org)

```bash
# 앱스토어 앱 미리보기용 (886x1920, 30초 안쪽)
ffmpeg -i jelly-shooting-promo-886x1920.webm -c:v libx264 -pix_fmt yuv420p -crf 20 \
       -movflags +faststart jelly-shooting-promo.mp4

# 인스타그램·유튜브 쇼츠용 (1080x1920 로 키우기)
ffmpeg -i jelly-shooting-promo.webm -vf scale=1080:-2 -c:v libx264 -pix_fmt yuv420p -crf 20 \
       jelly-shooting-promo-1080.mp4
```

> 참고: 영상에는 소리가 없습니다(녹화 환경에 소리 장치가 없어요).
> 배경음악을 얹고 싶으면 `-i music.mp3 -shortest -c:a aac` 를 더하면 돼요.

## 8. 자료를 다시 만들려면

```bash
node jelly-shooting/tools/make-icons.mjs          # 아이콘 (1024 포함) — 캐릭터를 고쳤을 때만
node jelly-shooting/tools/make-og.mjs             # 표지 그림(og.png) — 캐릭터를 고쳤을 때만
node jelly-shooting/tools/make-store-shots.mjs    # 스크린샷 12장 + 표지 + 대표 이미지 + 아이콘 복사
node jelly-shooting/tools/make-promo-video.mjs    # 소개 영상 2개 + 낱장 5장
python3 jelly-shooting/tools/make-press-font.py   # 소개 페이지 제목 글씨체 (글을 고쳤을 때만)
node jelly-shooting/tools/make-press-artifact.mjs # 소개 페이지를 한 파일로 (링크 하나로 공유용)
```

> ⚠ 그림 만드는 도구를 리눅스에서 돌릴 때는 **한글 폰트가 깔려 있어야** 합니다.
> 없으면 한글이 중국어 폰트로 그려져 글씨체가 이상해집니다(그래서 처음 만든 그림들이 어색했어요).
> 나눔고딕 등을 깔고 `fc-cache -f` 하면 됩니다.

두 도구는 **실제 게임을 띄워서 진짜로 플레이한 화면**을 찍습니다.
게임을 고치면 다시 돌리기만 하면 그림과 영상이 따라와요.
