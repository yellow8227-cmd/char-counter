두 개는 **서로 다른 사이트**입니다. 소개 페이지 안의 "지금 바로 플레이" 버튼은 게임 주소를 가리켜요.

## ① 페이지가 아예 안 보일 때 — 거의 항상 이것

**`index.html` 이 사이트 뿌리에 없으면 넷리파이는 "Page Not Found" 를 냅니다.**
지난 zip 은 안에 `press/` 폴더가 한 겹 있어서, 올리면 페이지가 `사이트주소/press/` 에 놓였어요.
그래서 사이트 주소로 들어가면 아무것도 안 보였던 겁니다.

**해결: `소개페이지-넷리파이.zip` 을 올리세요.** 이 zip 은 **압축을 풀면 바로 index.html** 이 나옵니다
(폴더 한 겹이 없습니다).

```
index.html          ← 사이트 뿌리에 이게 있어야 한다
og.jpg              ← 링크 미리보기 그림 (og:image 가 /og.jpg 를 가리킨다)
favicon-32.png  icon-192.png  apple-touch-icon.png
_redirects          ← /press/ 로 들어와도 같은 페이지가 열리게
shots/  fonts/  video/
```

- 넷리파이 Drop( https://app.netlify.com/drop )에 **zip 파일을 그대로** 끌어다 놓거나,
  풀어서 **폴더 안의 내용**을 끌어다 놓으세요. ⚠ 폴더째로 끌면 또 한 겹이 생깁니다.
- 이미 올린 사이트에 덮어쓰려면 그 사이트의 **Deploys → Deploy manually** 에 놓으면 됩니다.

## ② 그래도 안 보이면 순서대로 확인

1. 주소 끝에 `/index.html` 을 붙여 보세요 → 열리면 뿌리에 index.html 이 없다는 뜻(①).
2. `사이트주소/press/` 도 열어 보세요 → 열리면 폴더가 한 겹 있는 상태입니다(①).
3. 넷리파이 **Deploys** 탭에서 마지막 배포가 초록색(Published)인지 확인하세요.
4. 브라우저 캐시 — 새로고침을 강하게(⌘⇧R / Ctrl+F5).

## ③ 링크 미리보기 그림이 안 뜨거나 엉뚱할 때

- **claude.ai 아티팩트 주소**(`claude.ai/code/artifact/…`)는 미리보기 카드를 claude.ai 가 만듭니다.
  **클로드 로고가 나오고, 우리가 바꿀 수 없습니다.** 미리보기가 중요한 곳에는 위 표의 우리 주소를 쓰세요.
- 카톡·트위터는 **주소별로 그림을 캐시**합니다. 이미 보낸 주소는 새 그림으로 안 바뀔 수 있어요.
  - 쉬운 방법: 주소 끝에 `?v=2` 를 붙여 보내기
  - 확실한 방법: 카카오 디버거에서 캐시 삭제 → https://developers.kakao.com/tool/debugger/sharing
- `og:image` 는 반드시 **https:// 로 시작하는 진짜 주소**여야 합니다. 상대 경로(`shots/og.jpg`)로
  적으면 카톡·트위터가 못 읽어 회색 카드가 됩니다.

## ④ 주소가 또 바뀌면 (넷리파이 Drop 은 올릴 때마다 주소가 바뀝니다)

한 줄로 맞춥니다.

```bash
node jelly-shooting/tools/set-site-url.mjs --press https://새주소.netlify.app   # 소개 페이지
node jelly-shooting/tools/set-site-url.mjs         https://새주소.netlify.app   # 게임
```

og:url · og:image · twitter:image 세 곳을 한 번에 바꿔 줍니다.
주소를 고정하고 싶으면 넷리파이에서 사이트를 **내 것으로 등록(claim)** 하고 이름을 정하세요 —
그러면 이 명령을 다시 돌릴 일이 없습니다.

## ⑤ 지금 페이지에 박혀 있는 값

```html
<meta property="og:url"   content="https://dashing-quokka-c37a8b.netlify.app/">
<meta property="og:title" content="젤리슈팅 — 가족도 연인도 친구도, 3분이면 한 판">
<meta property="og:image" content="https://dashing-quokka-c37a8b.netlify.app/og.jpg?v=3">
<meta property="og:image:width"  content="1200">
<meta property="og:image:height" content="630">
<meta name="twitter:card" content="summary_large_image">
```

## ⑥ 대표 그림을 다른 그림으로 바꾸려면

1. 새 그림을 1200×630 `og.jpg` 로 만들어 사이트 뿌리에 올립니다
   (게임 캐릭터로 다시 뽑으려면 `node tools/make-og.mjs` → `og.png`·`og.jpg` 가 나옵니다).
2. `tools/set-site-url.mjs` 안의 `IMG_VER` 숫자를 올리고 위 명령을 다시 돌립니다
   (`?v=3` → `?v=4`). 주소가 달라져야 카톡이 새 그림을 받아갑니다.
