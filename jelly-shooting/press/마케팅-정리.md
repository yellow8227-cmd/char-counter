# 누구에게 팔 것인가 — 타겟 · 레퍼런스 · 문구 정리

소개 페이지와 스토어 문구를 "가족 · 연인 · 친구 / 전 연령이 가볍게" 쪽으로 다듬은 근거와,
같은 판을 파는 게임들이 쓰는 말버릇을 정리했습니다.

---

## 1. 타겟 — 세 장면만 판다

기능을 파는 대신 **장면**을 팝니다. 캐주얼 게임에서 사람이 기억하는 건 기능표가 아니라
"누구랑 언제 하는 것"이에요.

| 타겟 | 파는 장면 | 이 사람이 확인하고 싶은 것 | 우리가 내미는 답 |
|---|---|---|---|
| **가족** | 아이 옆에서 한 판, 주말 거실 | 광고·결제가 없나? 아이가 할 수 있나? | 난이도 순한맛 · 광고 0 · 결제 0 · 전 연령 |
| **연인** | 카페에서 누가 이기나 딱 한 판 | 티격태격할 거리가 있나? | 승패 그림 · 말풍선 놀리기 · 관전 |
| **친구** | 단톡방에 코드 던지고 바로 | 다들 설치해야 하나? 몇 명까지? | 설치 0 · 방 코드 네 자리 · 2~4명 |

**한 줄 포지셔닝**
> 온 가족이, 연인끼리, 친구랑. 3분이면 한 판 — 설치도 가입도 없어요.

이 한 줄에 타겟(3) · 플레이 시간(3분) · 진입 장벽(0)이 다 들어갑니다.
스토어 부제·간단한 설명·인스타 첫 줄에 같은 문장을 씁니다(메시지를 쪼개지 않기).

---

## 2. 레퍼런스 — 비슷한 판을 파는 게임들이 쓰는 말

### ① 웹에서 바로 하는 파티 게임 — Gartic Phone
- 한국어 페이지 첫 줄이 **"온라인 게임, 옮겨 말하기! 지금 무료로 이 인기 게임을 플레이하세요"**
  — 장르 + **무료** + **지금**을 한 줄에 넣습니다. ([garticphone.com/ko](https://garticphone.com/ko))
- 초대는 **방을 만들고 링크/QR로 부르기**가 전부. 이 '설치 없음 + 코드 초대'가 웹게임의 최대 무기라
  페이지 위쪽에서 바로 말합니다. ([Google Play](https://play.google.com/store/apps/details?id=com.gartic.garticphone))
- **우리가 가져온 것**: 히어로 바로 아래 `설치 0 · 가입 0 · 광고 0 · 결제 0 · 전 연령` 배지,
  그리고 **① 방 만들기 → ② 코드 보내기 → ③ 같이 시작** 3단계 섹션.

### ② 커플·가족 대상 앱들 (Lovify · 텐더 토크 · 커플 게임 등)
- 기능이 아니라 **관계의 상황**을 씁니다: "첫 데이트의 어색함을 깨고 싶을 때",
  "오래된 관계를 더 단단하게", "커플이나 친구들과 함께 시간을 보내기에 완벽한".
  ([Lovify](https://apps.apple.com/kr/app/재미있는-커플-게임-lovify/id1645893544) ·
  [텐더 토크](https://apps.apple.com/kr/app/텐더-토크-커플-게임/id6464399555))
- 애플이 직접 큐레이션하는 **'최고의 가족 게임'** 같은 코너도 "온 가족이 함께" 프레임으로 묶습니다.
  ([App Store 스토리](https://apps.apple.com/us/story/id1520181535?l=ko))
- **우리가 가져온 것**: 타겟 카드 세 장에 **장면 문구**를 넣었습니다
  ("아이 옆에서 한 판 · 주말 거실", "카페에서 · 저녁 통화하면서", "단톡방 · 점심시간").

### ③ 3매치 캐주얼 퍼즐 (애니팡 · 캔디크러쉬)
- **한 판의 길이**를 판다: 애니팡은 제한 시간 **1분**이 그대로 정체성입니다.
  ([애니팡](https://ko.wikipedia.org/wiki/애니팡) · [캔디크러쉬사가](https://apps.apple.com/kr/app/캔디크러쉬사가/id553834731))
- 설명은 **짧은 문장 + 이모지 + 한 줄 한 생각**으로 스캔되게 씁니다. 문단을 길게 쓰지 않습니다.
- **우리가 가져온 것**: "3분이면 한 판", "30초면 배워요" 를 반복해서 씁니다.
  섹션마다 태그(놀이 방법 세 가지 · 규칙 다섯 줄 · 46초)로 **분량을 미리 알려** 읽는 부담을 낮췄습니다.

### ④ 스토어 등록 페이지 (마이크로소프트 스토어 · 앱스토어)
- 큰 표지 그림 → 아이콘+이름 → 버튼 → 배지(무료·연령) → 스크린샷 → 설명 → 리뷰 → FAQ 순서.
- **우리가 가져온 것**: 페이지 순서를 그 흐름에 맞췄습니다(표지 → 이름·버튼·배지 → 타겟 →
  초대 3단계 → 영상 → 화면 → 규칙 → 만든 이야기 → FAQ → 마지막 버튼).

## 3. 페이지에 실제로 바꾼 것

| 자리 | 전 | 후 (왜) |
|---|---|---|
| 히어로 한 줄 | 톡 터트리는 3분, 친구랑 실시간 대전 | **온 가족이, 연인끼리, 친구랑** — 타겟을 먼저 말한다 |
| 히어로 아래 | (없음) | **설치 0 · 가입 0 · 광고 0 · 결제 0 · 전 연령** 배지 — 가족 타겟이 가장 먼저 확인하는 것 |
| 두 번째 섹션 | 게임 4가지 카드 | **타겟 카드 3장**(가족·연인·친구) + 장면 문구 |
| 세 번째 섹션 | (없음) | **초대 3단계** + 코드 `A7K2` 그림 — "어떻게 같이 하냐"에 즉답 |
| 영상 자리 | 아래쪽 | **위로 올림**(가장 강한 설득 재료) · 소리 켜라는 안내 추가 |
| 모드 설명 제목 | 기능 이름 | 효익 문장으로 ("혼자 하기 — 딱 3분", "2~4명이 같은 판에서") |
| 결과 화면 | 카드 한 줄 | **사진 + 설명 한 줄**로 키움 — 이 게임에서 가장 기억에 남는 장면이라 |
| FAQ | 4개 | **6개**(몇 살부터 · 데이터 · 계정 필요 여부 추가) — 반대 이유를 미리 없앤다 |
| 만든 이야기 | 6칸 | **4칸**으로 줄임 — 상업 페이지에선 이 부분이 가장 덜 중요하다 |
| 마지막 | 버튼 | 버튼 + **배지 한 번 더** |

문구 원칙 네 가지만 지켰습니다.
1. **한 줄 한 생각**, 문단은 세 줄 안.
2. **숫자를 넣는다** — 3분 · 30초 · 4자리 · 2~4명 · 네 단계 · 여섯 종.
3. **기능 대신 장면** — "실시간 브로드캐스트" 대신 "마지막 10초가 제일 시끄러워요".
4. **불안을 먼저 없앤다** — 광고·결제·연령·데이터·계정을 묻기 전에 답한다.

## 4. 더 상업적으로 만들려면 (다음에 할 일 순서)

지금 없는 것 중에 **효과가 큰 순서**로 적었습니다.

1. **소셜 프루프** — 지금 페이지에 남의 말이 하나도 없습니다. 친구·가족 반응 한 줄씩
   3개만 받아서 카드로 넣으면 전환이 확 올라갑니다. (스크린샷·카톡 캡처도 좋아요)
2. **15초 쇼츠 컷** — 71초 영상에서 '실시간 던전 + 승패 그림'만 잘라 세로 15초로.
   인스타 릴스·유튜브 쇼츠는 15초가 기본 단위예요. (지금 자료로 잘라내기만 하면 됩니다)
3. **첫 화면에 움직이는 그림** — 히어로에 3초 루프(GIF/짧은 webm)를 넣으면 체류가 늘어납니다.
   영상 앞부분을 그대로 쓸 수 있어요.
4. **ASO 키워드 정리** — '같이 하는 게임', '커플 게임', '가족 게임', '방 코드', '웹게임',
   '설치 없는 게임' 같은 실제 검색어를 부제·설명 첫 두 줄에 넣기.
5. **공유 문구 자동 채우기** — 결과 공유에 "너도 해봐 → 주소" 가 이미 들어가지만,
   '방 코드까지 담아 보내기'를 넣으면 초대가 곧 유입이 됩니다.
6. **랜딩에 방 코드 입력칸** — 페이지에서 코드를 넣으면 바로 그 방으로 들어가게 하면
   초대받은 사람이 게임을 두 번 열지 않아도 돼요.
7. **A/B 문구 두 벌** — 히어로 한 줄을 ①타겟형(지금 것) ②시간형("자기 전 3분, 딱 한 판")로
   번갈아 걸어 보고 남는 쪽을 씁니다.
