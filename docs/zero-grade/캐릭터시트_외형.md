# 0등급 零等級 — 캐릭터 시트 (외형)

> 「각혈」 캐릭터 시트와 같은 규격입니다.
> **NAME / 漢字·한글 / Age / Height / Role / Personality / Voice + 3패널 이미지(정면 전신 · 후면 전신 · 얼굴 클로즈업).**
>
> 외형 문장은 전부 「캐릭터 프롬프트 바이블」의 **고정 캐릭터 블록 원문 그대로**입니다.
> 새로 지어낸 것은 **한자 이름과 키 두 항목뿐이며 「가안」으로 표시**했습니다 — 원고에 없는 값입니다.

---

## ⚠ 먼저 정할 것 — 확정 레퍼런스와 바이블이 어긋납니다

업로드하신 **하은 포트레이트 영상(확정 레퍼런스)** 과 바이블의 고정 블록이 네 군데 다릅니다.
하은이 나오는 컷이 9컷 중 6컷이라, 이걸 먼저 맞추지 않으면 뒤 작업이 전부 흔들립니다.

| 항목 | 바이블 문구 | 확정 레퍼런스 실제 |
|---|---|---|
| 화장 | `no makeup` | **붉은 립 있음** |
| 입술 | `thin lips pressed into a straight line` | 도톰한 입술 |
| 피부 | `pale skin` | 웜톤, 창백하지 않음 |
| 머리 | `tight low bun` | 낮은 번 + **관자놀이 잔머리 흘러내림** |

**추천 — 립만 되돌리고 나머지 셋은 레퍼런스를 채택합니다.**

- **립은 반드시 지웁니다.** 「무화장」은 취향이 아니라 설정입니다 — 25년간 자기를 꾸미지 않은 사람이고,
  임선화가 관찰한 표본입니다. 붉은 립이 있으면 그 25년이 화면에서 사라집니다.
- **잔머리는 오히려 살립니다.** 완벽한 번보다 낫습니다. 후반에 머리를 풀어 변화를 보여줄 때,
  잔머리가 미리 있어야 「이미 조금씩 새고 있었다」가 됩니다.
- **피부·입술은 레퍼런스대로** 문구를 고칩니다. 얼굴을 다시 뽑는 비용이 더 큽니다.

→ 그래서 아래 하은 카드의 고정 블록은 **v5(개정안)** 로 적어두었습니다.
   바이블과 프롤로그 스토리보드 문서 **양쪽을 같이** 고쳐야 합니다.

# 얼굴 충돌 검증표

생성 후 아래로 대조합니다. 두 인물이 비슷하게 나왔으면 해당 축의 키워드를 강화하세요.

| 축 | 갈라지는 지점 |
|---|---|
| 얼굴형 | **각진 턱** 하은·도현·정 과장 ↔ **둥근 얼굴** 하린·김 노인·한지원 ↔ **좁고 긴 얼굴** 임선화·윤 감사관 ↔ **넓은 얼굴** 윤태석 |
| 눈매 | **깊은 홑꺼풀** 하은·정혜숙(모녀) ↔ **큰 쌍꺼풀** 하린 ↔ **처진 눈** 김 노인·강현우 ↔ **안경 뒤** 임선화·서도윤 |
| 머리 | **바짝 묶음** 하은·정혜숙(통제) ↔ **풀어헤침** 하린(해방) ↔ **헝클어짐** 도현(붕괴) ↔ **올백** 서도윤(자본) |
| 입 | **일자로 다문 입술** 1등급 계열 ↔ **웃음 주름 있는 입** 5등급 계열 |

**반드시 확인할 3쌍**
1. **하은 ↔ 하린** — 각진/둥근, 홑꺼풀/쌍꺼풀, 묶음/풀림. 자매인데 정반대여야 임선화 가설의 반증이 얼굴로 보인다
2. **하은 ↔ 정혜숙** — **눈매만** 공유. 나머지가 닮으면 실패
3. **강현우 ↔ 임선화** — 둘 다 부드러워 보이는데 성질이 반대. 인자한 얼굴의 **가짜 온기** ↔ 차분한 얼굴의 **진짜 냉기**
