# 촬영 배치도 (Shot Planner)

내일 찍을 것을, 오늘 밤에.

머릿속에서는 이미 다 찍었을 겁니다. 소파가 저기 있고, 카메라는 이쪽에서 들어가고.
다만 그게 몇 미터인지, 35mm에 두 사람이 다 들어오는지는 아직 아무도 모릅니다.

재 보고 자면 됩니다.

> 이 저장소의 글자수 세기 도구와는 별개의 프로젝트입니다.
> 나중에 따로 떼어내기 쉽도록 이 폴더 안에만 두었습니다.

## 실행

의존성도, 빌드도 없습니다. 파일 하나를 브라우저로 열면 됩니다.

```bash
open shot-planner/index.html      # macOS
xdg-open shot-planner/index.html  # Linux
start shot-planner\index.html     # Windows
```

## 하는 일

- **평면도 배치** — 추가 버튼을 누르면 소품이 커서를 따라오고, 클릭한 자리에 놓입니다.
  옆 물건이나 벽에 닿으면 딱 붙고, `Alt` 를 누르면 자유롭게 놓입니다.
- **소품 크기** — 놓인 소품마다 가로·세로·높이를 따로 줄 수 있습니다.
  같은 종류의 다른 소품은 그대로 두고 이 하나만 바뀝니다.
  「바닥에서」를 올리면 테이블 위에 얹은 것이 됩니다.
- **배우 자세** — 서기 · 앉기 · 바닥에 앉기 · 쪼그리기 · 무릎 꿇기 · 눕기.
  자세를 바꾸면 눈높이와 바닥에서 차지하는 자리, 샷 사이즈가 함께 바뀝니다.
  의자 위에서 「앉기」로 바꾸면 그 의자의 좌면 높이를 그대로 씁니다.
- **빠른 배치** — 「배우 2명, 소파, 카메라 2대」처럼 한 줄로 씬을 채웁니다.
  서로 겹치지 않는 자리를 찾아 놓습니다. 같은 자리에 「모두 삭제」와
  「이전 / 이후」 버튼이 있어, 지우고 다시 짜거나 되돌리기 쉽습니다.
- **렌즈 계산** — 센서 폭과 렌즈 mm 로 수평·수직 화각을 그리고, 조리개와 초점 거리로
  심도 범위와 과초점 거리를 냅니다.
- **180° 선 검사** — 두 인물을 기준으로 가상선을 긋고, 넘어간 카메라를 샷 리스트에서 짚어 줍니다.
- **카메라 뷰 · 조감도** — 고른 카메라가 지금 무엇을 보는지, 세트 전체가 어떻게 생겼는지 함께 봅니다.
- **조명과 그림자** — 키·필·백·프랙티컬의 색온도와 세기로 바닥 그림자를 그립니다.
- **내보내기** — 샷 리스트와 PNG 도면. 씬은 여러 개 만들 수 있습니다.

## 조작

| | |
|---|---|
| 휠 | 확대 / 축소 (커서 기준) |
| `Space` 드래그, 🖐 도구, 가운데·오른쪽 버튼 | 화면 이동 |
| `0` | 화면 맞춤 |
| 빈 곳 드래그 | 여러 개 고르기 (그대로 함께 이동) |
| `Shift` + 클릭 | 고른 목록에 넣기 / 빼기 |
| `Alt` + 클릭 | 겹친 것 중 아래 것 고르기 |
| 주황 손잡이 드래그 | 회전 (기본 15° 단위, `Shift` 로 자유각) |
| `R` | 회전 · `Del` 삭제 · `←↑↓→` 미세이동 |
| `Ctrl+D` / `Ctrl+A` / `Ctrl+Z` | 복제 / 전체 선택 / 되돌리기 |
| `Tab` | 다음 카메라 |
| ◧ 넓게 | 왼쪽 칸을 접어 배치도를 넓게 씁니다 |

## 저장

작업 내용은 브라우저의 localStorage 에 저장됩니다.
기기나 브라우저를 옮기면 따라가지 않으니, 옮기기 전에 저장해 두고 새 기기에서 불러오세요.

## 구조

`index.html` 한 파일이 전부입니다 — 스타일, 그리기, 계산이 모두 안에 들어 있고
외부에서 받아오는 것이 없습니다. 그래서 인터넷 없이도 열립니다.
