# 촬영 배치도 (Shot Planner)

내일 찍을 것을, 오늘 밤에.

머릿속에서는 이미 다 찍었을 겁니다. 소파가 저기 있고, 카메라는 이쪽에서 들어가고.
다만 그게 몇 미터인지, 35mm에 두 사람이 다 들어오는지는 아직 아무도 모릅니다.

재 보고 자면 됩니다.

> 이 저장소의 글자수 세기 도구와는 별개의 프로젝트입니다.
> 나중에 따로 떼어내기 쉽도록 이 폴더 안에만 두었습니다.

## 실행

의존성도, 빌드도 없습니다. 파일 하나를 브라우저로 열면 됩니다.

```bash
open shot-planner/index.html      # macOS
xdg-open shot-planner/index.html  # Linux
start shot-planner\index.html     # Windows
```

## 하는 일

- **평면도 배치** — 추가 버튼을 누르면 소품이 커서를 따라오고, 클릭한 자리에 놓입니다.
  옆 물건이나 벽에 닿으면 딱 붙고, `Alt` 를 누르면 자유롭게 놓입니다.
- **소품 크기** — 놓인 소품마다 가로·세로·높이를 따로 줄 수 있습니다.
  같은 종류의 다른 소품은 그대로 두고 이 하나만 바뀝니다.
  「바닥에서」를 올리면 테이블 위에 얹은 것이 됩니다.
- **배우 자세** — 서기 · 앉기 · 바닥에 앉기 · 쪼그리기 · 무릎 꿇기 · 눕기.
  자세를 바꾸면 눈높이와 바닥에서 차지하는 자리, 샷 사이즈가 함께 바뀝니다.
  의자 위에서 「앉기」로 바꾸면 그 의자의 좌면 높이를 그대로 씁니다.
- **빠른 배치** — 「배우 2명, 소파, 카메라 2대」처럼 한 줄로 씬을 채웁니다.
  서로 겹치지 않는 자리를 찾아 놓습니다. 같은 자리에 「모두 삭제」와
  「이전 / 이후」 버튼이 있어, 지우고 다시 짜거나 되돌리기 쉽습니다.
- **세트 크기** — 배치도의 검은 테두리가 촬영할 공간의 벽 안쪽 치수입니다.
  원룸 · 거실 · 사무실 · 스튜디오 · 야외 프리셋이 있고, 실측값을 직접 넣어도 됩니다.
- **렌즈 계산** — 센서 폭과 렌즈 mm 로 수평·수직 화각을 그리고, 조리개와 초점 거리로
  심도 범위와 과초점 거리를 냅니다. 착란원은 포맷별 시네 표준값(슈퍼35 0.025mm 등)을
  쓰고, 설정에서 「엄격(4K)」로 바꿀 수 있습니다. 아나모픽 스퀴즈(1.33~2x)도 지원합니다.
  T스톱은 투과율을 반영해 f값으로 환산해 심도를 냅니다(T2.8 ≈ f/2.5).
  화면비에 따라 센서에서 실제로 쓰는 면적을 계산하므로, 2.39 로 찍으면 세로가 잘립니다.
- **자** — 도구줄의 📏 로 두 점 사이 거리와 방위각을 잽니다.
- **소품 기울이기** — 사다리를 세우거나 액자를 눕히듯 앞뒤로 −90°~90° 넘어뜨립니다.
  넘어뜨린 만큼 바닥에서 차지하는 자리와 높이가 다시 계산됩니다.
- **180° 선 검사** — 두 인물을 기준으로 가상선을 긋고, 넘어간 카메라를 샷 리스트에서 짚어 줍니다.
- **카메라 뷰 · 조감도** — 고른 카메라가 지금 무엇을 보는지, 세트 전체가 어떻게 생겼는지 함께 봅니다.
- **조명과 그림자** — 키·필·백·프랙티컬의 색온도와 세기로 바닥 그림자를 그립니다.
- **한 장 인쇄** — A4 가로 한 장에 평면도 · 카메라 뷰 · 조감도 · 범례 · 셋업표를
  함께 담습니다. 도면 칸은 186×136mm 로 못 박혀 있어, 축척 1:50 · 1:100 이
  종이 위에서 그대로 맞습니다. 브라우저 인쇄에서 「PDF로 저장」을 고르면 파일이 되고,
  인쇄가 막힌 곳에서는 같은 종이를 300dpi PNG 한 장으로 뽑아 줍니다.
- **내보내기** — 한 장 시트 · 도면 · 카메라 뷰 · 조감도를 각각 PNG 로,
  샷 리스트는 엑셀에 그대로 붙는 형태로 뽑습니다. 씬은 여러 개 만들 수 있습니다.
- **그림이 곧 작업 파일** — 내보낸 PNG 안에는 작품 전체가 압축돼 들어갑니다
  (PNG 규격의 `tEXt` 칸, 그림에는 영향이 없습니다). 「이어서 하기」로 그 그림을
  도로 열면 배치가 그대로 살아납니다. 조감독에게 도면 한 장만 보내도 편집본을
  같이 보낸 셈입니다. 다만 그림을 다시 저장하거나 압축하는 서비스를 거치면
  그 칸이 지워질 수 있으니, 확실히 넘기려면 `.json` 이나 🔗 링크를 쓰세요.
- **나누기** — 🔗 공유는 세 가지를 구분해서 보여 줍니다.
  ① **도구 주소** (빈 배치도로 열립니다) · ② **이 배치도가 담긴 주소**
  (작품이 압축돼 `#p=` 뒤에 붙습니다) · ③ **파일** (PNG · .json · 클립보드).
  창 안에 끼워져 열린 상태에서는 바깥 주소를 읽을 수 없어 ① 을 한 번 붙여넣어 주면
  기억해 둡니다. 그럴 때 ② 는 받는 쪽까지 안 갈 수 있으니 ③ 이 가장 확실합니다.
- **이어서 하기** — 파일 고르기 · 끌어다 놓기 · `Ctrl+V` 붙여넣기 · JSON 붙여넣기,
  네 갈래를 한 창에 열어 둡니다. 어떤 환경에서는 파일 고르기 창 자체가 안 열립니다.

> **샌드박스 안에서 막히는 것들**
> 웹에 올려 두면 이 도구는 샌드박스 iframe 안에서 돕니다. 거기서는 `<a download>` 와
> `window.print()` 가 조용히 무시되고, `confirm()`·`prompt()` 는 **묻지도 않고 「아니오」**
> 를 돌려줍니다. 그래서 저장은 호스트가 주는 통로를 쓰고, 인쇄는 열렸는지 확인한 뒤
> 안 열리면 PNG 로 넘기고, 묻는 창은 브라우저 것 대신 직접 그립니다.
> 저장이 아예 막힌 곳에서도 🔗 공유 링크나 📋 복사로 작업을 꺼낼 수 있습니다.

## 조작

| | |
|---|---|
| 휠 | 확대 / 축소 (커서 기준) |
| `Space` 드래그, 🖐 도구, 가운데·오른쪽 버튼 | 화면 이동 |
| `0` | 화면 맞춤 |
| 빈 곳 드래그 | 여러 개 고르기 (그대로 함께 이동) |
| `Shift` + 클릭 | 고른 목록에 넣기 / 빼기 |
| `Alt` + 클릭 | 겹친 것 중 아래 것 고르기 |
| 주황 손잡이 드래그 | 회전 (기본 15° 단위, `Shift` 로 자유각) |
| `R` | 회전 · `Del` 삭제 · `←↑↓→` 미세이동 |
| `Ctrl+D` / `Ctrl+A` / `Ctrl+Z` | 복제 / 전체 선택 / 되돌리기 |
| `Tab` | 다음 카메라 |
| ◧ 넓게 | 왼쪽 칸을 접어 배치도를 넓게 씁니다 |

## 저장

작업 내용은 브라우저의 localStorage 에 저장됩니다.
기기나 브라우저를 옮기면 따라가지 않으니, 옮기기 전에 저장해 두고 새 기기에서 불러오세요.

## 구조

`index.html` 한 파일이 전부입니다 — 스타일, 그리기, 계산이 모두 안에 들어 있고
외부에서 받아오는 것이 없습니다. 그래서 인터넷 없이도 열립니다.
