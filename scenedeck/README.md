# 🎬 SCENEDECK · 씬덱

시나리오부터 AI 프롬프트까지 한 자리에서 굴리는 워크벤치.
**설치도 인터넷도 필요 없습니다** — `index.html`을 더블클릭하면 바로 열려요.

## 🚀 시작하기

**① 파일로 쓰기** — `index.html` 더블클릭. 끝. (크롬·엣지 아무거나)

**② 웹 주소로 쓰기** — GitHub Pages로 이미 올라가 있습니다.

```
https://yellow8227-cmd.github.io/char-counter/scenedeck/
```

주소만 있으면 폰이든 남의 컴퓨터든 그냥 열립니다.
**`main` 브랜치에 올리면 몇 분 안에 자동으로 반영됩니다** — 따로 업로드할 것이 없습니다.

> ⚠️ `fonts/` 폴더가 같이 있으면 슬레이트 글자가 손글씨체로 나옵니다.
> 없어도 **동작에는 아무 문제가 없습니다** — 그 자리만 `Consolas`로 대체됩니다.

## 🏠 홈 화면

첫 화면은 안내용 **홈**입니다 — 무엇을 할 수 있는지, 어떤 파일을 넣을 수 있는지,
지금 작업이 어디까지 왔는지(씬·컷·캐릭터 수)를 한눈에 보여줍니다.
카드를 누르면 그 작업 탭으로 바로 넘어가요.

탭을 옮기면 주소 끝이 `#prompt` 처럼 바뀝니다. **그 주소를 그대로 북마크·공유**하면
다음에 열 때 같은 탭으로 열리고, 그냥 새로고침해도 마지막에 보던 화면으로 돌아옵니다.

## 🧭 순서대로 따라가기

「대본 · 컷」 탭 맨 위에 **① 원고 올리기 → ② 씬으로 나누기 → ③ 컷 만들기 → ④ 프롬프트 뽑기**
네 칸이 있고, **지금 해야 할 것 하나만 색으로 표시**됩니다.
바로 아래 줄이 **무엇을 눌러야 하는지 문장으로 말해주고 그 버튼을 같이 놓아줍니다.**

파일은 **화면 아무 데나 끌어다 놓으면** 됩니다 — 점선 상자를 정확히 맞출 필요도, 탭을 먼저 옮길 필요도 없어요.
읽을 수 없는 형식(.hwp 등)은 **성공한 척하지 않고** 무엇으로 저장해 오면 되는지 알려줍니다.

## ⚡ 가장 빠른 길

**원고가 있을 때** — 「대본 · 컷」 탭에 파일을 끌어다 놓고 **①「✓ 적용」 ②「모든 씬을 컷으로 쪼개기」** 두 번만 누르면 끝입니다.
전 씬이 컷으로 나뉘고 **샷 · 앵글 · 렌즈 · 조명 · 길이까지 자동으로 채워져서**, 「프롬프트」 탭에 가면 바로 복사할 문장이 나와 있습니다.

| 자동 배분 규칙 | |
|---|---|
| 씬의 첫 컷 | 장소를 보여주는 **롱샷** · 24mm · 5초 |
| 대사 컷 | **미디엄 클로즈업** · 85mm · 대사 길이에 맞춘 초 |
| 중간 지문 컷 | 미디엄샷 · 35mm · 4초 |
| 씬의 마지막 컷 | **클로즈업** · 85mm · 푸시 인 |
| 조명 · 분위기 | 씬의 시간대에서 유추 (밤 → 로우키/긴장, 새벽 → 블루아워, 해질녘 → 골든아워 …) |

이미 컷이 있는 씬은 건드리지 않습니다. 마음에 안 들면 토스트의 **「되돌리기」** 한 번으로 전부 취소됩니다.

**원고도 씬도 없을 때** — 「프롬프트」 탭에서 **⚡ 빠른 입력**을 고르세요.
「무슨 일이 벌어지나요」 한 줄만 적으면 세 가지 프롬프트가 바로 나옵니다. 씬도 컷도 만들 필요가 없어요.
장소 · 시간대 · 샷 · 조명은 원하는 것만 고르면 되고, 캐릭터 칩을 켜면 **외형 고정 블록**도 그대로 들어갑니다.
한글로 쓰면 **옆 영문 칸이 저절로 채워지고**, 프롬프트는 그 영문으로 나갑니다.
쓸 만하면 「이 내용을 컷으로 저장」으로 남겨두면 보드 · 스케줄표 · 내보내기에서도 함께 쓰입니다.

## 🗺️ 탭 안내 — 5개

탭이 8개일 땐 어디서부터 손대야 할지 알기 어려웠습니다. 하는 일이 겹치는 것끼리 묶어 **5개**로 줄였습니다.

| 탭 | 하는 일 | 옛 탭 |
|---|---|---|
| **홈** | 기능 안내 · 현재 작업 요약 · 바로가기 | — |
| **기획** | 로그라인 → 시놉시스 → 3막 → 씬 리스트, 캐릭터 **외형 고정 블록** | 스토리 + 캐릭터 |
| **대본 · 컷** | **원고 올려 씬 자동 분해 → 전 씬 일괄 컷 생성** · 씬/컷 손보기 · 스토리보드 | 대본 + 씬·컷 + 보드 |
| **프롬프트** | 미드저니 · **런웨이/클링** · Veo(Flow) · 범용 4종. **복사하고 바로 열기** · 씬·컷 없이 뽑는 「빠른 입력」 | 프롬프트 |
| **설정** | 저장 용량, JSON 백업, CSV·TXT 내보내기 | 설정 |

합쳐진 탭 안에서는 맨 위의 **섹션 바로가기**로 건너뜁니다.
탭 아래쪽에는 **「다음 →」** 버튼이 있어 기획 → 대본·컷 → 프롬프트 순서가 자연스럽게 이어집니다.
옛 주소(`#story` `#board` …)로 들어와도 새 탭으로 알아서 보내줍니다.

## 🎬 프롬프트가 만들어지는 방식

**KEEPKWAN 「일관성을 유지하는 AI영상 제작」 교안의 프롬프트 블록 6요소**를 그 순서 그대로 씁니다.

```
① 목적        무엇으로 보이게 할 것인가 (영화 스틸 / 동화 일러스트 / 연필 스케치 …)
② 스토리      샷·앵글·구도 + 인물(외형 고정 블록 + 감정) + 행동 + 장소
③ 만드는 도구  목적에 맞는 도구 — 사진이면 카메라·렌즈, 그림이면 붓·종이
④ 디테일      시대 · 시간 · 조명 · 빛 효과
⑤ 컬러 · 무드  분위기 · 팔레트 · 화질 선언
⑥ 파라미터     --ar --style --sref --oref …
```

> **③이 ①과 어긋나면 결과가 무너집니다.** 동화 일러스트를 만들면서 `shot on Hasselblad`가 붙으면
> 맨 앞 선언과 정면으로 부딪쳐요. 그래서 **매체가 사진 계열이 아니면 카메라·렌즈 칸이 사라지고**
> 그 매체의 도구(붓 · 종이 · 렌더러)로 바뀌며, `--style raw`(＝사진처럼)도 자동으로 빠집니다.
> 교안이 ChatGPT에게 STEP 5로 따로 시키는 「목적 블록 정렬」을 화면이 알아서 합니다.

**맨 앞의 매체 선언이 결과를 가장 크게 바꿉니다.** 같은 장면이라도 —

| 매체 | 앞에 붙는 말 | 끝에 붙는 말 |
|---|---|---|
| 🎬 영화 스틸 | `cinematic, film still` | `hyper-realistic` |
| 📼 90년대 DVD 화면 | `DVD screengrab, movie still` | `hyper-realistic, detailed style` |
| 📷 다큐 사진 | `documentary photograph` | `natural light, unposed` |
| ✏️ 스토리보드 스케치 | `pencil sketch for storyboard` | `rough hatching, black and white` |
| 🖍️ 콘티 마커화 | `storyboard panel, marker sketch` | `loose linework, limited color` |
| 🎨 플랫 벡터 일러스트 | `flat vector graphic illustration` | `simple shapes and lines, flat colors` |
| 🖼️ 콘셉트 아트 | `cinematic concept art` | `digital matte painting` |
| 🌸 애니메이션 스틸 | `anime film still` | `cel shaded` |
| 📺 광고 · 제품 컷 | `commercial photography still` | `studio lighting` |
| 📰 에디토리얼 사진 | `editorial photography` | `in a hyper realistic, detailed style` |
| 📖 동화 일러스트 | `illustration for a childrens book` | `warm storybook texture` |

| 🖌️ 유화 | `masterpiece oil painting` | `visible brushstrokes, canvas texture` |

### 카메라 · 시대 · 구도

- **카메라 · 필름** — `shot on Hasselblad` `shot on Nikon FA` `Kodak Portra 400` `ARRI Alexa` `16mm 필름` …
  미드저니는 실제 기종의 화각 · 계조 · 입자를 알아듣습니다
- **시대** — `in the style of 1990s` 한 줄로 의상 · 소품 · 색감이 통째로 바뀝니다 (70s / 80s / 90s / Y2K / 현재 / 근미래)
- **구도** — 3등분 법칙 · **정중앙(중심선)** · **중심선에서 밀려남(불안)** · 대칭 · 프레임 속 프레임 · 여백 강조

### 샷 · 앵글이 주는 인상

컷을 고르면 그 아래에 무엇이 달라지는지 한 줄로 뜹니다.

| 앵글 | 인상 |
|---|---|
| 아이레벨 | 자연스럽고 친숙함 · 1인칭 시점 · 인물과의 교감 · 캐릭터 소개 |
| 로우앵글 | 고압적 · 지배적 · 위협적 · 권위 · 영웅심 · 감정 고조 |
| 하이앵글 | 약자 · 관찰당함 · 취약함 |
| 익스트림 롱샷 | 넓은 환경에 놓인 인물 — 취약성 · 외로움 |
| POV | 내가 그 장면을 바라보는 듯 — 몰입 |

### 컷을 얼마나 잘게 나눌지

| 방식 | 나누는 기준 |
|---|---|
| **문장마다 한 컷** (기본) | 줄바꿈을 지키고, 그 안에서 문장 단위로 |
| 문단 · 대사마다 한 컷 | 빈 줄로 나뉜 문단 하나 = 컷 하나 |
| 씬 하나당 한 컷 | 씬 전문을 통째로 |

지문 한 문단 안에는 보통 여러 개의 샷이 들어 있습니다.

```
무거운 군화 소리가 들려온다. 또각— 또각—
한 남자가 뒷짐을 진 채 계단을 오른다.
복도 양옆 철문 틈마다 억눌린 신음이 새어 나온다. 남자가 걸음을 멈춘다.
```

이건 컷 하나가 아니라 넷입니다. 「문장마다 한 컷」은 이걸 넷으로 나눕니다.

- **줄바꿈을 먼저 지킵니다.** 그래야 `또각— 또각—` 이 앞 문장에 붙습니다.
- `뚝.` `끼이익—` 같은 **소리 조각은 앞 문장에 붙입니다.** 따로 떼면 그릴 것이 없는 컷이 되니까요.
  단, 혼자 한 문단을 차지하면 작가가 일부러 세운 인서트로 보고 그대로 둡니다.
- 컷마다 **용도**를 정하고 거기서 샷·렌즈·길이가 따라 나옵니다 —
  인물이 나오면 미디엄샷 5초, 사물·소리면 인서트 3초, 대사면 미디엄 클로즈업.
- 대본 끝에 붙는 **역주·해설은 컷으로 만들지 않습니다.**
  지문은 한다체(오른다·멈춘다), 역주는 합쇼체(있습니다·합니다)로 갈립니다.
  존댓말 대사도 합쇼체라, `▶ ※ ■` 표시가 먼저 나온 뒤에만 적용합니다.

실제 장편 시나리오에서 문단 방식은 가장 긴 컷이 728자였지만,
문장 방식은 **가장 긴 컷이 88자**입니다. 컷 하나가 프롬프트 하나가 되려면 이 정도여야 합니다.

### 배경 먼저 · 인물 먼저

각 씬의 맨 앞에 **인물이 없는 빈 공간** 컷 하나와, 그 씬에 나오는 **인물마다 단독 판**을 세웁니다.

| 컷 | 무엇을 하나 | 프롬프트에 자동으로 붙는 것 |
|---|---|---|
| **배경 판** | 공간만 먼저 확정 | `empty location, no people` · `--no person, people, crowd, figure` |
| **인물 판** | 인물만 먼저 확정 | `single person, one character only` · 외형 고정 블록 |

인물 판에는 인물 고정 블록이 들어가고, 배경 판에는 들어가지 않습니다.

### 일관성 — 만든 배경·인물을 이어지는 씬이 물려받게

같은 장소가 여러 씬에 걸쳐 나옵니다 (백동성의 집 — 외관 · 현관 · 부엌 · 거실).
씬마다 배경을 새로 뽑으면 같은 집이 매번 다른 집이 됩니다.

1. **같은 장소의 배경 판은 한 번만 만듭니다.**
   실제 시나리오에서 씬 69개 → 배경 판 47개. 나머지 22개 씬은 앞서 만든 판을 씁니다.
2. 배경 판을 뽑고 나온 **참조 코드나 이미지 주소**를 씬 카드의 `--sref` 칸에 넣으면,
   **그 장소의 모든 컷**에 자동으로 붙습니다.
3. 인물 판도 같습니다. 캐릭터 카드의 `--oref` 칸에 넣으면
   **그 인물이 나오는 모든 컷**에 붙습니다. `--ow` 로 닮음 정도까지.
4. 전체 화면 룩에 적어 둔 값이 있어도 **이 컷의 참조가 이깁니다.**
5. 미드저니가 아닌 도구(Veo · 런웨이)에는 코드가 없으니 말로 적어 줍니다 —
   `Reference: Match the established background plate for this location and the established character plate for 동훈.`

### 잔인해서 이미지가 안 만들어질 때

미드저니는 콘텐츠 규정을 **PG-13**으로 두고, gore를
「잘린 신체 부위 · 피 · 폭력 장면 · 훼손된 몸」의 **그림**으로 정의합니다.
프롬프트에 걸리는 낱말이 있으면 아예 생성이 거부됩니다.
DALL·E · Firefly도 같은 방식이고, 필터가 넓게 잡혀서 정상적인 전쟁·역사 장면까지 막힐 때가 많습니다.

그러니 통과시키는 길은 낱말을 감추는 것이 아니라 **그 장면을 화면에 담지 않는 것**입니다.
그리고 이건 우회이기 이전에 **원래 영화가 폭력을 다루는 방식**입니다 —
어둠에 남겨진 것을 관객의 머리가 채워 넣고, 그 상상이 어떤 묘사보다 무섭습니다.

컷에 위험한 낱말이 있으면 프롬프트 화면에 안내가 뜨고, 다섯 가지 중에 고를 수 있습니다.

| 기법 | 화면에 담기는 것 | 화면에 사람이 |
|---|---|---|
| **말만 바꾸기** | 원래 그대로 — 샷도 구도도 안 바뀜 | 그대로 |
| **재료 바꾸기** | 「피」 자리에 고른 재료 — 먹물 · 검은 기름 · 녹물 · 흙탕물 … | 그대로 |
| **무대 티내기** | 촬영 현장 — 특수분장과 조명 장비가 보임 | 그대로 |
| **실루엣** | 원래 행위 — 단, 역광으로 통째 검게 | 있음 (형태만) |
| **그림자** | 벽에 드리운 두 그림자 | 그림자만 |
| **프레임 밖** | 지켜보는 사람의 얼굴 | 있음 (목격자) |
| **직후** | 넘어진 의자, 흐트러진 바닥, 빈 방 | 없음 |
| **사물 인서트** | 떨어진 짚신 한 짝, 젖은 바닥 | 없음 |

- **「재료 바꾸기」** — 「사실은 피인데 토마토 소스라고 부르기」가 아닙니다.
  그건 필터를 속이는 일이고, 실용적으로도 안 먹힙니다 —
  **모델은 적은 대로 그리므로 토마토 소스라고 쓰면 토마토 소스가 나옵니다.**
  여기 있는 것들은 *실제로 화면에 담고 싶은 다른 재료*입니다.
  돌바닥에 번지는 먹물은 피보다 덜 잔인하면서 더 셉니다.
  재료는 **명사만** 넣고 분위기는 별도의 절로 붙입니다 —
  `Drops of black ink falling to the floor, ink spreading slowly through the grain of the stone`.

  > **실제로 써 보고 알아낸 것 — 문제는 낱말이 아니라 색입니다.**
  > `red ink` 는 막혔고 `dark liquid` 는 통과했습니다.
  > 필터는 낱말만 보지 않고 **「붉은 방울이 바닥에 떨어진다」는 구성 자체를 피로 읽습니다.**
  > 그래서 재료 목록은 **색이 없는 것을 위에** 두었습니다. 확실한 순서는 —
  > **어두운 액체 → 먹물 → 젖은 어둠 → 검은 기름 → 흙탕물**

  **그런데 색을 다 빼면 초콜릿처럼 새까맣게 나옵니다.** 그래서 **재료**(무엇인가)와
  **색조**(어떤 색인가)를 따로 고릅니다. `red` 는 막히지만, 어두운 붉은색을 가리키는
  다른 이름들은 막히지 않으면서 색은 제대로 나옵니다.

  | 색조 | 들어가는 낱말 |
  |---|---|
  | 진한 포도주색 | `deep burgundy` |
  | 적갈색 | `dark maroon` |
  | 와인빛 | `wine-dark` |
  | 가넷 | `garnet` |
  | 녹슨 붉은빛 | `iron-oxide` |
  | 마호가니 | `mahogany` |
  | 검붉은 | `blackish crimson` — crimson 은 막힐 수 있음 |

  재료 `liquid` + 색조 `deep burgundy` → **`deep burgundy liquid`**.
  거기에 `warm lamplight catching its surface` 가 자동으로 붙어 표면이 붉게 살아납니다.
- **「말만 바꾸기」가 가장 약하고 대개 이것으로 충분합니다.** 인서트처럼 이미 사물만
  잡는 컷은 화면을 바꿀 이유가 없고, 걸리는 낱말 하나만 바꾸면 됩니다 —
  `Drops of blood falling to the floor` → `Drops of dark liquid falling to the floor`.
  화면에 보이는 것은 똑같습니다.
- 뒤 네 가지는 **지문 자체를 다른 화면으로 갈아끼웁니다.** 낱말만 바꾸면
  `a dark wet stain prisoner` 같은 깨진 문장이 나오고, 무엇보다 잔혹한 행위가
  그대로 프롬프트에 남아 어차피 막힙니다.
- **「화면에 담을 것」** 칸에 직접 적으면 그것이 이깁니다 —
  「바닥에 떨어진 짚신 한 짝, 젖은 마룻바닥」.
- 사람이 없는 기법에서는 인물 고정 블록을 빼고 `--no person, people, figure` 를 붙입니다.
  `single person` 과 부딪치지 않게 그 문구도 함께 뺍니다.
- 실루엣만 원래 지문을 유지하되, 품사를 지켜 순화합니다 —
  `bloodied prisoner` → `dark-stained prisoner`, `hangs upside down` → `is suspended`.
- **배제 목록(`--no`)에는 금지어를 절대 적지 않습니다.** 미드저니는 프롬프트 *텍스트*를 검사하고
  `--no` 도 그 텍스트의 일부라서, `--no blood, gore` 라고 쓰는 순간 금지어를 직접 심는 셈이 됩니다.
  막는 일은 긍정 묘사(빈 방 · 실루엣 · 사물)가 합니다.
- **마지막 청소** — 장소 · 외형 고정 블록 · 스타일 태그 어디에서 흘러들어왔든
  조립이 끝난 프롬프트 전체를 한 번 더 훑습니다. 지문만 순화하면
  `colonial-era torture chamber` 같은 장소가 그대로 남기 때문입니다.
- **남은 낱말을 그 자리에서 보여줍니다** — 「지금 프롬프트에 남아 있는 낱말: …」.
  다 지워지면 「걸릴 낱말이 없습니다 ✓」로 바뀝니다.
- **매체를 통째로 바꾸는 길**도 있습니다. 「스토리보드용으로 보기」를 누르면 연필 콘티가 되어
  사실적 잔혹함 자체가 사라집니다.
- 「이 씬의 위험한 컷에 모두 적용」으로 한 번에 처리할 수 있습니다.

> 이건 규정을 우회하는 장치가 아닙니다. 규정이 막는 것은 **잔혹한 그림**이고,
> 이 다섯 가지는 그 그림을 애초에 그리지 않는 방법입니다.
> 실제로 만들려는 장면이 규정이 금지하는 바로 그것이라면, 이 기능으로도 통과되지 않고 통과되어서도 안 됩니다.

### 인물이 둘일 때 — 누가 어디에, 그리고 의상

두 인물이 한 컷에 있으면 특징이 **쉼표로 뭉뚱그려져** 모델이 섞습니다.
「순사 제복 입은 독립투사」가 나오는 이유입니다.

이제 한 덩어리로 묶어 대비시킵니다.

```
two people — on the left, a Korean man in his late twenties, shaved head,
a pressed dark Japanese police uniform, brass buttons, polished boots;
on the right, a Korean man in his early twenties, torn filthy hemp clothes,
worn thin, rope-marked wrists
```

컷 카드의 **「누가 어디에」** 에서 고릅니다 —
왼쪽·오른쪽 / 앞·뒤 / 서 있는·앉은 / 위·아래.
안 고르면 `the first is … ; the second is …` 로 묶습니다.

### 인물 자료 읽어오기

시나리오만으로는 나이도 인종도 알 수 없습니다. **배우·제작진용 캐릭터 프로필 문서**에는
다 적혀 있고, 그걸 그대로 읽습니다. 「기획 → 캐릭터」의 **「인물 자료 읽어오기」**.

| 문서의 라벨 | 채워지는 칸 |
|---|---|
| 한국 이름 · 일본 이름 · 본명 | 이름 (한국 이름 우선) |
| 직업 · 신분 · 배역 | 역할 |
| 나이 · 연령 (`1944년 기준 46세`) | 나이대 |
| 정체성 · 출생 | 인종 |
| 핵심 성격 | 성격 |
| 언어 · 말투 · 목소리 | 말투 |
| 핵심 욕망 · 공포 · 모순 · 한 줄 정의 | 캐릭터 아크 |

같은 이름이 이미 있으면 **덮어쓰지 않고 빈 칸만** 채웁니다. 여러 개를 한 번에 올려도 됩니다.

**인종은 「정체성」 칸이 가장 셉니다.** 본문 전체를 보면
「감춰야 하는 조선계 혈통」 같은 서사 설명에 걸려 엉뚱한 답이 나옵니다 —
정체성 → 출생 → 이름 → 본문 순으로 좁은 것부터 봅니다.
이름으로도 짐작합니다: `시라후지` → 일본, `백동훈` → 한국.

### 관계 — 누가 누구를 쥐고 있나

**둘 사이가 어떤 사이인지 안 적으면 AI 는 언제나 가장 착한 쪽으로 읽습니다.**
손수건으로 입가를 닦아주는 손은 「돌봐주는 손」이 되고, 무릎을 굽힌 자세는 「간청」이 됩니다.
고문하러 온 순사가 자애로운 청년으로 나옵니다.

컷의 **「더 세밀하게」 → 관계** 에서 고릅니다.

| 관계 | 프롬프트에 붙는 말 |
|---|---|
| 가해 ↔ 당하는 사람 | a scene of power, not of care — one man holds the other and both of them know it |
| 심문 ↔ 끌려온 사람 | an interrogation — one man asks, the other cannot leave |
| 회유 ↔ 버티는 사람 | a false kindness offered by the man who holds the power and refused — the gesture is ownership, not mercy |
| 감시 ↔ 갇힌 사람 | one man is kept, the other keeps him |
| 명령 ↔ 따르는 사람 | rank between them — one speaks, the other complies |
| 배신 ↔ 믿었던 사람 | the trust between them is already broken and only one of them knows how far |
| 대등 · 보호 · 돌봄 | (따뜻한 쪽도 필요하니 남겨둡니다) |

차가운 관계에는 **따뜻한 쪽으로 새지 않게** 배제가 같이 붙습니다 —
`--no comforting, caregiving, rescue, first aid, tender moment, warm golden light, heartwarming …`

그리고 두 사람이 **한 덩어리로 묶여** 누가 누구인지 갈립니다.

```
two people —
  a Korean man in his forties, a pressed dark Japanese police uniform, brass buttons,
    the one offering, wearing a kindness he does not mean,
    sly and self-serving, a small cruelty sitting behind a polite face;
  a Korean elderly man, a jeogori gone grey, baji torn at the knees, bare feet,
    the one refusing it, upright and unbending, meeting the eye
```

**비워두면 지문에서 짐작합니다.** 69개 씬 × 컷마다 손으로 고를 수는 없으니까요.
`때리다 · 짓밟다 · 멱살` → 가해, `취조 · 자백 · 추궁` → 심문,
`철창 · 결박 · 수갑` → 감시, `명령 · 경례` → 명령.
짐작이 틀렸으면 골라서 덮으면 되고, 아예 안 쓰려면 **「없음」** 을 고릅니다.
한글 되짚기에 **「관계 (자동)」** 이라고 표시되니 무엇으로 짐작했는지 보입니다.

`닦아준다 · 손수건 · 달래다` 는 **힘을 쥔 쪽이 있을 때만** 회유로 봅니다.
순사·헌병·간수 같은 역할이 컷에 없으면 어머니가 아이 입가를 닦는 장면이므로 건드리지 않습니다.

### 「분위기 낱말」과 「분위기 묘사」는 다릅니다

앞에서 분위기는 안 걸린다고 했는데, 한 가지 단서가 붙습니다 —
**폭력을 가리키는 이름은 그 자체로 걸립니다.**
`menace` `malice` `threatening` `cruelty` 는 분위기 낱말처럼 보이지만
미드저니에게는 폭력 어휘입니다. 반면 같은 온도를 **묘사로** 쓰면 지나갑니다.

| 걸릴 수 있음 | 대신 |
|---|---|
| an atmosphere of quiet **menace** | the room colder than it looks, everyone in it very still |
| quiet **malice** under a polite surface | a polite surface with nothing kind under it |
| courteous on the surface and **threatening** underneath | formal and correct, and not kindness at all |
| a small **cruelty** behind a polite face | a polite face with nothing kind behind it |

바꾼 쪽이 **더 잘 나옵니다.** 이름은 모델에게 판정만 시키고,
묘사는 화면에 그릴 것을 줍니다.

이제 앱이 프롬프트에 싣는 **긍정 묘사 88개 전부**(공기 · 관계 · 태도 · 의도 · 시대 · 장소)에
폭력 어휘가 하나도 없습니다. `--no` 에 넣는 낱말 **133개**도 마찬가지입니다 —
`--no` 도 검사 대상이라 거기 적은 낱말은 프롬프트에 적은 것과 같습니다.

### 짧게 쓰기 — 프롬프트가 난잡해서 안 나올 때

미드저니는 **앞쪽 낱말에 힘을 싣고, 길어질수록 전부 평균으로 뭉갭니다.**
쉼표를 마흔 개 찍으면 어느 것도 세게 안 나옵니다.

**프롬프트 탭 → 「짧게 쓰기」** 를 누르면 같은 정보를 순서대로 **문장으로 끊고**, 뒤쪽 장식은 버립니다.

```
매체·샷 → 인물 → 인원 → 관계 → 행동 → 장소 → 시대 → 빛 → 공기
```

```
cinematic, film still, close-up shot, low angle looking up.
A Korean man in his thirties in a jeogori in unbleached off-white cotton gone grey,
baji torn at the knees. Upright and unbending. Single person, one character only.
He opens his eyes slowly. Bare windowless basement room, a single bolted chair.
Korea under Japanese colonial rule. Low-key lighting, deep shadows. Hyper-realistic.
--ar 16:9 --style raw --v 7 --no crowd, other people, extra person, …
```

인물 정보를 갖춘 컷 기준으로 **111단어 → 60단어**, 두 사람 컷은 **184단어 → 80단어**.
`--no` 도 열 개로 자릅니다 — **인원 통제를 맨 앞에 두고** 나머지를 채웁니다.

**얼굴 참고 이미지(`--oref`)가 걸린 컷에서는 인물 묘사를 더 줄입니다.**
얼굴은 참고 이미지가 잡는 것이지 프롬프트로 매번 다시 설명할 것이 아닙니다 —
매번 쓰면 **참고 이미지와 싸웁니다.** 그 컷은 46단어까지 줄어듭니다.

### 공기 — 분위기는 금지에 안 걸립니다

**막히는 것은 「분위기」가 아니라 「묘사」입니다.**
미드저니가 거르는 것은 피·상처·잘린 몸을 **화면에 그리라는 지시**이지,
서늘하다·불길하다 같은 **공기 묘사**가 아닙니다.
그래서 마음 놓고 세게 쓸 수 있고, 연출로도 이쪽이 셉니다 — 관객이 스스로 채워 넣으니까요.

컷의 **렌즈 · 조명 · 무드 옆 「공기」** 에서 고릅니다.

| 공기 | 프롬프트에 붙는 말 |
|---|---|
| 서늘한 위압 | an atmosphere of quiet menace, the room colder than it looks |
| 숨 막히는 압박 | oppressive and airless, the walls too close |
| 불길한 예감 | foreboding, something about to happen and everyone in the room knows it |
| 조용한 악의 | quiet malice sitting under a polite surface |
| 사무적인 냉정 | procedural and clinical, unhurried, done many times before |
| 짓눌린 침묵 | a silence with weight in it, nobody moving |
| 무너지기 직전 | strung tight, one moment away from breaking |
| 체념한 공기 | hollowed out, the fight already gone out of the room |
| 낯선 정적 | unnaturally still, wrong in a way nobody names |
| 위협적인 정중함 | courteous on the surface and threatening underneath |
| 차가운 권위 | the cold authority of a place where the rules are not yours |
| 스산한 예감 (호러) | dread, horror atmosphere, the air gone wrong |

여기 있는 말은 **전부 우리 위험어 검사(RISK_RE)를 통과하는지 확인해서** 넣었습니다.
`잔혹한` `광기 어린` 두 개만 **⚠ (조심)** 으로 두었고, 고르면 화면에 경고가 뜹니다 —
막지는 않지만 걸리면 위쪽 안전한 항목으로 바꾸면 됩니다.

**차가운 관계를 골라놓고 공기를 비워두면 그 관계에 맞는 공기가 자동으로 깔립니다.**
가해 → 서늘한 위압, 심문 → 사무적인 냉정, 회유 → 위협적인 정중함,
감시 → 숨 막히는 압박, 명령 → 차가운 권위, 배신 → 조용한 악의.
컷 아래에 무엇이 깔렸는지 한 줄로 보여주고, 안 쓰려면 **「없음」** 을 고릅니다.

### 태도 — 어떤 사람으로 보일까

「기획 → 캐릭터」의 **외형** 아래에 있습니다. 인물마다 한 번만 골라두면 모든 컷에 따라다닙니다.

야비한 · 냉혹한 · 위압적인 · 비굴한 · 광기 어린 · 강직한 · 지친 · 순박한 · 겁먹은 · 자존심 센

**야비한** 을 고르면 `sly and self-serving, a small cruelty sitting behind a polite face`
가 그 인물에게만 붙고, `--no kindly expression, gentle expression, warm smile` 로
친절한 표정 쪽으로 새는 것을 막습니다.
두 인물이 같이 나오는 컷에서 **서로 헷갈리지 않게** 하는 것도 이 값입니다.

### 캐릭터 프롬프트는 어디에 있나

인물이 수십 명이 되면 화면에서 하나씩 펼쳐보기 어렵습니다.
**「설정 · 내보내기 → 캐릭터 프롬프트 CSV」** 로 전부 한 표에 뽑을 수 있습니다 —
이름 · 역할 · 나이 · 성별 · 인종 · 태도 · 의상(한글/영문) · 특징 ·
**고정 블록 전문**(프롬프트에 실제로 들어가는 영문) · 손으로 덮어썼는지 · 등장 씬 수.
엑셀에서 한눈에 비교하고, 어긋난 인물만 골라 고치면 됩니다.

저장은 **이 브라우저 안**입니다. 서버로 올라가지 않고 계정도 없습니다.

- 글자(캐릭터 · 씬 · 컷 · 프롬프트) → `localStorage` 의 `scenedeck_v1` 키 하나
- 이미지 → `IndexedDB` 의 `scenedeck` 데이터베이스

주소마다 · 브라우저마다 따로입니다. 그래서 **브라우저 데이터를 지우면 같이 날아갑니다.**
「설정 → JSON으로 내보내기」 파일 하나에 이미지까지 전부 들어가니 그걸 백업으로 쓰세요.
남은 용량은 「설정」 맨 위 막대에서 볼 수 있습니다.

### 인원수 못 박기 — 두 명인데 넷이 나올 때

예전에는 **혼자일 때만** 인원수를 못 박았습니다. 둘 이상이면 아무 제한이 없어서
모델이 뒤쪽 문간을 알아서 사람으로 채웠습니다.

```
exactly two people in the entire frame, no one else, the background empty of people
--no crowd, other people, background people, bystanders, onlookers,
     figures in the background, people in the doorway, group of people
```

지문에 이름 없는 단역이 있는 컷(「others in frame wear …」)에서는 서로 부딪치므로 붙이지 않습니다.

### 시대 잠금 — 1940년대에 데님 재킷이 나오지 않게

시대를 골라도 AI 는 금방 현대로 샙니다. 데님 재킷, 지퍼, 가슴 플랩 포켓, 찢어진 청바지.
그래서 시대마다 **이 시대의 옷감과 색**을 못 박고, 시대에 없던 것을 배제합니다.

```
Era: Korea under Japanese colonial rule, 1930s to 1940s.
     period-accurate 1940s Korea under Japanese rule.
     unbleached off-white cotton and hemp gone grey with wear,
     indigo and persimmon-brown the only dyes.
     hand-stitched seams, cloth ribbon ties instead of buttons on Korean dress.
--no denim, jeans, zipper, snap buttons, chest flap pockets, cargo pockets,
     hoodie, t-shirt, sneakers, wristwatch, printed fabric, synthetic fabric,
     neon colour, bright yellow
```

**시대 목록에 역사 시대를 넣었습니다** — 조선 후기 · 대한제국 · 일제강점기 ·
해방 직후 · 한국전쟁 · 1950년대 · 1960년대. 예전에는 1970년대가 가장 오래된 항목이라
1940년대 조선을 고를 방법이 아예 없었습니다.

#### 고증 — 1940년대 조선의 옷과 색

- 서민의 옷은 **백의(白衣)**. 표백하지 않은 무명·삼베라 **희끄무레한 회백색**이고
  입을수록 잿빛으로 죽습니다. **노란 옷이 아닙니다.**
- 염료가 비싸 색은 **쪽빛(indigo)** 과 **감물빛(persimmon brown)** 정도였습니다.
- 1940년 조선총독부 제20호로 백의 착용을 「악습」이라 금지했고,
  1941년부터 여성에게 **몸뻬**를 강요했습니다. 남자는 1940년 칙령으로
  **국방색 국민복**에 전투모와 각반.
- **저고리는 단추가 없습니다.** 긴 **고름**으로 여미고 목에 흰 **동정**을 답니다.
  바지는 통이 넓고 발목을 **대님**으로 묶습니다.

그래서 영문 프롬프트에서 `jacket` `trousers` 같은 서양 옷 이름을 버리고
**`jeogori` `baji` 와 생김새 설명**을 씁니다 — 이게 데님 재킷이 나오던 진짜 원인이었습니다.

```
a jeogori — a short Korean jacket ending at the waist, closed with a long cloth
ribbon tie and no buttons, a narrow white collar band at the neck — in unbleached
off-white cotton gone grey, sleeves worn sheer; baji — wide Korean trousers
gathered and tied at the ankle, torn at the knees; bare feet
```

### 역할만 적으면 알아서 채워집니다

캐릭터의 **이름이나 역할**을 적으면 잠깐 뒤에 **의상 · 나이 · 성별**이 저절로 채워집니다.
버튼을 누를 필요가 없습니다.

```
역할에 「순사」 입력
  → 나이 30대 · 성별 남성 · 의상 자동
  → 외형 고정 블록
     a man in his thirties, a pressed black wool police tunic with five brass
     buttons, matching black wool trousers with a sharp crease, knee-high
     polished black leather boots, a stiff peaked cap
  → 그 인물이 나오는 모든 컷 프롬프트에 그대로 삽입
  → 3패널 시트 프롬프트에도 같은 의상
```

**나이를 채우는 게 중요합니다.** 비워 두면 고정 블록이 `a person` 이나 `a Korean man`
으로만 나가서 컷마다 나이가 달라집니다.

성별은 **확실한 역할에만** 넣습니다 — 할아버지·소녀·간호사처럼요.
독립투사·의사·회사원처럼 성별이 정해지지 않은 역할은 비워 둡니다. 작가가 정할 몫이니까요.

> **손으로 고친 값은 절대 덮어쓰지 않습니다.** 자동으로 넣었던 값 그대로일 때만 갱신하고,
> 한 번이라도 직접 고치면 그 뒤로는 건드리지 않습니다.
> 되돌리고 싶으면 토스트의 「되돌리기」를, 다시 채우려면 「역할로 다시 채우기」를 누르세요.

### 의상 자동 채우기

의상을 매번 손으로 쓰기는 번거롭습니다. 캐릭터 카드의 **「역할로 의상 채우기」** 를 누르면
**역할과 시대**를 보고 채워줍니다. 맘에 안 들면 그 자리에서 고치면 됩니다.

**상의 · 하의 · 신발 · 소품**을 색과 질감까지 적습니다.

| 역할 | 채워지는 것 |
|---|---|
| 순사 | 상의 — 빳빳하게 다린 **검정 모직** 정복, 놋쇠 단추 다섯 · 하의 — 같은 검정 모직 바지, 칼주름 · 무릎까지 오는 **광낸 검정 가죽** 장화 · 챙 달린 정모 |
| 독립투사 | 상의 — **누렇게 바랜 무명** 저고리, 소매가 해져 속이 비침 · 하의 — **잿빛 무명** 바지, 무릎이 찢김 · 맨발 · 손목에 붉은 밧줄 자국 |
| 망나니 | 상의 — 소매 없는 **거친 삼베** 조끼, 맨 팔 · 하의 — 잿빛 삼베 통바지, 종아리를 끈으로 동임 · **붉은 무명** 머리띠 · 짚신 |
| 기생 | 상의 — **연분홍 명주** 짧은 저고리, 자주색 고름 · 하의 — **짙은 남색** 치마, 종 모양 · 노리개 · 쪽 찐 머리에 비녀 |

`a pressed black wool police tunic with five brass buttons, matching black wool
trousers with a sharp crease, knee-high polished black leather boots, a stiff peaked cap`

순사·헌병·일본군·독립투사·죄수·망나니·양반·농민·기생·무당·스님·의사·간호사·형사·
변호사·학생·선생·사장·회사원·노숙인·할아버지·할머니·아이·어머니·아버지까지 있습니다.
역할이 비어 있으면 **시대**로, 그것도 없으면 **나이·성별**로 채웁니다 —
이름도 역할도 없는 인물을 그냥 두면 매 컷 다른 옷을 입고 나오기 때문에,
무엇이든 정해 주는 편이 낫습니다.

### 지문 속 단역

`아이 하나가 목을 조르는 시늉을 하며` `의료진이 분주히 오간다` —
**캐릭터로 등록하지 않은 사람들**입니다. 그냥 두면 모델이 매 컷 아무 옷이나 입힙니다.

지문에서 역할 낱말을 찾아 그 역할의 의상을 한 줄 얹습니다.

```
others in frame wear a knee-length white cotton coat over a pale blue shirt
and dark tie, grey slacks, a silver stethoscope around the neck;
a pale mint cotton scrub top, matching trousers, a white cap, white sneakers
```

- 한글과 **영문 지문 둘 다** 읽습니다 (`의사`·`doctor`, `간호사`·`nurse`).
- 이미 등록된 인물이 맡은 역할은 건너뜁니다 — 순사가 등록돼 있으면 `officer` 는 세지 않습니다.
- 단역이 있는 컷에서는 `single person` 을 빼서 서로 부딪치지 않게 합니다.
- 「프롬프트 → 전체 화면 룩」에서 끌 수 있습니다.

항목마다 **정돈된 쪽(crisp)과 남루한 쪽(worn)** 이 구분돼 있고 소품이 하나씩 박혀 있습니다 —
`놋쇠 단추 · 광낸 장화` ↔ `밧줄 자국 · 맨발`. 이 대비가 두 인물을 갈라줍니다.

인물이 둘 이상인 컷에서는 **「비어 있는 의상 자동으로 채우기」** 로 한 번에 됩니다.

> 밖으로 아무것도 보내지 않는 앱이라 AI 를 부르지 않습니다. 역할·시대 사전으로 찾습니다 —
> 대본의 배역은 생각보다 정해져 있고, 중요한 건 화려한 문장이 아니라 두 인물이 갈리는 것이니까요.

**의상이 진짜 열쇠입니다.** 인물이 둘 이상인데 의상이 비어 있으면
경고가 뜹니다. 그리고 「낡은 옷」 정도로는 부족합니다 —

| 이렇게 쓰면 섞임 | 이렇게 쓰면 갈림 |
|---|---|
| `hemp clothes` | `torn filthy hemp clothes, worn thin, rope-marked wrists` |
| `police uniform` | `a pressed dark Japanese police uniform, brass buttons, polished boots` |

**낡음의 정도와 재질까지** 적어야 제복과 갈립니다.
한쪽이 「빳빳하게 다린」이면 다른 쪽은 「해져서 얇아진」처럼 **반대로** 써주세요.

### 같은 동작, 반대의 뜻 — 「의도」 칸

`동훈이 무릎을 꿇는다` — 이건 굴복일 수도, **상대를 올려다보며 압박하는 위협**일 수도 있습니다.
동작만 주면 모델은 늘 굴복 쪽으로 그립니다. 그게 흔한 그림이니까요.

컷 카드의 **「이 동작의 의도 — 문맥」** 칸이 그걸 뒤집습니다.

| 의도 | 프롬프트에 붙는 것 | 배제되는 것 |
|---|---|---|
| 위협 — 겁주려는 것 | `a deliberate act of intimidation, controlled and unafraid, in command of the moment` | `anguish, crying, distressed expression, pleading, fear` |
| 우위 — 여유 | `calm and unhurried, in command of the room` | `anguish, panic` |
| 조롱 — 비웃음 | `faintly amused, contemptuous, a mocking half-smile` | `anguish, crying, fear` |
| 복종 — 굴복 | `submissive, head lowered, yielding` | `defiant, smiling` |

경계 · 숨김 · 결심 · 무심 · 애원 · 체념 · 두려움 · 슬픔도 있습니다.

**배제가 핵심입니다.** 긍정 문구만으로는 모델이 흔한 쪽으로 새기 때문에,
반대 감정을 `--no` 로 함께 막아야 의도대로 나옵니다.

### 앞 컷 문맥 — 영상 프롬프트

영상(Veo · 런웨이)에는 **앞 컷이 무엇이었는지**가 함께 나갑니다.

```
Context: this shot follows — he looks down at the seated man without blinking.
Intent:  A deliberate act of intimidation, controlled and unafraid.
```

앞 컷이 「노려본다」였다면 이어지는 무릎 꿇기를 굴복으로 읽지 않습니다.

### 장소가 막을 때 — 방 이름 대신 방 안에 뭐가 있는지

`고문실` `torture chamber` 는 **장소 칸**에 들어가므로, 걸리면 **그 씬의 컷이 전부** 막힙니다.
컷마다 순화하는 것으로는 못 잡습니다. 그래서 씬 카드에서 바로 잡습니다.

요령은 **방 이름을 대지 않는 것**입니다.

| 대신 | 프롬프트에 들어가는 문구 |
|---|---|
| 창 없는 지하실 — 의자 하나와 바닥 배수구 | `bare windowless basement room, a single bolted chair, a floor drain, one caged bulb` |
| 물 얼룩진 돌방 | `bare stone room, water-stained walls, a single hanging bulb` |
| 책상 하나뿐인 방 | `plain room with one table and two chairs, harsh overhead light` |

화면에는 **같은 방**이 나옵니다. 오히려 더 정확하게 나옵니다 —
「고문실」이라는 낱말보다 「의자 하나와 바닥 배수구」가 훨씬 구체적인 지시이기 때문입니다.

걸리는 장소를 쓰면 씬 카드에 안내가 뜨고, 대체안을 **누르면 그 자리에서 바뀝니다.**
사형장 · 처형장 · 교수대 · 영안실 · 감방도 같은 방식으로 준비돼 있습니다.

> 판정은 **장소 칸**만 봅니다. 씬 제목에 「고문실」이 남아 있어도 괜찮습니다 —
> 제목은 화면에만 있고 프롬프트에는 들어가지 않으니까요.

### 영문 프롬프트 밑의 한글 되짚기

영어로만 나오면 **어느 칸이 어떤 문구가 됐는지** 알 수 없습니다.
그래서 프롬프트 바로 밑에 한글 되짚기를 답니다.

```
무엇으로   영화 스틸           cinematic, film still
화면       인서트 · 아이레벨     insert shot, tight detail, eye-level angle
인물       동훈                a Korean man in his early twenties, Japanese police uniform
이 컷만    얼굴 — 뺨에 튄 자국
순화       재료 바꾸기 · 어두운 액체 · 진한 포도주색   deep burgundy liquid
내용       바닥으로 떨어지는 핏방울.   Drops of dark liquid falling to the floor.
장소·시간  조선총독부 경찰국 · 밤
빛 · 무드  로우키 · 긴장        low-key lighting, tense, suspenseful atmosphere
설정       화면비 16:9 · v7 · 사진처럼
빼는 것    --no  extra person, duplicate face, …
```

**기계 번역이 아닙니다.** 프롬프트를 이 앱이 조립하므로 재료를 그대로 되짚습니다 —
번역보다 정확하고, **무엇을 고치면 무엇이 바뀌는지**가 바로 보입니다.

- 「내용」 줄에는 **실제로 프롬프트에 들어간 영문**이 붙습니다.
  순화를 켜면 원문(`핏방울`)과 실제 문구(`dark liquid`)가 달라지는 것이 그대로 보입니다.
- 영상 쪽(Veo · 런웨이)에는 **카메라 4단 · 사건 · 길이 · 대사 · 사운드**가 더 붙습니다.

### 이 컷에서만 바뀌는 것 — 얼굴 · 의상 · 행동

캐릭터 원본은 그대로 두고 **이 컷에만** 얹는 칸입니다.

| 칸 | 예 | 프롬프트에서 |
|---|---|---|
| 얼굴 · 표정 변화 | 눈물 자국, 뺨에 튄 피 | 고정 블록 바로 뒤 |
| 의상 변화 | 젖은 순사 제복, 찢어진 소매 | 고정 블록 바로 뒤 |
| 행동 변화 | 칼을 천천히 들어 올린다 | 지문 뒤 |

**적는 즉시 프롬프트가 다시 조립됩니다.** 한글로 적으면 영문 칸도 저절로 채워집니다.

### 카메라 4단 — 무브먼트 · 속도 · 프레이밍 유지 · 종료 지점

장면 묘사와 카메라 지시를 한 문장에 섞으면 둘 다 흐려집니다.
컷 카드의 **카메라 4단** 칸은 넷을 따로 받아서 영상 프롬프트 맨 앞에 한 줄로 세웁니다.

```
Camera move: Slow dolly in toward the subject, natural dynamic motion,
keeping the subject centered in frame, ending on a close-up of the face.
```

| 단 | 무엇을 정하나 |
|---|---|
| ① 무브먼트 | 이름 있는 동작 하나 — `dolly in`, `arc shot` |
| ② 속도 | `slow` · `steady` · `fast` — 같은 달리 인도 속도가 감정을 바꿉니다 |
| ③ 프레이밍 유지 | 움직이는 동안 무엇을 계속 잡고 있는가 |
| ④ 종료 지점 | 어디서 끝나는가 |

- **종료 지점을 비우면 마지막 1초가 무너집니다.** 어디서 멈출지 모르는 모델은
  클립 끝에서 표류하거나, 다 온 자리에서 한 번 더 밀고 들어가 구도를 깹니다.
- **한 컷에 무브먼트는 하나만.** 달리 인 하면서 동시에 아크로 돌고 크레인으로
  올리라고 쓰면 모델이 셋을 평균 내서 아무 동작도 아닌 것을 만듭니다.
  두 개가 필요하면 두 컷으로 나누세요.

무브먼트를 고르면 그 아래에 **연출 의도**가 한 줄로 뜹니다 —
「배경만 어긋난다. 깨달음의 순간, 현기증.」 이름이 아니라 이 의도를 보고 고르면 됩니다.

### 컷 길이 — 감이 아니라 용도가 정한다

컷 카드의 **컷 용도**를 고르면 권장 길이가 자동으로 들어갑니다.

| 컷 용도 | 권장 길이 |
|---|---|
| 인서트 · 사물 클로즈업 | 3–4초 |
| 인물 이동 · 액션 | 5–7초 |
| 설정샷 (장소 소개) | 5–8초 |
| 감정선 · 대사 | 7–10초 |
| 롱테이크 | 10초 이상 (무브먼트는 여전히 하나만) |

**15–30초를 한 번에 생성하지 마세요.** 30초 클립에서 27초 지점이 마음에 안 들면
30초를 통째로 다시 뽑아야 합니다. 5초 단위로 쪼개 만들면 고칠 때 5초만 다시 뽑습니다 —
**수정 비용이 4분의 1**로 떨어집니다. 붙이는 일은 편집 타임라인이 합니다.

관절선(목·팔꿈치·무릎·발목)에 프레임 하단이 걸리면 인물이 잘려 보이므로,

### 매체 · 만드는 도구

| 매체 | 맨 앞 | 도구 칸에서 고르는 것 |
|---|---|---|
| 영화 스틸 · 다큐 · 에디토리얼 · 광고 · 90년대 DVD | `cinematic, film still` 등 | **카메라 · 렌즈** (해셀블라드 · Nikon FA · VHS · 슈퍼 8 · 홀가 · 시아노타입 …) |
| 스토리보드 스케치 · 콘티 마커화 | `pencil sketch for storyboard` | 연필 · 마커 · 펜 · 목탄 |
| 동화 일러스트 · 수채화 · 유화 · 콘셉트 아트 | `masterpiece oil painting` 등 | 세이블 붓 · 임파스토 · 냉압지 · 과슈 · 매트페인팅 |
| 플랫 벡터 | `flat vector graphic illustration` | 평면 도형 · 굵은 라인 · 그라디언트 |
| 3D 애니메이션 | `3d animation still` | Cinema 4D · 언리얼 5 · 블렌더 · 클레이 |
| 애니메이션 스틸 | `anime film still` | 셀 애니메이션 · 디지털 채색 |

**「스토리보드용으로 보기」 버튼**은 장면묘사를 그대로 두고 **맨 앞 목적만** 연필 스케치로 바꿉니다.
초안을 스케치로 돌려보고, 확정되면 다시 눌러 실제 소스용으로 되돌리는 교안의 작업 순서 그대로입니다.

### 사건(트리거) — 영상에서 제일 중요한 한 칸

컷의 **「더 세밀하게」**를 열면 인물 감정 · 카메라 속도 · 빛 효과 · **사건**을 고를 수 있습니다.

> **사건을 비워두면 카메라만 움직이고 장면은 그대로 있습니다.** 무언가 *일어나게* 하려면
> 갑자기 나타난다 · 빛나기 시작한다 · 무너져 내린다 · 밀려든다 · 빨려 들어간다 … 를 골라주세요.
> 교안이 VFX 파트에서 강조하는 부분이고, 실제로 영상 결과가 가장 크게 갈리는 지점입니다.

### 인물 일관성 — 인종 한 칸이 제일 강하다

캐릭터에 **인종 · 민족**을 고르면 외형 고정 블록 맨 앞이 `a Korean man in his forties`처럼 바뀝니다.
교안이 정리한 권역별 표현(한국 · 일본 · 한족 · 인도 · 아랍 / 슬라브 · 게르만 · 켈트 · 북유럽 /
베르베르 · 줄루 · 하우사 / 마오리 · 사모아 / 나바호 · 이누이트 · 마야 …)을 그대로 씁니다.

### 같은 스타일로 계속 뽑기 — `--sref` · `--oref`

| | 무엇을 붙잡나 |
|---|---|
| **`--sref`** | **화풍**. 코드를 적어두면 다음 컷도 같은 톤. **두 개를 섞으면** 자기만의 색이 나옵니다. `random` 버튼도 있습니다 |
| **`--oref` + `--ow`** | **인물**. 미드저니에 올린 사진 주소를 넣습니다. 닮은 정도는 70(자유) / 100(기본) / 300(얼굴 고정) |

> `--oref` 는 미드저니 **v7 이상**에서 동작합니다. 예전 `--cref` 를 대체한 방식이에요.

## 🖼️ 미드저니로 바로 작업하기

「프롬프트」 탭에서 **어디에 쓸 건지 하나만 고르면** 그 카드만 펼쳐집니다 — 셋을 동시에 보며 고민할 필요가 없어요.

- **그냥 사이트만 열기** — 「어디에 쓸 건가요」 아래에 미드저니 · 디스코드 · Flow · ImageFX · Bing **바로가기 링크 줄**이 항상 떠 있습니다.
  복사 없이 사이트만 보고 싶을 때 쓰세요. 진짜 링크라서 우클릭 → 새 탭도 됩니다.
- **📋 복사하고 미드저니 열기** — 프롬프트가 클립보드에 담기고 미드저니가 새 탭으로 열립니다. 입력창에 `Ctrl+V` 하고 Enter.
  이것도 `<a href>` 링크라 **팝업 차단에 걸리지 않습니다.** 프롬프트가 비어 있어도 사이트는 그대로 열려요.
- **🪟 옆에 띄워두고 작업** — 미드저니를 화면 오른쪽 절반에 띄웁니다. 왼쪽 이 창에서 `←` `→` 로 컷을 넘기며 반복하세요.
- **한글 → 영문 자동 번역** — **한글 칸에 쓰고 잠깐 멈추면 옆 영문 칸이 저절로 채워집니다.**
  버튼도 모달도 없습니다. **컷 지문 · 씬 장소 · 캐릭터 의상/특징 · 빠른 입력** 전부에 걸려 있어요.
  - **손으로 쓴 영문은 절대 덮어쓰지 않습니다.** 자동으로 채운 칸에만 「어떤 한글에서 나왔는지」를 적어두고,
    그 한글이 바뀌었을 때만 다시 번역합니다. 영문을 직접 고치면 그 칸은 그때부터 건드리지 않아요
  - 크롬 내장 번역(온디바이스)이라 **글자가 컴퓨터 밖으로 나가지 않고** 요금도 없습니다
  - 언어팩은 처음 한 번만 받습니다. 브라우저가 사용자 동작을 요구하면 「번역 켜기」 한 번만 눌러주세요
  - 「설정 → 번역 엔진」에서 끌 수 있습니다
- **한글 경고** — 그래도 프롬프트에 한글이 남으면 알려줍니다. 이때 버튼이 하는 일은 브라우저에 따라 다릅니다.
  - **크롬 138 이상(내장 번역 가능)** — 「영문으로 바꾸기」 한 번이면 **그 자리에서 번역해 영문 칸을 채웁니다.** 창도 안 뜹니다.
  - **그 외 브라우저** — 자동 번역이 없다는 사실을 **누르기 전에** 알려주고, 버튼이
    「번역 요청문 복사」 + 「AI 답변 붙여넣기」로 바뀝니다.
    (예전엔 눌러야 비로소 「복붙하세요」를 만나는 막다른 길이었습니다)
- **미드저니 설정** — `--ar` `--style` `--stylize` `--v` 를 외울 필요 없이 버튼으로 고릅니다.

| 버튼 | 붙는 값 |
|---|---|
| 화면비 | `--ar 16:9` `9:16` `1:1` … |
| 느낌 — 사진처럼 / 그림처럼 | `--style raw` / (없음) |
| 스타일 강도 — 약 / 보통 / 강 | `--stylize 50` / (없음) / `--stylize 600` |
| 버전 — v7 / v6.1 / 니지 | `--v 7` / `--v 6.1` / `--niji 6` |

「미드저니가 처음이신가요? — 4단계」 가이드가 카드 안에 접혀 있습니다.

### ⚠️ 미드저니는 유료입니다

무료 체험이 없습니다. 계정을 만들어도 **구독을 해야 이미지가 나옵니다.**
그래서 **「그 외 이미지 AI」** 카드에 무료로 쓸 수 있는 곳 바로가기를 넣었습니다.

| 어디 | 비용 | 버튼 |
|---|---|---|
| 미드저니 | 유료 구독 | 📋 복사하고 미드저니 열기 |
| Google Flow (Veo) | 유료 | 📋 복사하고 Flow 열기 |
| **Google ImageFX** | 구글 계정만 있으면 **무료** | 📋 복사하고 ImageFX 열기 |
| **Bing 이미지 크리에이터** | MS 계정만 있으면 **무료** | 📋 복사하고 Bing 열기 |

무료 쪽은 `--ar` 같은 파라미터를 쓰지 않으므로 **범용 프롬프트**가 복사되고,
화면비는 그 사이트에서 직접 고르면 됩니다. **문장 자체는 그대로 통합니다.**

### 이 버튼들이 실제로 하는 일

- 브라우저가 할 수 있는 건 **클립보드에 넣기 + 새 창 열기**까지입니다.
  미드저니 웹은 주소로 프롬프트를 미리 채워 넣는 방법을 공개하지 않았고,
  **iframe 삽입은 미드저니·디스코드가 서버에서 막아두어** 이 페이지 안에 끼워 넣을 수 없습니다.
- 그래서 두 동작을 한 버튼으로 묶었습니다. 사용자에게 남는 건 **붙여넣기 한 번**입니다.
- 팝업이 차단되면 안내 문구가 뜹니다. 「옆에 띄워두고 작업」은 데스크톱 전용이라 모바일에선 숨깁니다.
- 클립보드는 **`execCommand('copy')`를 먼저** 쓰고, 실패하면 `navigator.clipboard`로 넘어갑니다.
  순서가 반대였을 땐 프레임 안에서 `navigator.clipboard`가 「Document is not focused」로 거절되는데,
  그 거절이 **비동기**라 대체 방법이 실행될 즈음엔 이미 클릭(사용자 동작)이 끝나 함께 막혔습니다.
  복사가 끝내 막히면 **주소를 미리 선택해 두어** `Ctrl+C` 만 누르면 되게 합니다.

## 🔒 핵심 — 외형 고정 블록

AI 영상의 최대 난관은 **캐릭터가 매 컷마다 딴 사람이 되는 것**입니다.

「캐릭터」 탭에서 나이·성별·머리·눈·체형을 고르면 이런 영문 블록이 자동 생성됩니다.

```
a man in his forties, short black hair, dark brown eyes,
slender build, worn grey trench coat, scar through left eyebrow
```

이 블록이 **모든 컷 프롬프트에 토씨 하나 안 틀리고 똑같이** 들어갑니다.
컷에서 등장인물 칩만 켜두면 자동이에요.

### 캐릭터 시트는 정확히 3패널

고정 블록만으로 부족할 때는 **레퍼런스 이미지**를 씁니다.
이때 전면·측면·후면에 무기 도해와 표정 모음까지 한 장에 몰아넣은 시트는
AI 입장에서 **여러 명이 한 화면에 있는 그림**으로 읽힙니다.
그 시트를 레퍼런스로 넣는 순간 컷마다 얼굴이 섞입니다 — **도플갱어 현상**.

「캐릭터」 카드의 **3패널 시트 프롬프트** 버튼은 세 장을 따로 뽑아줍니다.

| 패널 | 무엇을 담나 |
|---|---|
| ① 전신 정면 | 머리를 지운 마네킹 — 의상 실루엣과 소재 |
| ② 전신 후면 | 등판 — 뒤에서 잡을 컷의 근거 |
| ③ 얼굴 클로즈업 | 이목구비 단독 — 인물 동일성의 유일한 출처 |

①②에 얼굴이 들어가면 ③과 경쟁합니다. 저해상도로 찌그러진 전신 속 얼굴이
클로즈업의 얼굴을 오염시키기 때문에, 머리를 아예 지웁니다.
**의상이 바뀌면 ①②만 다시 뽑고 ③은 원본을 재사용**하세요.
얼굴 출처가 하나로 유지되는 한 인물은 유지됩니다.

### 프롬프트 락

시트를 규격대로 만들어도, 프롬프트가 열려 있으면 모델은 인물을 하나 더 만들어 넣습니다.
「프롬프트 → 전체 화면 룩」의 **프롬프트 락**을 켜두면 (기본값 켬)

- 인물이 **한 명인 컷**에 `single person, one character only` 이 자동으로 붙고
- `extra person · duplicate face · multiple views · collage · crowd` 가 배제 목록에 들어갑니다

배경 제한을 빼먹는 것이 가장 흔한 사고입니다.
배경이 열려 있으면 군중이 생기고, 군중이 생기면 그중 하나가 주인공 얼굴을 나눠 갖습니다.

> 미드저니 파라미터 칸에 `--no` 를 직접 써두었다면 그쪽을 존중하고 자동 추가는 하지 않습니다.

## 📄 이미 쓴 원고가 있다면

「대본 · 컷」 탭에 **파일을 끌어다 놓으세요.** 씬 단위로 알아서 쪼개집니다.

| 형식 | 지원 |
|---|---|
| `.txt` `.md` | ✅ |
| `.docx` (워드) | ✅ 라이브러리 없이 직접 읽습니다 |
| `.fdx` (파이널 드래프트) | ✅ 인물·대사를 「이름: 대사」로 합쳐 읽습니다 |
| `.pdf` | ⚠️ **종류를 탑니다** — 아래 참고 |
| `.hwp` (한글) | ❌ 워드나 PDF로 저장해서 올려주세요 |

**PDF는 두 종류가 있습니다.**

- ✅ **워드·한글에서 「PDF로 저장」한 것** — 글자가 데이터로 들어있어 읽힙니다
- 🖼️ **스캔하거나 사진 찍은 것** — 글자가 아니라 그림입니다. 이때는 **페이지 그림을 꺼내주고
  글자로 바꾸는 길을 안내**합니다 (아래 「사진 PDF」 참고)

읽어낸 결과가 깨져 보이면 **그냥 넣지 않고 알려드립니다.** 억지로 이상한 글자를 집어넣지 않아요.
한글 PDF는 글자를 코드번호로 저장하고 변환표(ToUnicode)를 따로 들고 있는데, 그 표까지 해석합니다.

**직접 만든 시험용 PDF 3종으로 검증했습니다.**

| 종류 | 결과 |
|---|---|
| 일반 PDF (폰트·표가 그대로 노출) | ✅ 한글 그대로 |
| **객체 스트림(ObjStm) PDF** — 워드 · 한글 · 리브레오피스가 실제로 만드는 형식 | ✅ (예전엔 **한 글자도 못 읽었습니다**) |
| 스캔본 (JPEG 이미지만) | 🖼️ 사진임을 알려주고 페이지 그림을 꺼내줍니다 |

> PDF 1.5부터는 폰트 정보를 압축된 **객체 스트림** 안에 몰아넣는 게 기본이고,
> 워드·한글이 만드는 PDF는 거의 다 이 방식입니다. 그 스트림을 풀지 않으면
> 「글자 → 코드번호」 변환표를 찾지 못해 **한글이 통째로 사라집니다.** 그게 원인이었습니다.

### 🖼️ 사진 PDF (스캔본)

글자 데이터가 없으면 **페이지 그림을 꺼내고** 안내 카드를 띄웁니다.

- **🖼️ 페이지 그림 내려받기** — PDF 안의 JPEG를 페이지별로 저장합니다
- **📄 구글 드라이브로 글자 뽑기** — PDF를 드라이브에 올리고 **우클릭 → 연결 프로그램 → Google 문서**.
  한글 정확도가 가장 좋고 무료입니다
- **🔍 Google 렌즈** · ChatGPT · Claude에 그림을 넣고 「글자를 그대로 옮겨 적어줘」
- 받은 글자는 **📋 뽑은 글자 붙여넣기**로 넣으면 씬 분해로 이어집니다

> 이 앱은 밖으로 아무것도 보내지 않아서 **글자 인식(OCR)을 직접 하지는 못합니다.**
> 한글 인식 데이터만 수십 MB라 파일 하나에 담을 수 없습니다. 대신 위 경로가 확실합니다.

**알아보는 씬 머리글 — 42가지를 시험했습니다**

사람마다 쓰는 방식이 다르고, AI가 준 답을 그대로 붙여넣으면 마크다운까지 얹혀 옵니다.
그래서 **장식을 먼저 걷어낸 뒤** 넉넉한 규칙으로 맞춥니다.

| 형태 | 예 |
|---|---|
| 표시 + 번호 | `S#1` `S1` `s1` `S 1` `S-1` `S_1` `SC1` `SC 1` `SC#1` `SCENE 1` |
| 한글 | `씬 1` `씬1` `씬#1` `제1씬` `제 1 씬` `1씬` `장면 1` `장면1` |
| 번호만 | `#7` `1.` `12.` |
| 영문식 | `INT. 뒷골목 - NIGHT` `EXT.` `I/E.` `실내` `실외` |
| 장식이 붙어도 | `## S#1.` `**S#1.**` `- S#1.` `> S#1` `[S#1]` `(S#1)` `【S#1】` `「S#1」` `Ｓ＃１` |
| 구분자 아무거나 | `S#1. 뒷골목` `S#1: 뒷골목` `S#1 - 뒷골목` `S#1 — 뒷골목` |

반대로 **지문을 씬으로 착각하지 않습니다.**
`1985년 겨울, 그는…` `3초 뒤 문이 열린다` `20년 전 이야기다` 처럼
숫자 뒤에 바로 글자가 붙으면 씬으로 세지 않아요. (번호만 있는 형태는 `1.` `12)` 처럼
**구분자가 붙었을 때만** 인정합니다)

장소와 시간대(낮·밤·새벽·NIGHT·DAWN…)를 자동으로 뽑아냅니다.
맨 앞의 제목·작가명은 씬으로 세지 않고, **비어 있으면 작품 제목으로 채워줍니다.**

**등장인물 목록을 씬으로 세지 않습니다**

원고 맨 앞에 이런 목록이 흔합니다.

```
[등장인물]
1. 망나니
2. 할아버지
...
S#1. 프롤로그 - 日本 - ○○ 병원 복도
```

**원고에 `S#1.` 같은 진짜 머리글이 하나라도 있으면, `1.` `2.` 같은 맨번호는 씬으로 세지 않습니다.**
대신 맨 앞부분을 따로 떼어 **「맨 앞 11줄은 씬이 아니라 등장인물 목록으로 보입니다 — 망나니 · 할아버지 …」**
라고 알려주고, **「캐릭터로 등록」** 한 번이면 인물이 만들어집니다.

**장소·시간도 더 똑똑하게 뽑습니다**

| 머리글 | 뽑아내는 값 |
|---|---|
| `S#1. 프롤로그 - 日本 - ○○ 병원 복도` | 장소 **○○ 병원 복도** (「프롤로그」는 이름표라 건너뜀) |
| `S#3. 日本 - 종문의 집 - 외관 (N)` | 장소 **종문의 집** · 시간 **밤** |
| `S#4. 병원 병실 (D)` | 장소 **병원 병실** · 시간 **정오** |
| `S#2. 타이틀 시퀀스⇥■ 나레이션은…` | 탭·문서기호 뒤는 잘라냄 |

`(N)` `(D)` `(M)` `(E)` 같은 시간 약어를 읽고, 조각이 여럿이면 **가장 구체적인 것**을 장소로 봅니다.

**틀렸을 때 고칠 수 있습니다 — 이게 더 중요합니다**

세상의 모든 대본 형식을 맞히겠다고 약속할 수는 없습니다. 대신 **틀리면 바로 보이고 바로 고쳐집니다.**

- 미리보기의 각 줄에 **「✕ 씬 아님」** — 잘못 잡힌 줄을 앞 씬에 도로 붙입니다. 「처음으로」로 되돌리기도 됩니다
- 결과가 미덥지 않으면 **앱이 먼저 의심합니다** — 「씬 하나당 본문이 평균 12자뿐입니다 — 목록을 씬으로 셌을 수 있어요」,
  「씬 머리글을 하나도 못 찾았습니다」, 「씬 대부분에서 장소를 못 뽑았습니다」
- 그래도 안 맞으면 **「빈 줄로 나누기」 · 「통째로 한 씬으로」**

**머리글이 아예 없어도 넣을 수 있습니다**

찾지 못하면 원고의 첫 줄들을 보여주며 **왜 못 찾았는지** 알려주고, 두 가지 길을 줍니다.

| 버튼 | 결과 |
|---|---|
| **빈 줄로 나누기** | 빈 줄을 경계로 토막내고 각 토막의 첫 줄을 씬 제목으로 |
| **통째로 한 씬으로** | 나누지 않고 전부 한 씬에 |

그다음 할 수 있는 것:

- **🎬 모든 씬을 컷으로 쪼개기** — 지문 문단 하나 = 컷 하나, 대사 한 줄 = 컷 하나로 **전 씬 일괄** 변환
  (씬 하나만 처리하려면 「씬별 원고 편집」의 「이 씬만 컷으로 쪼개기」)
- **🤖 이 씬 수정 요청문** — 이 씬만 집중해서 고쳐달라는 질문지
- **📥 고친 대본 붙여넣기** — AI가 고친 대본을 되돌려 넣으면 씬 번호를 찾아 해당 씬만 갈아끼웁니다
- **전체 대본 검토 / 대사 살리기** — 뺄 씬 판정, 설명조 대사 색출, 인물별 말투 구분 점검

### 어떤 머리글을 알아보나

| 형태 | 예 |
|---|---|
| 번호 표시 | `S#1.` `S1` `씬 1` `제1씬` `제1화` `#7` `SCENE 3` `SC 3` |
| 회차 · 막 | `1화` `1장` `1막` `EP.1` `PART 1` `CHAPTER 1` |
| 괄호 번호 | `1.` `1)` `[1]` `<1>` `【1】` |
| 영문 대본 | `INT. 골목 - 밤` `EXT. ALLEY - NIGHT` `실내. 골목 - 밤` |
| **번호 없는 장소 + 시간** | `골목 / 밤` `교실 - 낮` `기억 상점 (심야)` `비 내리는 뒷골목 · 밤` `옥상, 새벽` |
| **시간 약어** | `日本 - 백동성의 집 - 외관 (N)` `韓国 - 경찰국 (D)` `병원 수술실 (D/N)` |
| **라벨** | `프롤로그 - 병원 복도` `타이틀 시퀀스` `에필로그` `몽타주` |
| 전환 (다른 게 없을 때만) | `CUT TO - 수술실 안` `FLASH BACK — 병원 진료실` `INTER CUT - …` |

아래 세 줄이 실제 대본에서 제일 흔한데, 번호도 INT./EXT. 표시도 없어서
예전에는 못 잡고 원고 전체가 통짜 한 씬이 됐습니다. 지금은 잡습니다.

실제 장편 시나리오 `.docx` (77,000자)로 확인 — **씬 69개**, 본문 중앙값 816자,
가장 짧은 씬도 263자. 제목·등장인물 목록 24줄은 씬으로 세지 않고 앞부분으로 뺐습니다.

> **탭으로 칸을 나눈 대본** — 대본은 `인물⇥대사` 처럼 탭으로 칸을 나눠 쓰고,
> 머리글 뒤에도 `프롤로그 - 병원 복도 ⇥ ■ 표시는 일본어 대사입니다` 처럼 메모가 붙습니다.
> 머리글은 **첫 칸만** 보고, 대사는 **콜론과 탭을 모두** 알아봅니다.
> (같은 파일에서 대사 438줄 · 인물 12명을 뽑았습니다)

본문 문장을 잘못 물지 않도록, 구분자로 쪼갠 조각 중 하나가 **순수한 시간 표현**일 때만
머리글로 봅니다. 그래서 `밤이 깊었다.` `그는 밤에, 골목을 걸었다` `창밖은 이미 밤이었다`
`회상 - 10년 전 밤` 은 전부 본문으로 남습니다.

### 앞부분의 등장인물 목록

첫 머리글보다 위에 있는 내용은 씬으로 세지 않고, 거기서 **인물 이름을 뽑아** 줍니다.
`1. 망나니` 같은 번호 목록과 `백동훈: 白藤 勲` 같은 콜론 형식을 모두 알아봅니다.
「캐릭터로 등록」을 누르면 그대로 캐릭터가 만들어져요.
(`등장인물` `각본` `감독` 같은 소제목은 사람으로 세지 않습니다)

### 머리글이 하나도 없으면 — 생김새로 알아서 나눕니다

표시를 하나도 못 찾아도 통짜 한 덩어리로 떨어뜨리지 않습니다.
원고의 구조를 보고 세 가지를 순서대로 시도합니다.

1. **빈 줄 사이에 홀로 선 짧은 줄** — 생김새가 같은 것만 (제일 흔한 형태)
2. **빈 줄 뒤의 짧은 줄** + 그 아래로 더 긴 본문이 이어지는 경우
3. **빈 줄이 아예 없는 원고**에서 짧고 문장이 아닌 줄
   (전체 줄의 40%를 넘으면 포기합니다 — 본문을 씬으로 셀 순 없으니까)

셋 다 실패하면 그때만 한 씬이 됩니다. 산문 한 덩어리는 나누지 않는 게 맞으니까요.
자동으로 나눴을 때는 미리보기 위에 **「머리글 표시가 없어서 — …로 봤습니다」** 라고 알려줍니다.

또 본문이 한 글자도 없는 첫 덩어리는 씬이 아니라 **작품 제목**으로 보고 앞부분으로 넘깁니다.

### 그래도 어긋나면 — 「여기부터 — 줄 직접 고르기」

원고 형식은 사람마다 다르고, 자동 인식은 언젠가 반드시 어긋납니다.
그럴 때 「분해 미리보기」 아래의 **「여기부터 — 줄 직접 고르기」** 를 누르세요.

원고가 줄 번호와 함께 펼쳐지고, **씬이 시작하는 줄을 직접 누르면** 그 줄이 씬 제목이 되고
다음 표시 전까지가 그 씬의 본문이 됩니다.

**첫 표시보다 위에 있는 내용은 씬으로 만들지 않습니다** —
작품 제목 · 등장인물 목록 · 기획의도를 여기서 잘라낼 수 있어요.

한 줄만 누르면 나머지는 앱이 찾아줍니다.

| 버튼 | 하는 일 |
|---|---|
| **비슷한 줄 모두 고르기** | 방금 누른 줄과 **같은 형태**의 줄을 원고 전체에서 찾습니다 |
| 빈 줄 다음 줄 모두 | 빈 줄 바로 다음 줄을 전부 고릅니다 |
| 자동 인식대로 | 앱이 처음 찾아낸 머리글로 되돌립니다 |
| 모두 해제 | 표시를 전부 지웁니다 |

「비슷한 줄」이 보는 것은 이름이 아니라 **형태**입니다.

- `◆1화 객잔 앞 / 낮` 을 누르면 → 숫자로 시작하는 줄을 전부
- `EXT. BACK ALLEY - NIGHT` 을 누르면 → INT./EXT. 줄을 전부
- `비 내리는 뒷골목 · 밤` 처럼 표시가 아예 없으면 →
  **빈 줄 사이에 홀로 선 짧은 줄** 중에서, 구분자(`·` `/` `-`)와 시간대 단어가
  같은 방식으로 붙어 있고 문장부호로 끝나지 않는 줄만 고릅니다.
  (그래서 본문 한 문장이 씬 제목으로 딸려 들어가지 않습니다)

고른 결과는 「분해 미리보기」에 그대로 나오므로, 확인하고 「✓ 적용」을 누르면 됩니다.

>
> ⚠️ **이 앱이 다른 페이지 안(iframe)에 끼워져 있으면 공유 링크를 만들지 않습니다.**
> 그 자리에서 만든 주소는 바깥 페이지가 아니라 **안쪽 화면의 주소**라 남에게 보내도 열리지 않기 때문입니다.
> 만든 척하지 않고 사실대로 알려주고, **JSON 백업**과 **따로 열어 쓰는 법**을 안내합니다.

만든 시각이 함께 표시되고(`08/10 17:20 시점`), 모달에도 그렇게 적혀 있습니다.

| 받은 사람이 고치면 | 그쪽 브라우저에만 남습니다. 이쪽으로 돌아오지 않아요 |
| 링크 유효기간 | 없습니다. 내용이 주소 안에 통째로 들어 있어서, **올려둔 사이트가 살아 있는 한** 계속 열립니다 |
| 내 작업 | 이 브라우저에 계속 남습니다. 새로고침해도, 창을 닫았다 열어도 그대로예요 |

| | |
|---|---|
| 담기는 것 | 제목 · 스토리 · 캐릭터 · 씬 · 컷 · 화면 룩 · 미드저니 설정 |

## 🧩 한 씬을 한 장으로 뽑고 싶을 때

컷으로 잘게 나누면 프롬프트도 여러 개로 쪼개집니다.
**한 장면을 한 장으로** 뽑고 싶으면 방식을 골라주세요.

| 방식 | 결과 |
|---|---|
| **문단 · 대사마다 한 컷** | 지문 문단 하나 = 컷 하나, 대사 한 줄 = 컷 하나 (기본) |
| **씬 하나당 한 컷 (전문 통째로)** | 씬 본문을 합쳐 **프롬프트 한 개**. 대사는 Veo의 Audio 줄로 들어감 |

- 「대본 · 컷」 탭 **「컷까지 한 번에」** 카드의 드롭다운에서 고르고 「모든 씬을 컷으로 만들기」
- 「프롬프트」 탭에서는 씬 고르개 옆의 **「문단마다 한 컷」 ↔ 「씬 전문 한 컷」** 을 눌러
  **몇 번이든 왔다갔다 하며 비교**할 수 있습니다. 한 번 누르면 못 돌아가는 게 아니에요
- 방식을 바꿔도 **직전 것을 버리지 않습니다** — 손으로 고쳐둔 지문까지 그대로 기억했다가
  돌아오면 되돌려줍니다 (이번에 열어둔 동안 유지)

## 🧰 기술 메모

- `index.html` 한 파일에 HTML·CSS·JS 전부 인라인. 빌드 없음, 외부 라이브러리 없음
- `fonts/` 폴더만 외부 에셋 (`@font-face` 상대경로, `file://`에서 동작 확인).
  `local()`을 먼저 보므로 폰트가 설치돼 있으면 폴더가 없어도 적용되고, 둘 다 없으면 시스템 고딕으로 대체
- 저장: `localStorage['scenedeck_v1']` + IndexedDB `scenedeck` / `img` 스토어
- 탭 상태는 주소 해시(`#prompt`)와 `localStorage['scenedeck_tab']`에 함께 기록 — 링크 공유와 새로고침 복원용.
  옛 탭 이름은 `TABMAP`으로 새 탭에 매핑
- 미드저니 파라미터는 `S.mj`(느낌·강도·버전) + `S.style.ar`을 `mjParams()`가 조립해 `S.style.mj`에 쓴다.
  수동 입력칸은 「전체 화면 룩」 안에 고급 항목으로 남겨둠
- 화면 밝기는 `<html data-theme>` + `localStorage['scenedeck_theme']`. 색은 전부 CSS 변수로만 정의(하드코딩 색 0개)
- 「빠른 입력」은 임시 씬·컷 객체를 즉석에서 만들어 기존 `buildMJ/buildVEO/buildGEN`에 그대로 태운다. 입력값은 `S.quick`에 보관
- 레이아웃: 1180px 컨테이너 / 820px·720px 두 단계 반응형. 가로 스크롤 없음
- 무거운 목록(씬 목록 · 스토리보드)은 화면에 들어올 때만 그린다.
  컷 300개 기준 「대본 · 컷」 탭 전환이 6.5초 → 0.23초
- 확인창은 `confirm()` 대신 자체 `ask()` 모달 — iframe에서 브라우저가 confirm을 막는다
- PDF는 객체 스트림(/Type /ObjStm)을 풀어 그 안의 폰트 객체까지 훑는다.
  글자가 없으면 /Subtype /Image + DCTDecode 스트림을 JPEG 표식으로 확인해 꺼낸다
- 문법 검사:
  ```
  node -e "const fs=require('fs');const h=fs.readFileSync('scenedeck/index.html','utf8');const m=h.match(/<script>([\s\S]*)<\/script>/);new Function(m[1]);console.log('JS syntax OK');"
  ```
