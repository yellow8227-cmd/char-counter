# 🎬 SCENEDECK · 씬덱

시나리오부터 AI 프롬프트까지 한 자리에서 굴리는 워크벤치.
**설치도 인터넷도 필요 없습니다** — `index.html`을 더블클릭하면 바로 열려요.

## 🚀 시작하기

**① 파일로 쓰기** — `index.html` 더블클릭. 끝. (크롬·엣지 아무거나)

**② 웹 주소로 쓰기** — GitHub Pages를 켜면 링크로 바로 열립니다.
저장소 **Settings → Pages → Source: `Deploy from a branch`** 로 브랜치를 고르면
`https://<계정>.github.io/char-counter/scenedeck/` 주소가 만들어집니다.
주소만 있으면 폰이든 남의 컴퓨터든 그냥 열려요.

> ⚠️ `fonts/` 폴더가 같이 있으면 제목이 손글씨체로 나옵니다.
> 없어도 **동작에는 아무 문제가 없고**, 시스템 고딕으로 자동 대체됩니다.

## 🏠 홈 화면

첫 화면은 안내용 **홈**입니다 — 무엇을 할 수 있는지, 어떤 파일을 넣을 수 있는지,
지금 작업이 어디까지 왔는지(씬·컷·캐릭터 수)를 한눈에 보여줍니다.
카드를 누르면 그 작업 탭으로 바로 넘어가요.

탭을 옮기면 주소 끝이 `#prompt` 처럼 바뀝니다. **그 주소를 그대로 북마크·공유**하면
다음에 열 때 같은 탭으로 열리고, 그냥 새로고침해도 마지막에 보던 화면으로 돌아옵니다.

## ⚡ 가장 빠른 길

**원고가 있을 때** — 「대본 · 컷」 탭에 파일을 끌어다 놓고 **①「✓ 적용」 ②「🎬 모든 씬을 컷으로 쪼개기」** 두 번만 누르면 끝입니다.
전 씬이 컷으로 나뉘고 **샷 · 앵글 · 렌즈 · 조명 · 길이까지 자동으로 채워져서**, 「프롬프트」 탭에 가면 바로 복사할 문장이 나와 있습니다.

| 자동 배분 규칙 | |
|---|---|
| 씬의 첫 컷 | 장소를 보여주는 **롱샷** · 24mm · 5초 |
| 대사 컷 | **미디엄 클로즈업** · 85mm · 대사 길이에 맞춘 초 |
| 중간 지문 컷 | 미디엄샷 · 35mm · 4초 |
| 씬의 마지막 컷 | **클로즈업** · 85mm · 푸시 인 |
| 조명 · 분위기 | 씬의 시간대에서 유추 (밤 → 로우키/긴장, 새벽 → 블루아워, 해질녘 → 골든아워 …) |

이미 컷이 있는 씬은 건드리지 않습니다. 마음에 안 들면 토스트의 **「되돌리기」** 한 번으로 전부 취소됩니다.

**원고도 씬도 없을 때** — 「프롬프트」 탭에서 **⚡ 빠른 입력**을 고르세요.
「무슨 일이 벌어지나요」 한 줄만 적으면 세 가지 프롬프트가 바로 나옵니다. 씬도 컷도 만들 필요가 없어요.
장소 · 시간대 · 샷 · 조명은 원하는 것만 고르면 되고, 캐릭터 칩을 켜면 **외형 고정 블록**도 그대로 들어갑니다.
쓸 만하면 「💾 이 내용을 컷으로 저장」으로 남겨두면 보드 · 스케줄표 · 내보내기에서도 함께 쓰입니다.

## 🗺️ 탭 안내 — 5개

탭이 8개일 땐 어디서부터 손대야 할지 알기 어려웠습니다. 하는 일이 겹치는 것끼리 묶어 **5개**로 줄였습니다.

| 탭 | 하는 일 | 옛 탭 |
|---|---|---|
| 🏠 **홈** | 기능 안내 · 현재 작업 요약 · 바로가기 | — |
| ✍️ **기획** | 로그라인 → 시놉시스 → 3막 → 씬 리스트, 캐릭터 **외형 고정 블록** | 스토리 + 캐릭터 |
| 🎬 **대본 · 컷** | **원고 올려 씬 자동 분해 → 전 씬 일괄 컷 생성** · 씬/컷 손보기 · 스토리보드 | 대본 + 씬·컷 + 보드 |
| ✨ **프롬프트** | 미드저니 · Veo(Flow) · 범용 3종. **복사하고 바로 열기** · 씬·컷 없이 뽑는 「빠른 입력」 | 프롬프트 |
| ⚙️ **설정** | 저장 용량, JSON 백업, CSV·TXT 내보내기 | 설정 |

합쳐진 탭 안에서는 맨 위의 **섹션 바로가기**로 건너뜁니다.
탭 아래쪽에는 **「다음 →」** 버튼이 있어 기획 → 대본·컷 → 프롬프트 순서가 자연스럽게 이어집니다.
옛 주소(`#story` `#board` …)로 들어와도 새 탭으로 알아서 보내줍니다.

## 🖼️ 미드저니로 바로 작업하기

「프롬프트」 탭에서 **어디에 쓸 건지 하나만 고르면** 그 카드만 펼쳐집니다 — 셋을 동시에 보며 고민할 필요가 없어요.

- **그냥 사이트만 열기** — 「어디에 쓸 건가요」 아래에 미드저니 · 디스코드 · Flow · ImageFX · Bing **바로가기 링크 줄**이 항상 떠 있습니다.
  복사 없이 사이트만 보고 싶을 때 쓰세요. 진짜 링크라서 우클릭 → 새 탭도 됩니다.
- **📋 복사하고 미드저니 열기** — 프롬프트가 클립보드에 담기고 미드저니가 새 탭으로 열립니다. 입력창에 `Ctrl+V` 하고 Enter.
  이것도 `<a href>` 링크라 **팝업 차단에 걸리지 않습니다.** 프롬프트가 비어 있어도 사이트는 그대로 열려요.
- **🪟 옆에 띄워두고 작업** — 미드저니를 화면 오른쪽 절반에 띄웁니다. 왼쪽 이 창에서 `←` `→` 로 컷을 넘기며 반복하세요.
- **한글 경고** — 프롬프트에 한글이 섞이면 알려줍니다. 이때 버튼이 하는 일은 브라우저에 따라 다릅니다.
  - **크롬 138 이상(내장 번역 가능)** — 「🌐 영문으로 바꾸기」 한 번이면 **그 자리에서 번역해 영문 칸을 채웁니다.** 창도 안 뜹니다.
  - **그 외 브라우저** — 자동 번역이 없다는 사실을 **누르기 전에** 알려주고, 버튼이
    「📋 번역 요청문 복사」 + 「📥 AI 답변 붙여넣기」로 바뀝니다.
    (예전엔 눌러야 비로소 「복붙하세요」를 만나는 막다른 길이었습니다)
- **미드저니 설정** — `--ar` `--style` `--stylize` `--v` 를 외울 필요 없이 버튼으로 고릅니다.

| 버튼 | 붙는 값 |
|---|---|
| 화면비 | `--ar 16:9` `9:16` `1:1` … |
| 느낌 — 사진처럼 / 그림처럼 | `--style raw` / (없음) |
| 스타일 강도 — 약 / 보통 / 강 | `--stylize 50` / (없음) / `--stylize 600` |
| 버전 — v7 / v6.1 / 니지 | `--v 7` / `--v 6.1` / `--niji 6` |

「미드저니가 처음이신가요? — 4단계」 가이드가 카드 안에 접혀 있습니다.

### ⚠️ 미드저니는 유료입니다

무료 체험이 없습니다. 계정을 만들어도 **구독을 해야 이미지가 나옵니다.**
그래서 **「🎨 그 외 이미지 AI」** 카드에 무료로 쓸 수 있는 곳 바로가기를 넣었습니다.

| 어디 | 비용 | 버튼 |
|---|---|---|
| 미드저니 | 유료 구독 | 📋 복사하고 미드저니 열기 |
| Google Flow (Veo) | 유료 | 📋 복사하고 Flow 열기 |
| **Google ImageFX** | 구글 계정만 있으면 **무료** | 📋 복사하고 ImageFX 열기 |
| **Bing 이미지 크리에이터** | MS 계정만 있으면 **무료** | 📋 복사하고 Bing 열기 |

무료 쪽은 `--ar` 같은 파라미터를 쓰지 않으므로 **범용 프롬프트**가 복사되고,
화면비는 그 사이트에서 직접 고르면 됩니다. **문장 자체는 그대로 통합니다.**

### 이 버튼들이 실제로 하는 일

- 브라우저가 할 수 있는 건 **클립보드에 넣기 + 새 창 열기**까지입니다.
  미드저니 웹은 주소로 프롬프트를 미리 채워 넣는 방법을 공개하지 않았고,
  **iframe 삽입은 미드저니·디스코드가 서버에서 막아두어** 이 페이지 안에 끼워 넣을 수 없습니다.
- 그래서 두 동작을 한 버튼으로 묶었습니다. 사용자에게 남는 건 **붙여넣기 한 번**입니다.
- 팝업이 차단되면 안내 문구가 뜹니다. 「옆에 띄워두고 작업」은 데스크톱 전용이라 모바일에선 숨깁니다.
- 클립보드는 `navigator.clipboard` → 실패 시 `execCommand('copy')` 순으로 두 겹입니다.

## 🔒 핵심 — 외형 고정 블록

AI 영상의 최대 난관은 **캐릭터가 매 컷마다 딴 사람이 되는 것**입니다.

「캐릭터」 탭에서 나이·성별·머리·눈·체형을 고르면 이런 영문 블록이 자동 생성됩니다.

```
a man in his forties, short black hair, dark brown eyes,
slender build, worn grey trench coat, scar through left eyebrow
```

이 블록이 **모든 컷 프롬프트에 토씨 하나 안 틀리고 똑같이** 들어갑니다.
컷에서 등장인물 칩만 켜두면 자동이에요.

## 📄 이미 쓴 원고가 있다면

「대본 · 컷」 탭에 **파일을 끌어다 놓으세요.** 씬 단위로 알아서 쪼개집니다.

| 형식 | 지원 |
|---|---|
| `.txt` `.md` | ✅ |
| `.docx` (워드) | ✅ 라이브러리 없이 직접 읽습니다 |
| `.fdx` (파이널 드래프트) | ✅ 인물·대사를 「이름: 대사」로 합쳐 읽습니다 |
| `.pdf` | ⚠️ **종류를 탑니다** — 아래 참고 |
| `.hwp` (한글) | ❌ 워드나 PDF로 저장해서 올려주세요 |

**PDF는 두 종류가 있습니다.**

- ✅ **워드·한글에서 「PDF로 저장」한 것** — 글자가 데이터로 들어있어 읽힙니다
- 🖼️ **스캔하거나 사진 찍은 것** — 글자가 아니라 그림입니다. 이때는 **페이지 그림을 꺼내주고
  글자로 바꾸는 길을 안내**합니다 (아래 「사진 PDF」 참고)

읽어낸 결과가 깨져 보이면 **그냥 넣지 않고 알려드립니다.** 억지로 이상한 글자를 집어넣지 않아요.
한글 PDF는 글자를 코드번호로 저장하고 변환표(ToUnicode)를 따로 들고 있는데, 그 표까지 해석합니다.

**직접 만든 시험용 PDF 3종으로 검증했습니다.**

| 종류 | 결과 |
|---|---|
| 일반 PDF (폰트·표가 그대로 노출) | ✅ 한글 그대로 |
| **객체 스트림(ObjStm) PDF** — 워드 · 한글 · 리브레오피스가 실제로 만드는 형식 | ✅ (예전엔 **한 글자도 못 읽었습니다**) |
| 스캔본 (JPEG 이미지만) | 🖼️ 사진임을 알려주고 페이지 그림을 꺼내줍니다 |

> PDF 1.5부터는 폰트 정보를 압축된 **객체 스트림** 안에 몰아넣는 게 기본이고,
> 워드·한글이 만드는 PDF는 거의 다 이 방식입니다. 그 스트림을 풀지 않으면
> 「글자 → 코드번호」 변환표를 찾지 못해 **한글이 통째로 사라집니다.** 그게 원인이었습니다.

### 🖼️ 사진 PDF (스캔본)

글자 데이터가 없으면 **페이지 그림을 꺼내고** 안내 카드를 띄웁니다.

- **🖼️ 페이지 그림 내려받기** — PDF 안의 JPEG를 페이지별로 저장합니다
- **📄 구글 드라이브로 글자 뽑기** — PDF를 드라이브에 올리고 **우클릭 → 연결 프로그램 → Google 문서**.
  한글 정확도가 가장 좋고 무료입니다
- **🔍 Google 렌즈** · ChatGPT · Claude에 그림을 넣고 「글자를 그대로 옮겨 적어줘」
- 받은 글자는 **📋 뽑은 글자 붙여넣기**로 넣으면 씬 분해로 이어집니다

> 이 앱은 밖으로 아무것도 보내지 않아서 **글자 인식(OCR)을 직접 하지는 못합니다.**
> 한글 인식 데이터만 수십 MB라 파일 하나에 담을 수 없습니다. 대신 위 경로가 확실합니다.

**알아보는 씬 머리글**

```
S#1. 비 내리는 뒷골목 / 밤      ← 한국식
씬 3  |  #7  |  12. 폐병원 로비
INT. HOSPITAL LOBBY - DAWN     ← 영문식
```

장소와 시간대(낮·밤·새벽·NIGHT·DAWN…)를 자동으로 뽑아냅니다.
맨 앞의 제목·작가명은 씬으로 세지 않고, **비어 있으면 작품 제목으로 채워줍니다.**

그다음 할 수 있는 것:

- **🎬 모든 씬을 컷으로 쪼개기** — 지문 문단 하나 = 컷 하나, 대사 한 줄 = 컷 하나로 **전 씬 일괄** 변환
  (씬 하나만 처리하려면 「씬별 원고 편집」의 「이 씬만 컷으로 쪼개기」)
- **🤖 이 씬 수정 요청문** — 이 씬만 집중해서 고쳐달라는 질문지
- **📥 고친 대본 붙여넣기** — AI가 고친 대본을 되돌려 넣으면 씬 번호를 찾아 해당 씬만 갈아끼웁니다
- **전체 대본 검토 / 대사 살리기** — 뺄 씬 판정, 설명조 대사 색출, 인물별 말투 구분 점검

## 🧩 한 씬을 한 장으로 뽑고 싶을 때

컷으로 잘게 나누면 프롬프트도 여러 개로 쪼개집니다.
**한 장면을 한 장으로** 뽑고 싶으면 방식을 골라주세요.

| 방식 | 결과 |
|---|---|
| **문단 · 대사마다 한 컷** | 지문 문단 하나 = 컷 하나, 대사 한 줄 = 컷 하나 (기본) |
| **씬 하나당 한 컷 (전문 통째로)** | 씬 본문을 합쳐 **프롬프트 한 개**. 대사는 Veo의 Audio 줄로 들어감 |

- 「대본 · 컷」 탭 **「⚡ 컷까지 한 번에」** 카드의 드롭다운에서 고르고 「모든 씬을 컷으로 만들기」
- 「프롬프트」 탭에서는 씬을 고른 뒤 **「📄 씬 전문을 한 컷으로」** — 이미 쪼개둔 씬도
  **「다시 만들기」**로 한 컷짜리로 갈아끼울 수 있고, 마음에 안 들면 「되돌리기」

## 🎯 씬만 있고 컷이 없을 때

「프롬프트」 탭 맨 위 **씬 고르개**에서 씬을 고르면, 컷이 없는 씬은
그 자리에서 **「🎬 이 씬을 컷으로 쪼개기」** 버튼이 나타납니다.
탭을 옮겨 다닐 필요 없이 **고르고 → 누르고 → 바로 프롬프트**입니다.

대사만 있는 컷은 예전엔 「무엇을 그릴지」가 비어 프롬프트가 장소·카메라만 남았습니다.

## 🧰 기술 메모

- `index.html` 한 파일에 HTML·CSS·JS 전부 인라인. 빌드 없음, 외부 라이브러리 없음
- `fonts/` 폴더만 외부 에셋 (`@font-face` 상대경로, `file://`에서 동작 확인).
  `local()`을 먼저 보므로 폰트가 설치돼 있으면 폴더가 없어도 적용되고, 둘 다 없으면 시스템 고딕으로 대체
- 저장: `localStorage['scenedeck_v1']` + IndexedDB `scenedeck` / `img` 스토어
- 탭 상태는 주소 해시(`#prompt`)와 `localStorage['scenedeck_tab']`에 함께 기록 — 링크 공유와 새로고침 복원용.
  옛 탭 이름은 `TABMAP`으로 새 탭에 매핑
- 미드저니 파라미터는 `S.mj`(느낌·강도·버전) + `S.style.ar`을 `mjParams()`가 조립해 `S.style.mj`에 쓴다.
  수동 입력칸은 「전체 화면 룩」 안에 고급 항목으로 남겨둠
- 화면 밝기는 `<html data-theme>` + `localStorage['scenedeck_theme']`. 색은 전부 CSS 변수로만 정의(하드코딩 색 0개)
- 「빠른 입력」은 임시 씬·컷 객체를 즉석에서 만들어 기존 `buildMJ/buildVEO/buildGEN`에 그대로 태운다. 입력값은 `S.quick`에 보관
- 레이아웃: 1180px 컨테이너 / 820px·720px 두 단계 반응형. 가로 스크롤 없음
- 무거운 목록(씬 목록 · 스토리보드)은 화면에 들어올 때만 그린다.
  컷 300개 기준 「대본 · 컷」 탭 전환이 6.5초 → 0.23초
- 확인창은 `confirm()` 대신 자체 `ask()` 모달 — iframe에서 브라우저가 confirm을 막는다
- PDF는 객체 스트림(/Type /ObjStm)을 풀어 그 안의 폰트 객체까지 훑는다.
  글자가 없으면 /Subtype /Image + DCTDecode 스트림을 JPEG 표식으로 확인해 꺼낸다
- 문법 검사:
  ```
  node -e "const fs=require('fs');const h=fs.readFileSync('scenedeck/index.html','utf8');const m=h.match(/<script>([\s\S]*)<\/script>/);new Function(m[1]);console.log('JS syntax OK');"
  ```
