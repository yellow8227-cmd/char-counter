자주 묻는 것

내가 쓴 내용이 어디로 전송되나요?

아닙니다. 모든 내용은 이 브라우저 안에만 저장됩니다 — 텍스트는 localStorage, 이미지는 IndexedDB. 서버로 올라가는 것도, 계정을 만드는 것도 없습니다. 대신 브라우저 데이터를 지우면 같이 날아가니 「설정」에서 JSON 백업을 습관으로 만드세요.

AI가 자동으로 연결되나요?

API 키를 꽂아 사이트 안에서 답을 받는 기능은 아직 없습니다. 대신 각 단계에서 질문지를 만들어 복사해 주니, Claude나 ChatGPT에 붙여넣고 받은 답을 다시 붙여넣으면 됩니다. 돈이 들지 않고 어디서든 동작해요.

이미지는 몇 장까지 넣을 수 있나요?

브라우저가 허용하는 만큼입니다 — 보통 수 GB. 넣는 이미지는 가로 1280px JPEG로 자동 축소되고, 「설정」 탭에서 지금 쓰는 용량을 실시간으로 볼 수 있습니다.

다른 컴퓨터에서 이어서 작업하려면?

「설정 → JSON으로 내보내기」로 파일 하나를 받아 옮긴 뒤, 그쪽에서 「JSON 불러오기」 하세요. 스토리 · 캐릭터 · 컷 · 이미지까지 전부 들어 있습니다.

글씨체가 다르게 보여요

제목용 손글씨체(Griun 602)는 이 PC에 설치돼 있거나 fonts/ 폴더가 파일 옆에 있을 때만 적용됩니다. 없으면 시스템 고딕으로 자동 대체되며, 기능에는 아무 영향이 없습니다.
