컷 프롬프트까지, 한 화면에서

원고를 올리면 씬으로 나뉘고, 버튼 하나면 컷까지 만들어집니다. 급할 땐 한 줄만 적어 프롬프트만 뽑을 수도 있어요. 캐릭터 외형 고정 블록은 모든 컷에 토씨 하나 안 틀리고 들어가서, 컷마다 인물이 딴 사람이 되는 사고를 막아줍니다.

1

원고를 끌어다 놓기

「대본 · 컷」 탭에 파일을 떨구면 씬 단위로 자동 분해됩니다. 이야기부터 만들고 싶으면 「기획」에서 시작해도 돼요.

2

컷으로 쪼개기 — 버튼 하나

「모든 씬을 컷으로 쪼개기」를 누르면 전 씬이 한 번에 컷으로 나뉘고, 샷·조명까지 자동으로 채워집니다.

3

프롬프트 뽑아 쓰기

미드저니 · Veo(Flow) · 범용 이미지 세 문법이 동시에 만들어집니다. 급하면 씬·컷 없이 한 줄만 적어 뽑는 「빠른 입력」도 있어요.

자주 묻는 것

내가 쓴 내용이 어디로 전송되나요?

아닙니다. 모든 내용은 이 브라우저 안에만 저장됩니다 — 텍스트는 localStorage, 이미지는 IndexedDB. 서버로 올라가는 것도, 계정을 만드는 것도 없습니다. 대신 브라우저 데이터를 지우면 같이 날아가니 「설정」에서 JSON 백업을 습관으로 만드세요.

씬·컷 안 만들고 프롬프트만 뽑고 싶어요

「프롬프트」 탭 맨 위에서 ⚡ 빠른 입력을 고르세요. 무슨 일이 벌어지는지 한 줄만 적으면 세 가지 프롬프트가 바로 나옵니다. 씬도 컷도 만들 필요 없어요. 마음에 들면 「이 내용을 컷으로 저장」으로 나중에 이어서 쓸 수도 있습니다.

원고를 올렸는데 컷을 하나하나 만들어야 하나요?

아닙니다. 원고를 적용하면 「대본 · 컷」 탭에 ⚡ 컷까지 한 번에 카드가 나타납니다. 「모든 씬을 컷으로 쪼개기」 한 번이면 전 씬이 컷으로 나뉘고, 샷·조명 자동 배분까지 켜져 있어 프롬프트가 곧바로 쓸 만한 문장으로 나옵니다. 이미 컷이 있는 씬은 건드리지 않아요.

AI가 자동으로 연결되나요?

API 키를 꽂아 사이트 안에서 답을 받는 기능은 아직 없습니다. 대신 각 단계에서 질문지를 만들어 복사해 주니, Claude나 ChatGPT에 붙여넣고 받은 답을 다시 붙여넣으면 됩니다. 돈이 들지 않고 어디서든 동작해요.

이미지는 몇 장까지 넣을 수 있나요?

브라우저가 허용하는 만큼입니다 — 보통 수 GB. 넣는 이미지는 가로 1280px JPEG로 자동 축소되고, 「설정」 탭에서 지금 쓰는 용량을 실시간으로 볼 수 있습니다.

다른 컴퓨터에서 이어서 작업하려면?

「설정 → JSON으로 내보내기」로 파일 하나를 받아 옮긴 뒤, 그쪽에서 「JSON 불러오기」 하세요. 스토리 · 캐릭터 · 컷 · 이미지까지 전부 들어 있습니다.

글씨체가 다르게 보여요

제목용 손글씨체(Griun 602)는 이 PC에 설치돼 있거나 fonts/ 폴더가 파일 옆에 있을 때만 적용됩니다. 없으면 시스템 고딕으로 자동 대체되며, 기능에는 아무 영향이 없습니다.

PDF는 종류를 탑니다. 워드·한글에서 「PDF로 저장」한 건 읽히지만, 스캔하거나 사진 찍은 PDF는 글자가 아니라 그림이라 못 읽어요. 실패하면 알려드립니다. 한글 파일(.hwp)은 지원하지 않으니 워드나 PDF로 저장해서 올려주세요.

① 구글 드라이브 (한글 정확도가 가장 좋습니다 · 무료)
드라이브에 이 PDF를 올린 뒤 파일을 우클릭 → 연결 프로그램 → Google 문서로 열면 글자가 뽑힌 문서로 바뀝니다. 그 글자를 복사해 「뽑은 글자 붙여넣기」에 넣으세요.

② AI에게 그림째로 물어보기
「페이지 그림 내려받기」로 받은 이미지를 ChatGPT · Claude · Google 렌즈에 넣고 「이 이미지의 글자를 그대로 옮겨 적어줘」라고 하면 됩니다.

이 앱은 밖으로 아무것도 보내지 않기 때문에 글자 인식(OCR)을 직접 하지는 못합니다. 한글 인식에 필요한 데이터만 수십 MB라 파일 하나에 담을 수가 없어요. 대신 위 두 길이 확실합니다.

⚡ 컷까지 한 번에 프롬프트 바로 쓰기

문단 · 대사마다 한 컷은 지문 문단 하나 = 컷 하나, 대사 한 줄 = 컷 하나로 잘게 나눕니다. 씬 하나당 한 컷은 씬 전문을 합쳐 프롬프트 한 개로 만듭니다 — 한 장면을 한 장으로 뽑을 때 쓰세요. 샷 · 조명 자동 배분을 켜두면 첫 컷은 장소를 보여주는 롱샷, 대사 컷은 인물 클로즈업, 조명은 씬의 시간대에 맞춰 채워져서 프롬프트가 곧바로 쓸 만한 문장으로 나옵니다. 나중에 언제든 고칠 수 있어요.

이미 컷이 있는 씬은 건드리지 않습니다. 지문이 한글이어도 프롬프트는 나오지만, 「영문 칸 채우기」를 한 번 돌려두면 결과가 눈에 띄게 좋아집니다.

먼저 알아두실 것 — 미드저니는 유료입니다.
무료 체험이 없어서, 계정을 만들어도 구독을 해야 이미지가 나옵니다. 공짜로 먼저 해보고 싶으면 아래 「🎨 그 외 이미지 AI」를 여세요 — ImageFX · Bing은 계정만 있으면 무료고, 프롬프트는 그대로 통합니다.
미드저니가 처음이신가요? — 4단계

1. 위 「복사하고 미드저니 열기」를 누르면 프롬프트가 복사되고 미드저니 창이 새로 열립니다. 첫 방문이면 로그인(구글 또는 디스코드 계정)과 구독 확인을 거칩니다.

2. 미드저니의 입력창을 클릭하고 Ctrl+V(맥은 ⌘+V)로 붙여넣은 뒤 Enter.

3. 이미지가 여러 장 나오면 마음에 드는 것을 골라 크게 뽑습니다(Upscale).

4. 이 창으로 돌아와 ← → 키로 다음 컷으로 넘기고 2번부터 반복하세요. 컷을 넘길 때마다 프롬프트가 새로 조립되니, 「복사하고 열기」 대신 「복사만」을 누르고 옆 창에 붙여넣으면 더 빠릅니다.

창이 안 열리면 주소창 오른쪽의 팝업 차단 아이콘에서 허용해 주세요. 「🪟 옆에 띄워두고 작업」은 창을 나란히 놓을 수 있는 데스크톱에서만 의미가 있습니다.
