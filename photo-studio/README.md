# 증명사진 자판기 (Photo Studio)

두 줄만 맞추면 규격이 나옵니다.

사진관에서 해 주던 일 중에 사실 대부분은 **재는 일**입니다.
얼굴이 32mm인지, 머리 위가 4mm 비었는지. 찍는 것 말고 그 부분은
브라우저에서도 됩니다.

정수리에 한 줄, 턱끝에 한 줄. 그러면 배율과 위치가 정해지고
나머지는 계산입니다.

> 이 저장소의 글자수 세기 도구와는 별개의 프로젝트입니다.
> 나중에 따로 떼어내기 쉽도록 이 폴더 안에만 두었습니다.

## 사진은 어디로도 가지 않습니다

고른 사진은 브라우저 안에서만 처리됩니다. 서버로 올라가지 않고,
새로고침하면 남지 않습니다. 증명사진은 얼굴과 이름이 함께 붙어 다니는
파일이라, 이 도구는 아예 보낼 곳을 만들어 두지 않았습니다.

## 담긴 규격

| 규격 | 크기 | 얼굴 길이 | 머리 위 여백 |
|---|---|---|---|
| 증명 3×4 | 30×40mm | 24~30mm | 3~6mm |
| 여권·취업 3.5×4.5 | 35×45mm | 32~36mm | 3~5mm |
| 반명함 5×7 | 50×70mm | 40~52mm | 5~10mm |
| 미국비자 2×2″ | 51×51mm | 25~35mm | 6~13mm |
| 자유 | 직접 입력 | — | — |

「규격 점검」 칸이 지금 값이 범위 안인지 계속 알려 줍니다.
회사 지원서나 학교 서류는 규격이 조금씩 다르니 공고를 한 번 더 보세요.

## 하는 일

- **기준선 맞추기** — 정수리·턱끝·얼굴 중심 세 줄. 끌거나 화살표 키로 한 픽셀씩.
  줄을 잡으면 돋보기가 떠서 머리카락 한 올 단위로 보입니다.
  처음 열 때는 배경 경계와 입술 색으로 자리를 추측해 두므로,
  대개는 손댈 것이 없습니다.
- **배경 갈아 끼우기** — 흰색·회색 그러데이션·단색.
  테두리에서 번져 나가는 칠하기로 배경을 따내므로,
  이마 하이라이트나 흰 셔츠에 구멍이 뚫리지 않습니다.
  원래 배경이 단색일 때만 깔끔합니다.
- **보정** — 밝기·대비·따뜻함·선명도.
  선명도는 문지르는 쪽이 아니라 결을 살리는 쪽입니다.
  요즘 보정 앱이 남기는 밀랍 같은 피부를 되돌리는 데 씁니다.
- **인화지 배치** — 4×6″, 5×7″, A4 한 장에 몇 칸이 나오는지 세어 깔아 줍니다.
  가위선까지 그려 주니 무인 인화기에 그대로 넣으면 됩니다.
- **내려받기** — JPEG 로 저장하면서 인치당 점 수(300/600dpi)를 파일 머리말에
  적어 넣습니다. 인화기가 크기를 제 맘대로 읽지 않게 하려는 것입니다.

## 안 하는 일

옷을 갈아입히거나 얼굴을 고치지 않습니다. 잘라내고, 배경을 바꾸고,
톤을 만지는 데서 멈춥니다. 원본 화소를 그대로 옮기기 때문에
결과물에 사람이 만든 티는 나도 기계가 지어낸 티는 나지 않습니다.

정장이 필요하면 정장을 입고 찍는 편이 낫습니다.

## 잘 안 될 때

| 증상 | 까닭과 해법 |
|---|---|
| 배경을 바꿨더니 머리카락 끝이 뭉텅 잘림 | 「따내는 정도」를 낮춥니다 |
| 배경 구석에 원래 색이 남음 | 「따내는 정도」를 올립니다 |
| 얼굴에 구멍이 뚫림 | 배경이 단색이 아닙니다. 「그대로」로 두는 편이 낫습니다 |
| 「원본이 규격보다 작습니다」 | 사진 화소가 모자랍니다. 인쇄하면 흐립니다 |
| 「자리가 사진 밖으로 나갑니다」 | 얼굴 길이를 줄이거나 여백을 좁힙니다 |
| 내려받기가 안 됨 | 창(iframe)에 끼워져 열렸을 때 막힙니다. 웹 페이지로 띄우세요 |

## 만든 방식

파일 하나입니다. 바깥에서 가져오는 것이 없어 인터넷 없이도 돌아갑니다.
그림 처리는 전부 `<canvas>` 위에서 합니다 —
배경 따내기는 색 거리로 알파를 만든 뒤 테두리에서 번지는 칠하기로
배경에 이어진 곳만 남기고, 크기 줄이기는 절반씩 내려가며 계단을 줄이고,
선명도는 흐린 판과의 차이를 되돌리는 언샤프 마스크입니다.
