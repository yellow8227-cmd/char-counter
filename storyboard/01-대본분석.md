## 4. 반전 구조 — 이걸 모르고 그리면 그림이 다 틀어집니다

대본이 100분 동안 관객에게 **‘그것 = 대물림되는 저주’**라고 믿게 만든 뒤, 씬 71에서 뒤집습니다.

| | 관객이 믿는 것 (씬 1~70) | 실제 (씬 71~72) |
|---|---|---|
| 정체 | 핏줄을 따라온 원귀 | **망나니의 노모** — 아들이 손자를 살리려 시신에 건 봉신 |
| 색동저고리 | 죽은 아이 귀신의 옷 | **손자의 옷** — 「그 핏줄을 잊지 않도록」 무당이 시킨 것 |
| 뒤틀린 다리 | 기괴한 형상 | 망나니가 **직접 뒤꿈치를 잘랐다** (완전한 희생) |
| 붉은 부적 「封神」 | 얼굴을 가린 표식 | **원혼 수백을 가둔 봉인** — 뜯으면 터진다 |
| 거대함 | 점점 강해지는 저주 | **매달린 원귀의 무게** — 떼어내면 작고 왜소한 노인 |
| 목적 | 대를 끊으러 온다 | **대를 지키러 온다** (쿠키에서 확정) |

**연출상의 함의 — 스토리보드가 감당해야 할 두 겹**

1. **1~70씬**: ‘그것’은 항상 **거울·반사면·그림자**에서 크게 보인다. 실제 몸은 작다.
   → 거울 속 = 원귀 다발, 실제 = 왜소한 노인. **이 이중 노출을 씬마다 유지**해야 마지막이 성립합니다.
2. **씬 71 이후**: 부적을 떼는 순간 **얼굴 없음** → 그것이 떠나자 **원혼이 쏟아진다**.
   그것은 저주가 아니라 **방파제**였다. 「그년이 왜 사라졌는지 이제 알았다」

## 7. 스토리보드 작업 시 반드시 지켜야 하는 것 — 5개

1. **씬 1 ↔ 씬 54·55는 동일 장면.**
   프롤로그에서 쓴 컷 번호를 씬 54에 그대로 재사용하고, 「전환효과」 칸에 `MATCH CUT ← S1` 이라고 남깁니다. 두 번 그리면 예산과 촬영이 두 배로 듭니다.

2. **‘그것’은 두 개의 사이즈를 가진다.**
   - **실제 몸** — 작고 왜소한 노인 (씬 71에서 확정)
   - **그림자 · 거울 · 반사면** — 거대하게 부푼 원귀 다발
   같은 컷 안에서 이 둘이 어긋나야 합니다. 「디테일/메모」 칸에 매번 `실물=소 / 반사=대` 로 표기.

3. **세대가 바뀌어도 카메라 문법은 같게.**
   동훈의 임종(28) · 동성의 죽음(33) · 슈의 마지막(71)은 **같은 앵글·같은 사이즈**로 반복돼야 「원의 법칙」(3p 제사)이 성립합니다.
   → 세 씬 모두 `하이앵글 → 얼굴 위로 포개짐 → 부적 BCU` 3컷 세트로 고정.

4. **부적은 항상 정면.** 「封神」 두 글자가 읽혀야 씬 61(지현이 준 부적)과 씬 72(봉신성립)가 연결됩니다.

5. **온도 표시.** ‘그것’이 3m 이내로 들어오면 **입김 · 성에 · 서리**가 화면에 있어야 합니다 (씬 24·28·33·55·71). 「디테일/메모」에 `입김 ON`.

## 9. PPT 템플릿 구조

원본 `AI 스토리보드.ppt` — 슬라이드 1장에 **패널 6개 (3열 × 2행)**, 현재는 상단 3패널만 배치된 빈 템플릿입니다.
(현재 삽입돼 있는 이미지 1장은 샘플 스톡 사진이라 교체 대상입니다.)

패널 1개 = 4열 × 6행 표 + 그림 개체 틀 1 + 텍스트 개체 틀 6

```
┌─────────────────────────────────┐
│ Scene [__]        Shot [__]     │  ← 텍스트 틀 2개
├─────────────────────────────────┤
│                                 │
│        (그림 개체 틀)            │  ← 3.79 × 2.14 in ≒ 16:9
│                                 │
├──────────┬──────────────────────┤
│ 카메라    │                      │  ← 텍스트 틀
├──────────┼──────────────────────┤
│ 장면묘사  │                      │
├──────────┼──────────────────────┤
│ 디테일/메모│                     │
├──────────┼──────────────────────┤
│ 전환효과  │                      │
└──────────┴──────────────────────┘
```

슬라이드 13.333 × 7.5 in (16:9) · 그림 칸은 **3.79 × 2.14 in = 1.771:1** → 생성 이미지는 **16:9 (1.778:1)** 로 뽑으면 거의 딱 맞습니다.

### 5개 칸에 무엇을 넣는가 — 씬덱 규칙 그대로

| 칸 | 넣는 것 | 예 |
|---|---|---|
| **카메라** | 프레임 사이즈 + 앵글 + 카메라 4단(무브먼트·속도·유지·종료) | `MS 로우앵글 / dolly in, slow, 얼굴 중앙 유지, BCU에서 종료` |
| **장면묘사** | 무엇이 보이는가 — 인물·행동·공간 | `복도 한가운데 등을 보인 슈. 뒤에서 절룩이는 형체가 다가온다` |
| **디테일/메모** | 소품·사운드·특수효과·연속성 표시 | `슥…쿵 / 형광등 3회 점멸 / 실물=소 반사=대 / 입김 ON` |
| **전환효과** | 다음 컷으로 어떻게 넘어가는가 | `CUT TO` `MATCH CUT ← S1` `F.O` `DISSOLVE` `INTER CUT` |

## 10. 이미지 작업 순서 제안

1. **외형 고정 블록 먼저** — 인물 5명 + ‘그것’의 캐릭터 시트 3패널을 먼저 확정합니다.
   특히 **‘그것’은 두 벌** 필요합니다: ① 실물(왜소한 노인) ② 반사/그림자(원귀 다발).

   `--sref` 코드를 시대마다 하나씩 고정해두면 130장이 한 작품으로 붙습니다.

   1 · 8 · 12 · 19 · 21 · 26 · 33 · 55 · 69 · 70 · 71 · 72
