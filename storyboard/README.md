# 赫血 스토리보드 작업 폴더

원본 대본(117p·72씬)을 컷으로 쪼개고, 원본 PPT 템플릿에 **이미지까지 넣어서** 뽑는 곳입니다.

## 무엇이 들어 있나

| 파일 | 무엇 |
|---|---|
| `01-대본분석.md` | 대본 분석 — 시간선 · 반전 구조 · 반복 모티프 · 72씬 일람 · 대본 확인 필요 사항 |
| `cuts.json` | **컷 목록.** 여기만 고치면 됩니다 |
| `template.pptx` | 원본 PPT 템플릿 (샘플 스톡 사진은 빼둠 · 19KB) |
| `images/` | 컷 이미지. 파일 이름을 `cuts.json` 의 `image` 값과 맞춥니다 |
| `build_deck.py` | `cuts.json` + `images/` → `out/storyboard.pptx` |
| `preview.sh` | 만든 pptx를 PDF·PNG로 뽑아 눈으로 확인 |

## 지금까지 채워진 것

### 씬 1 · 2 · 54 배정

| 이미지 | 배정 | 왜 |
|---|---|---|
| 복도를 뒤덮은 거대한 형체 | **S1 C8** | 실물은 작고 그림자·덩어리만 거대하다는 원칙에 딱 맞는 컷 |
| ‘그것’의 맨발 (타이트 / 와이드) | **S1 C2 · C3** | 다가오는 발. 짚신 한 짝은 합성으로 얹어야 합니다 |
| 입가 비틀린 미소 | **S1 C16** | 입만 나와서 프롤로그의 **정체 숨김**이 유지됩니다 |
| 복도 정면 — 남자 + 뒤의 ‘그것’ | **S54 C8** | 얼굴이 드러난 컷. 대본상 정체 공개는 프롤로그가 아니라 **씬 54**입니다 |
| 赫血 - KAKKETSU - 타이틀 | **S2 C9** | 타이틀 시퀀스 마지막, 영문이 떠오르는 자리 |

씬 54는 대본에 `MATCH CUT TO — 병원 복도는 프롤로그와 동일한 씬입니다` 라고 적혀 있어서,
**씬 1에서 쓴 컷을 그대로 재사용**하도록 짰습니다 (S54 C6·C7·C14). 두 번 찍을 필요가 없습니다.

### 씬 72 — 무당씬 46장

받은 46장이 전부 씬 72 시퀀스라, 대본(p.110~115) 순서 그대로 66컷으로 쪼개고 하나씩 붙였습니다.

| 구간 | 컷 | 내용 |
|---|---|---|
| 사당 밖 | C1–3 | 초승달 · 사당 외관 · 수레에 무구를 싣는 사람들 |
| 사당 안 | C4–17 | 무당 / 거꾸로 선 망나니 / 삼경 종소리 / 「죽어」 |
| 문밖 | C18–20 | 노모가 엿듣는다 · **횃대의 색동저고리** |
| 무덤 | C21–29 | 보름달 · 부엉이 · 삽 · 짚신 · 관 뚜껑 |
| 관 | C30–32 | 색동저고리를 입은 노모 · 「어머니……」 |
| 의식 | C33–40 | 부적 · 손바닥 · 주문 3구 · **인신봉명** |
| 각성 | C41–47 | 머리카락 · 손톱 |
| 완전한 희생 | C48–55 | **발목 절단 — ‘그것’의 뒤틀린 다리가 완성되는 자리** |
| 봉신성립 | C56–66 | 부적을 이마에 · 얼굴이 사라진다 · 관에서 일어난다 |

이 씬은 영화의 **원점**이라, 뒤쪽 씬과 묶어놓은 연결을 「디테일/메모」 칸에 전부 적어뒀습니다.
색동저고리(C19·C30) → S8·S71, 짚신(C27) → S1·S54, 뒤틀린 다리(C55) → 전편,
부적(C14·C34·C59) → S1 C13·S61, 「슥…쿵」의 최초 발생(C64) → 전편.

## 쓰는 법

```bash
python3 build_deck.py     # out/storyboard.pptx 생성
./preview.sh 1            # 1번 슬라이드를 PNG로 확인
```

이미지가 아직 없는 컷은 **그림 칸을 빈 채로 두고 넘어갑니다.** 나중에 파일만
`images/` 에 넣고 다시 돌리면 그 자리에 들어갑니다.

## 컷 하나는 이렇게 생겼습니다

```json
{
  "scene": "1", "shot": "8",
  "camera": "LS 로우앵글 / 고정, 남자와 형체를 한 프레임에 유지",
  "desc":   "남자 뒤를 따라오는 ‘그것’. 한쪽 다리를 끌며 절룩인다.",
  "note":   "실물=왜소 / 벽 그림자=거대 · 팔이 여러 개로 엉킴 / 슥…쿵",
  "trans":  "CUT TO",
  "image":  "S01_C08.png"
}
```

| 칸 | PPT의 어느 자리 | 넣는 것 |
|---|---|---|
| `scene` `shot` | 패널 맨 위 | 씬 번호 · 컷 번호 |
| `camera` | 카메라 | 프레임 사이즈 + 앵글 + 카메라 4단(무브먼트·속도·유지·종료) |
| `desc` | 장면묘사 | 무엇이 보이는가 |
| `note` | 디테일 / 메모 | 소품 · 사운드 · VFX · 연속성 표시 |
| `trans` | 전환효과 | `CUT TO` `MATCH CUT ← S1` `F.O` `DISSOLVE` `INTER CUT` |

## 글자 길이

칸 하나가 **2.85 × 0.26 in** 밖에 안 됩니다. `build_deck.py` 가 글자 수를 재서
8pt → 5pt 사이로 자동으로 줄이지만, **한 칸 45자 안쪽**으로 쓰면 8pt를 유지하고 제일 잘 읽힙니다.

## 이미지 규격

그림 칸이 **3.79 × 2.14 in = 1.771:1** 이므로 **16:9 (1920×1080)** 로 뽑으면 거의 딱 맞습니다.
칸에 맞춰 가운데를 기준으로 잘려 들어가니, 인물을 프레임 가장자리에 두지 마세요.

파일 이름은 `S<씬 2자리>_C<컷 2자리>.png` — 예: `S01_C08.png`, `S72_C20.png`.
