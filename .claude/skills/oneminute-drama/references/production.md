# 제작 — 프롬프트 · 자막 · 운영

## 컷 프롬프트

대본의 타임코드를 컷 단위로 쪼갠다. 60초 = 20~26컷.
컷마다 이미지 프롬프트 하나, 그리고 그 이미지를 움직일 모션 프롬프트 하나.

프롬프트 본문은 **짧게** 쓰고 스타일과 캐릭터는 파라미터에 맡긴다.
얼굴을 말로 다시 묘사하면 레퍼런스와 싸워서 결과가 나빠진다.
"카메라 → 피사체 → 동작 → 빛" 순으로 20단어 안쪽.

컷 표에 넣을 항목 — 컷번호 / 타임코드 / 길이 / 샷·렌즈 / 프롬프트 본문 / 모션 / 비고.

## 스타일 고정

- **`--sref` 는 시즌 하나로 고정.** 10화 전체가 같은 코드를 쓴다.
  코드를 바꾸면 그 회차만 다른 작품처럼 보인다.
- **스타일 접미사는 한 곳에만 둔다.** 컷마다 복붙하지 말고 문서 상단에 한 번 정의하고
  빌드할 때 붙인다. 그래야 나중에 한 번에 바꿀 수 있다.
- `--ar 9:16` 고정.

## 캐릭터 고정

Midjourney V7 기준. 얼굴 고정은 **`--oref` + `--ow`** 를 쓴다.
`--cref` 는 V6 / Niji 6 문법이라 V7에서 동작하지 않는다.

| 상황 | `--ow` |
|---|---|
| 얼굴만 정확히 유지 | 400 ~ 600 |
| 의상이나 헤어를 바꿔야 하는 컷 | 200 ~ 300 |

`--ow` 를 높게 두면 옷이 안 바뀐다. 의상 변경 컷에서 결과가 계속 원본을 따라오면
가중치부터 낮춘다.

**Omni Reference가 안 먹는 조건** — Draft Mode, Conversational Mode, Fast Mode, `--q 4`.
결과가 이상하면 이것부터 확인한다.

`--iw` 는 이미지 프롬프트 전용(0~3, 기본 1)이고 `--oref` 와 역할이 다르다. 혼동하지 않는다.

## 숫자는 생성에 맡기지 않는다

시계 숫자, 날짜, 카운트다운, 시리즈 표식은 **전부 편집에서 얹는다.**
생성 모델은 숫자를 거의 매번 틀리고, 틀린 숫자는 시리즈 전체의 신뢰를 깨뜨린다.
프롬프트에서는 "시계 클로즈업"까지만 지시하고 문자판은 비워둔다.

## 영상화

이미지 → Kling / Runway / DreamMachine 으로 3초 클립.
립싱크는 대사 컷에만 필요하고, 생성 실패율이 가장 높으므로 회차당 3~4컷을 넘기지 않는다.
그래서 대사를 적게 쓰는 것이 예산 문제이기도 하다.

## 자막 규격

| 항목 | 값 |
|---|---|
| 한국어 | 1줄 13자 이내 · 최대 2줄 · 노출 최소 1.2초 |
| 영어 | 1줄 32자 이내 · 최대 2줄 · 한국어와 같은 프레임 |
| 세이프존 | 하단 22% 안쪽. 인스타 UI가 아래를 먹는다 |
| 훅 / 엔딩 카드 | 화면 중앙 · 대문자 · 자간 넓게 · 배경 딤 40% |
| 액센트 | 시즌 액센트 색 하나만. 다른 색을 쓰지 않는다 |

한국어와 영어를 같은 프레임에 붙이는 이유는, 자막 트랙을 갈아끼우는 것만으로
다른 언어권 버전을 만들기 위해서다. 대사가 적어야 이게 성립한다.

## 캐릭터 시트

시트는 한 장에 전신 4방향 턴어라운드 / 표정 8종 / 손 / 의상 플랫레이를 넣는다.
장르 중립 외형으로 만들어야 다음 작품에 그대로 쓴다 —
현대 복장, 시대색 없는 헤어, 특수 소품 없음.

시트 자체의 레이아웃은 리포지토리의 `ai-video-handbook/character-sheets/build.py`
(dark / light 두 테마)를 재사용한다. 매번 새로 짜면 시리즈처럼 안 보인다.

## 운영

- **업로드 시각을 시리즈 표식과 맞춘다.** 알람을 걸어두는 팬이 생기면 초기 도달이 고정된다.
- **캡션마다 같은 질문을 던지고, 실제 댓글을 다음 화 사연에 넣는다.**
- **투표는 시즌에 두 번, 질문은 하나로 고정.**
- **제작량 역산** — 10화 × 1분 = 10분, 총 200~250컷. 주 1화 기준 10주.
