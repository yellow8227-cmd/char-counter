# 설치된 스킬

## oneminute-drama  (자체 제작)

ONE MINUTE STUDIO 하우스 스타일. 세로 1분 숏드라마의 대사·회차·티저·프롬프트 규칙.
한국 단막극 5편과 상용 숏드라마 티저를 분해해 1분 포맷의 제약에 맞게 옮긴 것이다.

- `SKILL.md` — 작업 순서, 소리 채널 넷, 절대 안 하는 것, 내보내기 전 점검
- `references/dialogue-craft.md` — 대사 규칙 10개 + 개고 진단표
- `references/lead-voice.md` — 말이 많은데 정체는 모르게 만드는 여섯 장치
- `references/episode-structure.md` — 60초 비트 그리드, 시즌 설계, 궁금증 설계표
- `references/teaser-grammar.md` — 30초 티저 문법, 컷다운 파생
- `references/series-11-11.md` — 「11:11」 성경 (인물·규칙·사물 회수표·팔레트·계정)
- `references/production.md` — `--oref`/`--sref` 운용, 자막 규격, 운영
- `scripts/build_screenplay_docx.py` — 하우스 서식 워드 빌더

## creative-writing-skills  (외부)

출처: https://github.com/haowjy/creative-writing-skills (Apache-2.0)
소설·연재물용 창작 스킬 10종. `oneminute-drama` 가 포맷 규칙을 담당하고,
이쪽이 산문·비평·구조의 일반 이론을 담당한다.

`writing-principles` 가 특히 유용하다 — 독자 보상 채널(몰입·미감·사회적 시뮬레이션·
몰입도·호기심)과 LLM이 그것을 망가뜨리는 방식을 정리해 두었다.
"과잉 설명은 사회적 시뮬레이션을 깨뜨린다"가 우리 1고 대사가 죽은 이유다.

원본의 `llm-writing` / `shared-dao` / `project-setup` 은 상위 패키지(meridian-base)에
있어 이 설치본에 없다. 나머지 10종은 리소스까지 전부 받았다.
