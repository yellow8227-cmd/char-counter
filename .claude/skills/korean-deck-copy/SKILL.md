# 한국어 제안서 문구

정주원 룩백 제안서 작업에서 실제로 반려당한 문장들에서 뽑은 규칙이다.
추상적인 원칙이 아니라 **고치기 전 / 고친 후**가 붙어 있다.

## 1. 대구(對句)를 만들려고 무리하지 마라

`A가 아니라 B` 구문 자체는 죄가 없다. **대비 축이 실제로 맞을 때만** 쓴다.
축이 안 맞으면 멋있어 보이려고 만든 문장이라는 게 바로 티가 난다.

| 판정 | 문장 | 이유 |
|---|---|---|
| ✗ | 상은 사람이 아니라 **편에 걸립니다** | 상은 걸리는 게 아니라 주는 것. 술어가 틀렸다 |
| ✓ | 상은 **한 편 단위로 줍니다** | |
| ✗ | **기획안이 아니라** 지금 돌아가는 화면입니다 | 기획안 ↔ 화면은 같은 층위가 아니다 |
| ✓ | 지금 이 주소로 들어가도 그대로 돌아갑니다 | 검증해 보라는 초대로 바뀐다 |
| ✓ | 왜 **성수가 아니라 극장 안**인가 | 장소 ↔ 장소. 축이 맞다 |
| ✓ | **찍는 부스가 아니라 그리는 부스** | 동사 ↔ 동사. 축이 맞다 |
| ✓ | 첫 칸은 **프로가 아니라 학생**이 그립니다 | 사람 ↔ 사람. 축이 맞다 |

쓰기 전에 자문한다: **양쪽이 같은 종류인가?** 아니면 버린다.

## 2. 읽는 사람의 행동·감정을 단정하지 마라

제안서는 제안하는 글이지 확인시키는 글이 아니다.

| 판정 | 문장 |
|---|---|
| ✗ | 기획이 어디까지 돌아가는지는 **이미 확인하셨습니다** |
| ✓ | 프로토타입까지는 혼자 만들었습니다. 정식 오픈은 디자이너 1명·개발자 1명, 4주면 됩니다 |

`~하셨습니다` `이미 ~` `보시다시피` `느끼셨겠지만` — 전부 의심하고 본다.
자기 쪽이 한 일과 앞으로 필요한 것만 쓴다.

## 3. 은어·비유형 서술어를 평서형으로

| 판정 | 문장 |
|---|---|
| ✗ | 참여가 **안 붙으면** |
| ✓ | 사람이 덜 모이면 |

「붙다」「먹히다」「터지다」「돌다」 같은 업계 은어는 슬라이드에서 헐거워 보인다.
말할 때는 써도 되지만 쓰지는 않는다.

## 4. 금지 어휘

- **AI 상투어**: 극대화, 시너지, 임팩트, 혁신적, 새로운 패러다임, 차별화된, 최적화된, 전략적으로
- **번역투**: ~에 있어서, ~을 통해, ~화(化)를 이루다, ~라 할 수 있다, ~에 다름 아니다
- **과장 부사**: 정말, 매우, 굉장히, 압도적으로 — 숫자가 있으면 부사는 필요 없다
- **느낌표** — 제안서에 감탄사는 안 쓴다

## 5. 문장 길이와 마침

- 한 문장 **45자 이내**. 넘으면 자른다
- 슬라이드의 결론 한 줄은 **두 문장 이내**
- `~습니다` 로 끝낸다. 명사형 종결(`~함`, `~임`)은 표 안에서만

## 6. 가운뎃점(·)은 나열에만

`공간 · 집객 · 신뢰` 처럼 **같은 층위 낱말 나열**은 좋다.
문장을 잘라 붙이는 용도로 쓰면 리듬이 기계적으로 들린다.

- ✗ 개봉작 체험 콘텐츠 · 관객 로비 체류 18~22분 · 굿즈 매출 분배
- ✓ 로비에 개봉작 체험존. 관객이 18~22분 더 머뭅니다

한 장에 가운뎃점 **7개를 넘으면** 나열이 아니라 습관이다. 세어 보고 줄인다.

## 7. 문장 속 em-dash(—)를 남발하지 마라

극적 휴지를 만들려고 넣은 `—` 는 대부분 마침표로 바뀐다.
제목의 `제목 — 부제` 용법만 남긴다.

- ✗ 그 편에 참여한 사람은 전원 공동 수상입니다 — 혼자 그렸으면 혼자 받습니다.
- ✓ 그 편을 함께 그린 사람은 모두 공동 수상입니다. 혼자 그렸으면 혼자 받습니다.

## 8. 숫자는 근거와 함께, 수사 없이

- ✗ 압도적인 참여를 이끌어냅니다
- ✓ 참여 20,000명 = 완성 네컷 5,000편 × 편당 평균 4명

## 고치는 순서

1. `A가 아니라 B` 를 전부 찾아 **축이 맞는지** 하나씩 본다
2. `~하셨습니다` `이미` 로 독자를 단정한 곳을 찾는다
3. 가운뎃점을 센다. 장당 7개 넘으면 문장으로 푼다
4. 문장 속 `—` 를 마침표로
5. 45자 넘는 문장을 자른다
6. 금지 어휘 검색

## 기계로 세기

```bash
python3 - <<'PY'
import io,re,sys
t=re.sub(r'<[^>]+>',' ', io.open(sys.argv[1] if len(sys.argv)>1 else 'deck.html',encoding='utf-8').read())
t=' '.join(t.split())
for name,pat in [
  ('A가 아니라 B',   r'[^\s]{1,14}(?:이|가) 아니라 [^.。\n]{1,30}'),
  ('독자 단정',      r'(?:이미|보시다시피)[^.。]{0,20}(?:하셨|셨습니다)'),
  ('문장 속 em-dash', r'[가-힣] — [가-힣]'),
  ('금지 어휘',      r'극대화|시너지|임팩트|혁신적|패러다임|차별화된|최적화된|에 있어서|을 통해|라 할 수 있'),
]:
    m=sorted(set(re.findall(pat,t)))
    print(f'[{name}] {len(m)}건'); [print('   ·',x) for x in m[:12]]
print('가운뎃점', t.count('·'), '개')
PY
```
